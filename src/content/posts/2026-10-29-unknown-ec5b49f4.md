## 行为分析

共 **8** 条行为，每条都挂了证据，且全部静态可得。

### 1. 伪装系统组件

`T1036.005` · 置信度 **高** · 静态

资源版本信息自称 Microsoft (R) Windows (R) / Windows System Component，内部名与原始文件名为 rundll32.exe，产品名却是 Storage Optimizer，版本 7.0.27114.752，身份自相矛盾。

> **证据**：.rsrc VS_VERSIONINFO: CompanyName=Microsoft (R) Windows (R), InternalName=rundll32, OriginalFilename=rundll32.exe, ProductName=Storage Optimizer
> 
> **来源**：`ev-000012` · `ref:01f19284c0`

### 2. 探测虚拟机环境

`T1497.001` · 置信度 **中** · 静态

代码中出现 cpuid 指令用于探测虚拟化/调试环境（位于 rva 0x5824e），属于环境感知分支。

> **证据**：0x5824e cpuid
> 
> **来源**：`ref:adf25d778f`

### 3. rdtsc时间差反调试

`T1622` · 置信度 **中** · 静态

使用 rdtsc 读取时间戳并比较时间差，用于发现单步/调试停顿（位于 rva 0x8a20）。

> **证据**：0x8a20 rdtsc 时间差
> 
> **来源**：`ref:adf25d778f`

### 4. int 2Dh反调试

> **证据**：0x4ec90 cd 2d

> **来源**：`ref:adf25d778f` · `ref:ab6c94b126`

### 5. 加密节就地变换

`T1027.002` · 置信度 **高** · 静态

入口从自身节表读取 .b6fc41 的 VA 与大小（rva 0x314f），在 rva 0x3174 调用 VirtualProtect(0x140592000, 0x205000, PAGE_READWRITE) 后就地处理该 2.1MB 节；仿真中该节出现以 8 字节为步长的自移位写入，表明运行时解包/解密流程。

> **证据**：0x314f mov rax,[rip+0x58ab52] (VirtualProtect IAT); 0x3174 call rax; 仿真参数 addr=0x140592000 size=0x205000 prot=4
> 
> **来源**：`ref:eac10f3cd1` · `ref:068989a379` · `ref:06afaff139`

### 6. 最小化导入表

`T1027` · 置信度 **高** · 静态

> **证据**：pe.imports: 3 DLL / 17 symbols; imphash a8a0fef9c36f2c07ecd49e85e9a605eb

> **来源**：`ref:5ac3092533` · `ev-000002`

**局限与待验证**

1. 真实动态仅观测到进程启动与系统模块加载，未观测到后续载荷行为，无法确认 C2 与持久化。
2. 反虚拟机/反调试检查（cpuid、rdtsc、int 2Dh）可能导致沙箱内提前退出，动态结论受限。
3. 加密节 .b6fc41 未能在仿真中完成解密（执行超过 2.86 亿条指令仍处于变换阶段），family 与真实能力未确认。

5. 版本信息 Comments/PrivateBuild 中两串十六进制标识的用途未能确认（可能为构建/配置标识，但无证据）。
