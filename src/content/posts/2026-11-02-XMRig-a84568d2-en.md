## Behavior analysis

**8** behaviors in total, each backed by evidence; **4** are obtainable statically and **4** were obtained through dynamic analysis.

### 1. Drop temporary payload

`T1105` · Confidence **High** · Dynamic

Drops 19935385.exe under %LOCALAPPDATA%\Temp\ and creates child process 3248 to execute it; the process loads winhttp and then initiates outbound connections.

> **Evidence**: dynamic timeline: child process 19935385.exe (pid 3248), path C:\Users\analyst\AppData\Local\Temp\19935385.exe; the monitoring component recorded its image path in the target list
> 
> **Source**: `ref:c8c6956baa` · `ev-000042`

### 2. Hollow notepad and inject

`T1055.012` · Confidence **High** · Dynamic

The memory modules of notepad.exe (pid 3176) were replaced: the DOS/file/NT headers, entry point, and section headers were all modified, the original notepad image was replaced wholesale (REALIGNED), and the injected image contains XMRig.

> **Evidence**: memory forensics report: is_pe_replaced=1, dos/file/nt_hdr_modified=1, ep_modified=1, sec_hdr_modified=1, dump_mode=REALIGNED; the dumped module strings contain xmrig / stratum+tcp:// / RANDOMX_*
> 
> **Source**: `ref:c8c6956baa` · `ev-000042`

### 3. Connect to mining pool

`T1496` · Confidence **High** · Dynamic

The injected notepad.exe connects to donate[.]corvusminer[.]top on ports 444/443/3333 and uses XMRig's stratum+tcp:// and stratum+ssl:// protocols for Monero hash-power hijacking.

> **Evidence**: network monitoring: notepad.exe (3176) requested TCP 192.0.2[.]123:444/443/3333; DNS queries for donate[.]corvusminer[.]top and donate[.]ssl[.]corvusminer[.]top; dumped module contains stratum+tcp://, stratum+ssl://, RANDOMX_DATASET_BASE_SIZE
> 
> **Source**: `ref:c8c6956baa` · `ev-000042`

### 4. Fetch GitHub marker

`T1071.001` · Confidence **High** · Dynamic

The second-stage process uses WinHTTP to access the repository marker path /fuhudasi123/test7/refs/heads/main/1tag on raw[.]githubusercontent[.]com, which can be polled repeatedly, likely for version/config checks or update downloads.

> **Evidence**: network monitoring: 19935385.exe (3248) GET /fuhudasi123/test7/refs/heads/main/1tag HTTP/1.1, User-Agent: WinHTTP/1.0, Host: raw[.]githubusercontent[.]com

> **Source**: `ref:c8c6956baa` · `ev-000042`

### 5. XOR-obfuscated strings

`T1027` · Confidence **High** · Static

main and internal packages restore strings on the stack with byte-wise XOR 0xD8, combined with randomized function and package names to raise the cost of static reading; restored names include NetworkInstall/CorpVPN/RemoteAccess/DialerProfile/WANLink/SecureTunnel/EdgeDial/ConnMgr and the format string %s_%04x.

> **Evidence**: decompilation 0x111180: loop over local_1a6/local_1ad/local_1b9/local_1d9 with ^0xD8; pclntab: module ggvbzbtsq, main.* are short names such as bim1/car8/jer7/kyg2
> 
> **Source**: `ev-000041` · `ev-000042`

### 6. AES-GCM encrypted payload

## Do not misjudge

:::important
The following conclusions are **easy to misjudge**; keep this in mind when citing this report.

- Do not classify it as ransomware or a wiper: no file encryption, ransom notes, or disk destruction were observed; the AES constants are used only for payload/config encryption and cannot support a ransomware inference.
- Do not classify it as an info-stealer/banker: no file access or exfiltration related to browser credentials, wallets, clipboard, or keylogging was observed.
- Do not claim registry Run-key, service, or scheduled-task persistence: this run captured no evidence of registry/service/scheduled-task writes.
- Do not claim the sample installed itself as System32\mstp.exe: that path is only implied by the SystemRoot/System32/mstp.exe/taskkill.exe string concatenation in the static code, and no such drop was observed dynamically.
:::

## Analysis method and limitations

| Item | Content |
|:--|:--|
| Analysis method | Dynamic sandbox analysis + static decompilation |
| Unpacking | No |

**Limitations and open questions**

1. The second stage 19935385.exe only executed inside the sandbox and was not retrieved from disk, so its hash and signature cannot be provided.
2. The static code contains path-concatenation strings for SystemRoot\System32\mstp.exe and taskkill.exe, but their actual purpose (masquerading/killing processes/self-installation) was not confirmed dynamically and is not treated as a persistence conclusion.
3. This run did not process full registry and filesystem monitoring data (only network, process timeline, and memory dumps), so registry/scheduled-task persistence cannot be ruled out — only that it was not observed in this run.
4. Some configuration strings of the Go loader are XOR-obfuscated and only name-like strings were statically recovered; the mining-pool address could not be fully recovered — the pool domain came from real network observation.
5. The purpose of 19935385.exe's repeated connections to 127.0.0[.]1:8080 is unknown, possibly a local proxy/management interface; it is not included in the C2 conclusion.
