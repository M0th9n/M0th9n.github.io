## Behavior analysis

**11** behaviors in total, each backed by evidence; **10** are obtainable statically and **1** was obtained through dynamic analysis.

### 1. Decrypt browser key store

`T1555.003` · Confidence **High** · Static

Reads os_crypt.encrypted_key / app_bound_encrypted_key from Chromium Local State, unwraps them via DPAPI, and decrypts the passwords and cookies stored in Login Data/Web Data with BCrypt AES-GCM or ChaCha20-Poly1305.

> **Evidence**: function 0x5dc0; 0x5f4f lea rdx, os_crypt; strings encrypted_key/app_bound_encrypted_key/DPAPI/ChainingModeGCM/CHACHA20_POLY1305; imports CryptUnprotectData, BCryptDecrypt
> 
> **Source**: `ev-000014` · `ev-000005`

### 2. Steal browser credentials

`T1555.003, T1539` · Confidence **High** · Static

Enumerates the user-data directories of Chrome/Edge/Brave/Opera/Opera GX/Vivaldi/Yandex and reads Login Data, Login Data For Account, Web Data, Preferences/Secure Preferences, Local Extension Settings, and IndexedDB, collecting cookies, passwords, and form data.

> **Evidence**: strings Login Data, Web Data, Local Extension Settings, IndexedDB\chrome-extension_; endpoints /api/v1/ext/passwords, /api/v1/ext/tokens; memory contains ...Edge\User Data\Default
> 
> **Source**: `ev-000014` · `dyn-log-43340d`

### 3. Harvest wallets and TG data

`T1555` · Confidence **High** · Static

Locates MetaMask/Trust/OKX/SafePal extension storage, plus Exodus/Atomic/Electrum/Bitcoin/Litecoin wallet files and Telegram Desktop tdata, packages them into wallet.zip/tdata.zip, and uploads them.

> **Evidence**: strings metamask/trust/okx/safepal, Exodus\exodus.wallet, Electrum\wallets, Telegram Desktop\tdata, tdata.zip, /api/v1/ext/wallets, /api/v1/ext/telegram
> 
> **Source**: `ev-000014`

### 4. Drop malicious extension

`T1176` · Confidence **High** · Static

Extracts an embedded ZIP from the .embed section into a Manifest V3 extension named Google Translate v1.2.1, writes it to %LOCALAPPDATA%\Packages\Extensions\<HWID>\e<index>, and can install, pin, and enable it for specified browsers.

> **Evidence**: PK ZIP from 0x36a00, manifest name=Google Translate/version 1.2.1; runtime memory paths ...\Packages\Extensions\<HWID>\e0 and Temp\extE899.tmp.zip
> 
> **Source**: `ev-000006` · `ev-000014` · `dyn-log-43340d`

### 5. Register native-messaging host

`T1559, T1176` · Confidence **High** · Static

Writes host.ps1, host.bat, and com.lunex.explorer.json into the runtime directory and registers com.lunex.explorer under HKCU Chrome/Edge NativeMessagingHosts, giving the extension a channel to read, write, and execute local files.

> **Evidence**: FUN_0x19f40 writes host.ps1/host.bat/com.lunex.explorer.json; 0x1a35f/0x1a36e lea rcx registry paths; RegCreateKeyExW/RegSetValueExW
> 
> **Source**: `ev-000015` · `ev-000014`

### 6. Create logon autostart task

`T1053.005` · Confidence **High** · Static

Registers a task named installerUtils through Task Scheduler COM that triggers at logon and executes the current sample path, described as Starts installerUtils at user logon.

> **Evidence**: FUN_0x1a480 calls ITaskService/RegisterTaskDefinition; 0x1a7e1 lea r9, 'Starts %s at user logon'; runtime memory contains installerUtils
> 
> **Source**: `ev-000016` · `dyn-log-43340d`

### 7. Report host fingerprint

`T1082, T1518.001` · Confidence **High** · Dynamic

Collects HWID, computer/user name, OS build and patches, CPU/RAM/GPU/disk/screen, timezone/language, MAC, admin flag, antivirus products, and installed browsers, then POSTs them to /api/v1/checkin.

> **Evidence**: real dynamic: GET hxxp://37[.]187[.]140[.]177:8080/api/v1/agent/config (X-API-Key), two POST /api/v1/checkin, body contains hwid/computer_name/username/os_build/cpu/mac_address/is_admin/antivirus/browsers
> 
> **Source**: `dyn-log-43340d` · `ev-000014`

### 8. Query antivirus and system information

`T1518.001, T1082` · Confidence **High** · Static

Enumerates antivirus displayName from the WMI ROOT\SecurityCenter2 AntiVirusProduct table and reads registry keys such as CurrentVersion, CPU, GPU, timezone, and Locale.

> **Evidence**: 0x11163 lea rdx, ROOT\SecurityCenter2; string SELECT displayName FROM AntiVirusProduct; 0x10a26 CurrentVersion

> **Source**: `ev-000014` · `ev-000005`

### 9. Deliver and execute remote tasks

`T1105, T1059.001, T1059.003` · Confidence **High** · Static

Polls /api/v1/agent/tasks?hwid= and ACKs tasks, downloads files and executes them via cmd.exe /C, PowerShell -File, or msiexec, and can kill specified browser processes with taskkill.

> **Evidence**: 0xed40; 0xf27d cmd.exe /C "%s"; 0xf2dc powershell ... -File "%s"; strings imsiexec.exe /i, taskkill /F /IM "%s" /T, /api/v1/agent/tasks
> 
> **Source**: `ev-000014`

### 10. Remotely control the browser

`T1185, T1056.001, T1113` · Confidence **High** · Static

The extension connects to a controlled WebSocket/HTTP channel and executes commands such as injecting overlays, simulating mouse/keyboard, capturing tab screenshots, reading cookies/history/bookmarks, setting a proxy, and closing/reloading tabs.

> **Evidence**: background.js deobfuscation: /api/v1/ext/remote?api_key=, __bp_spoof_frame__ full-screen iframe (camera/microphone/geolocation/payment/clipboard-write), captureVisibleTab, mouse_move/key_down, set_proxy, bp_sent_cookies
> 
> **Source**: `ev-000006` · `dyn-log-43340d`

### 11. Strip CSP and inject pages

`T1176, T1185` · Confidence **High** · Static

The extension injects a content script into <all_urls> at document_start/all_frames and uses declarativeNetRequest rules to remove CSP headers from all responses, clearing the way for script injection and full-screen spoofed pages.

> **Evidence**: manifest content_scripts matches <all_urls> run_at document_start all_frames; rules/strip_csp.json removes 4 headers including content-security-policy
> 
> **Source**: `ev-000006` · `ev-000014`

## Do not misjudge

:::important
The following conclusions are **easy to misjudge**; keep this in mind when citing this report.

- Do not classify it as ransomware or a wiper: no file encryption, ransom notes, or destructive writes were found.
- Do not treat the extension's self-professed Google Translate name as benign evidence: its manifest requests cookies, proxy, nativeMessaging, <all_urls>, and other permissions, and actively strips CSP.
- Do not claim the extension was confirmed loaded in a browser or that the C2 delivered configuration: this run only observed the config/checkin requests; extension deployment and task delivery were not fully closed-loop.
:::

**Limitations and open questions**

1. No vendor-engine/YARA results are available for cross-validation; the family name is based on the internal namespace com.lunex.explorer and the companion extension, medium confidence.
2. In the real dynamic run the C2 was taken over by network monitoring, and only /api/v1/agent/config and /api/v1/checkin were observed; /api/v1/ext/* uploads, task delivery, and final extension loading were not verified in this run.
3. The sandbox guest only had Edge installed, not Chrome, so Chrome-specific paths were not triggered dynamically.
4. The registration code and runtime strings of the persistence task installerUtils were confirmed, but no registry/scheduled-task snapshot was exported for secondary verification.
5. The sample had already exited during the memory scan and no child processes were observed; the download-execution chain is statically confirmed.
