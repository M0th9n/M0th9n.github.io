## Behavior Analysis

**10** behaviors in total, each backed by evidence; **7** are static findings and **3** were obtained through dynamic analysis.

### 1. Built-in Multi-Channel C2 Addresses

`T1071.001` · Confidence **High** · Static

The program embeds cleartext HTTP IP address 177[.]221[.]180[.]26, Tor .onion and I2P addresses as control channels, and preferentially reads externally supplied addresses from /etc/pcc0 and $HOME/.ssh/pcc0; when neither exists it falls back to the built-in IP.

> **Evidence**: strings 0x537140/0x5371c0/0x537200 (.data.rel.ro); FUN_0041a007(0x41a007) first probes /etc/pcc0 and .ssh/pcc0, otherwise uses 0x537140
> 
> **Source**: `ref:50c93b3a37` · `ref:757ef24d7c`

### 2. CGI Channel Reports Host Information

`T1071.001` · Confidence **High** · Static

Using the GET /cgi-bin/p.cgi?r=0&auth=hash&i=<botid>&enckey=<key> template, it reports host information to the controller and parses replies and commands in the ?&i=...&answ=... form.

> **Evidence**: format strings 0x502aa0 and 0x502ad5; cross-references 0x41ab03/0x41ac65 (function 0x41a8a7)
> 
> **Source**: `ref:73998f5639` · `ref:2902f017e8`

### 3. Registers a systemd Service for Autostart

`T1543.002` · Confidence **High** · Static

Copies itself to /usr/sbin/uplugplay and /etc/uplugplay, writes /lib/systemd/system/uplugplay.service (Description=UPlay, Type=forking), then runs systemctl daemon-reload/enable/start to achieve boot autostart.

> **Evidence**: FUN_00423e78(0x423e78) decompilation: assembles the uplugplay.service content and invokes the systemctl command series
> 
> **Source**: `ref:77100f5c3b`

### 4. Writes a crontab Boot Entry

`T1053.003` · Confidence **High** · Static

Runs crontab -l to read existing tasks; if none exist, it assembles '@reboot <install path> -cron' and writes it back to crontab using task.cron as a temporary file, forming a second layer of persistence.

> **Evidence**: FUN_004236f4(0x4236f4) decompilation: @reboot prefix, -cron suffix, task.cron and crontab -l
> 
> **Source**: `ref:b71a13c222`

### 5. Attempts User-Mode Install to Disk

`T1036.005` · Confidence **High** · Dynamic

After startup it reads /proc/self/exe, checks whether /usr/sbin/uplugplay and /etc/uplugplay exist and attempts to install itself; under restricted privileges it prints 'Usermode install...Fail'.

> **Evidence**: dynamic events: readlink('/proc/self/exe'); access('/usr/sbin/uplugplay',F_OK)=-ENOENT; access('/etc/uplugplay',F_OK)=-ENOENT; stdout 'Usermode install...Fail'
> 
> **Source**: `ref:fd2360ae3e` · `ref:77100f5c3b`

### 6. Cleans Up Competing Processes and Old Versions

`T1489` · Confidence **High** · Dynamic

When the process count is greater than 1, it assembles the updatecheckerd/updatecheckerd.dat path, runs 'pkill updatecheckerd' and deletes the old file; it also checks for traces of old components such as /usr/sbin/msdtc, msdtc2, msdtc3 and /etc/CommId.

> **Evidence**: FUN_00423224(0x423224) decompilation; dynamic events openat('/usr/sbin/msdtc'|'msdtc2'|'msdtc3',O_RDONLY) and openat('/etc/CommId',O_RDONLY)
> 
> **Source**: `ref:1f52b159b4` · `ref:fd2360ae3e`

### 7. Tampers with hosts to Block Domains

`T1565.001` · Confidence **High** · Dynamic

Opens /etc/hosts with O_WRONLY|O_CREAT|O_APPEND to attempt appending records, used to block security vendor or update domains; under unprivileged execution it returns EACCES.

> **Evidence**: dynamic event: openat('/etc/hosts', O_WRONLY|O_CREAT|O_APPEND, 0666) = -EACCES
> 
> **Source**: `ref:fd2360ae3e`

### 8. Collects Host Fingerprint

`T1082` · Confidence **Medium** · Static

Reads /etc/os-release, /etc/redhat-release, /etc/debian_version, /proc/cpuinfo, /proc/meminfo, calls dmidecode --type baseboard to obtain the motherboard model, and uses nslookup 8.8.8[.]8 to probe the public address before reporting back.

> **Evidence**: strings 0x502931/0x50296d/0x502990/0x5029e7; cross-references 0x417d9a, 0x418838, 0x418af0, 0x419170 (function 0x4184bd); nslookup reference 0x496ea6
> 
> **Source**: `ref:73998f5639` · `ref:2902f017e8`

### 9. Performs Monero Mining

`T1496` · Confidence **Medium** · Static

Embeds the 'start_mining' command and 'HashPowerProject' mining pool/hashpower fields, starting the hashpower hijacking module on controller command.

> **Evidence**: 0x502f5b 'start_mining' is referenced by 0x42b1eb(main) and 0x421eaf; 0x5026ab 'HashPowerProject' is used in FUN_00410a6b(0x410a6b) to construct fields
> 
> **Source**: `ref:8d4169f4e2` · `ref:d568935ae8`

### 10. Modular Download and Update

`T1105` · Confidence **Medium** · Static

Supports module commands such as dbgwget, chkxwget, sha256ch, Dcomsvc, and updoldve, downloading, verifying and executing follow-on components on controller command while cleaning up old versions.

> **Evidence**: module command names assembled with movabs on the stack (dbgwget/chkxwget/sha256ch/Dcomsvc/updoldve/updatecheckerd.dat), .rodata 0x502f8d 'pkill updatecheckerd'
> 
> **Source**: `ref:8d4169f4e2` · `ref:73998f5639`

## Do Not Misjudge

:::important
The following conclusions are **easy to misjudge**; please take note when citing this report.

- Do not assert that the sample achieved persistence or a successful install: the isolated run executed as an unprivileged user, the install stage printed 'Usermode install...Fail', and no actual writes of uplugplay.service or crontab were observed.
- Do not assert that C2 was successfully contacted or that data was reported back: the isolated environment had no internet access, no successful session occurred, and C2 is only confirmed by static strings and cross-references.
- Do not classify it as ransomware or a wiper: no file encryption, mass deletion or ransom notice was found; the code focuses on persistence, information collection and hashpower hijacking.
:::

**Limitations and Pending Verification**

1. The isolated run environment had no internet access and ran as an unprivileged user, so no real C2 session, actual hashpower consumption by the mining process, or persistence file drops could be observed; C2 and configuration are marked static and pending dynamic verification.
2. The sample is statically linked with symbols stripped; for some modules (dbgwget/chkxwget, the mining payload) only strings and call traces exist, and their downloads or in-memory modules were not obtained.
3. No multi-engine naming or vendor signature results were available; the family determination is based on the built-in prometei.cgi identifier and evidence from this environment.
