>

> After running in a real Windows dynamic sandbox, the sample immediately sends DHT/KRPC bootstrap packets to UDP port 6881 on 13 hardcoded addresses and repeatedly queries TXT records of 4 runtime-generated domains through 6 public DNS servers; static decompilation also confirms boot autostart, service registration, single-instance mutex, download-and-execute, LAN reconnaissance, proxy forwarding and Monero mining monitoring capabilities. Static and dynamic evidence corroborate each other, and it is judged to be a malicious P2P botnet client.

## Behavior Analysis

A total of **12** behaviors, each with attached evidence; **10** are statically available and **2** were obtained through dynamic analysis.

### 1. Decrypts the Built-In String Table

`T1027` · Confidence **high** · Static

At startup it uses a self-implemented ChaCha20 (hardcoded 32-byte key and 12-byte nonce) to decrypt the 0x2175-byte string table in .rdata, then restores all paths, service names, protocol and command-line text through an index table; static scanning therefore sees only the after-XOR 'expand 32-byte k' constant.

> **Evidence**: 0x140011300 call FUN_140007f10(0x14001b5a0, 0x140062080, 0x2175, 0x140064200, 0x140064220, 0); 0x140007cc0 is the ChaCha20 block function; 0x140006530 restores the constant to 'expand 32-byte k' using 0xA5
> 
> **Source**: `ev-000022` · `ev-000025` · `ev-000027`

### 2. Installs for Boot Autostart

`T1547.001` · Confidence **high** · Static

When run without arguments it copies itself to %ProgramData%\protokol\ under its current filename, then writes a value named 'protokol' with its own quoted path as data to HKCU\Software\Microsoft\Windows\CurrentVersion\Run.

> **Evidence**: 0x140012260 CopyFileA + RegOpenKeyExA(HKEY_CURRENT_USER, Run subkey) + RegSetValueExA(value='protokol')
> 
> **Source**: `ev-000019`

### 3. Registers a System Service

`T1543.003` · Confidence **high** · Static

Opens SCManager with administrator rights and creates or updates an auto-start service named 'protokol' with display name 'protokol service'; the command line is built as '"<own path>" --run-service'; it configures restart-on-failure and calls StartService immediately.

> **Evidence**: 0x140012480 OpenSCManagerA/CreateServiceA(0x10=SERVICE_WIN32_OWN_PROCESS, start=2 auto)/ChangeServiceConfig2A/StartServiceA
> 
> **Source**: `ev-000020`

### 4. Single-Instance Mutex

`T1057` · Confidence **high** · Static

Creates the 'Local\protokol.single' mutex; if it already exists, it reads the pid lock file, verifies the start time via OpenProcess + GetProcessTimes, terminates the old instance with TerminateProcess and takes over, preventing multiple instances on the same machine.

> **Evidence**: 0x140010e00 CreateMutexA('Local\\'+string index 0xa2) + OpenProcess(0x401)+TerminateProcess; takes over after WaitForSingleObject timeout
> 
> **Source**: `ev-000033`

### 5. DHT Bootstrap Networking

`T1090` · Confidence **high** · Dynamic

Sends UDP packets to 13 hardcoded IPv4:6881 addresses for BitTorrent DHT/KRPC bootstrapping, then switches to TCP connections to active peers after receiving the node list; UDP 6881 requests to all 13 addresses were actually observed in the dynamic sandbox.

> **Evidence**: 0x14000f8f0 socket(2,2,0)/sendto to 13 {ip,port=6881} entries starting at .rdata 0x140065320; the same set of addresses is accessed in network byte order in the dynamic network log
> 
> **Source**: `ev-000034` · `ref:02e68ebac8`

### 6. DNS TXT C2 Addressing

`T1071.004` · Confidence **high** · Dynamic

Repeatedly queries TXT records of paranoidjuice[.]info, howtodisappearcompletely[.]zip, imaweirdo[.]my and smithsonn-s[.]top through six public resolvers — 208.67.222[.]222, 8.8.4[.]4, 8.8.8[.]8, 1.1.1[.]1, 1.0.0[.]1, 9.9.9[.]9 — to bypass local DNS and obtain commands or node information.

> **Evidence**: dynamic network monitoring record: pid 6052 produced 42 TXT queries for each of the 4 domains above; the static string table contains '.top/.pw/.cc/.xyz' suffixes and TXT parsing logic
> 
> **Source**: `ref:02e68ebac8` · `ev-000025`

### 7. Deploys a Monero Miner

`T1496` · Confidence **high** · Static

Contains xmrig-compatible configuration fields (pools/coin=monero/randomx/donate-level/huge-pages) and payload names pk-c.exe, pk-r.exe, pk-c.json, and parses hashrate, shares_good, uptime, pool and other fields through a local HTTP API to monitor mining revenue.

> **Evidence**: string table indexes 325-360 and 397-401; 0x1400135e0 parses miner JSON through the 127.0.0[.]1 HTTP API; 0x14000f450 handles issued commands
> 
> **Source**: `ev-000025` · `ev-000031`

### 8. Downloads and Executes Payloads

`T1105` · Confidence **medium** · Static

Uses wget/curl/ftp/aria2c or a built-in HTTP client to fetch second-stage files, parses them by BEGIN/chunk offset and verifies by hash, then launches them with chmod/exec; failure branches include messages such as 'chunk offset mismatch', 'hash mismatch' and 'exec failed'.

> **Evidence**: string table indexes 76-108 (wget/curl/ftp/aria2c, chunk/size/hash mismatch, exec failed); message types 0x10-0x23 at 0x140014910 are dispatched by FUN_14000f450
> 
> **Source**: `ev-000025` · `ev-000032`

### 9. LAN Host Discovery

`T1016` · Confidence **high** · Static

Reads /proc/net/route, /proc/net/arp, /proc/net/if_inet6 and /proc/net/wireless to enumerate interfaces, routes and neighbor tables, and outputs scan results in the form '# recon lan hosts=%d' for lateral movement.

> **Evidence**: string table indexes 9-10, 169-173 (/proc/net/arp, route, if_inet6, '# recon lan hosts=%d'); IPHLPAPI GetAdaptersInfo/GetIpNetTable imports
> 
> **Source**: `ev-000025` · `ev-000012`

### 10. LAN Service Scanning

`T1046` · Confidence **high** · Static

Contains built-in probe packets for mDNS/DNS-SD, SSDP/UPnP, RTSP, SSH banner and printer services (_services._dns-sd._udp, 239.255.255[.]250:1900, RTSP OPTIONS, ssh-2.0-) to discover attackable IoT/LAN devices.

> **Evidence**: string table indexes 174-180, 406-427 (bencode find_node/get, M-SEARCH, _services._dns-sd._udp, ssh-2.0-, _ipp/_printer)
> 
> **Source**: `ev-000025`

### 11. Built-In Proxy Channel

`T1090` · Confidence **medium** · Static

Implements SOCKS4/SOCKS5/CONNECT and the HAProxy PROXY protocol, detects whether tunneling tools such as frpc/frps/chisel/ligolo/rsocks are running locally, and can use the compromised host as a proxy node to forward traffic.

> **Evidence**: string table indexes 66, 288-300 (PROXY TCP4, socks5, socks4, CONNECT, frpc/frps/chisel/ligolo/rsocks); message types 0x02/0x05 at 0x140014910 handle chained forwarding
> 
> **Source**: `ev-000025` · `ev-000032`

### 12. Anti-Debug Detection

`T1622` · Confidence **medium** · Static

The decrypted strings include IsDebuggerPresent and CheckRemoteDebuggerPresent, and it reads the TracerPid field of /proc/self/status to determine whether it is in a debugging or analysis environment.

> **Evidence**: string table indexes 34, 158-159 (TracerPid: / IsDebuggerPresent / CheckRemoteDebuggerPresent); decrypted at 0x140011300 and consumed by the startup flow
> 
> **Source**: `ev-000025`

## Do Not Misjudge

:::important
The following conclusions are **easy to misjudge**; please note them when citing this report.

- Do not classify it as ransomware or a wiper based only on the built-in Monero mining configuration and hashrate monitoring; no file encryption, ransom note or destructive deletion behavior was seen in the sample.
- Do not claim that a successful C2 session, command delivery or second-stage payload drop was observed; the dynamic phase captured only UDP 6881 bootstrap probes and DNS TXT queries, with no response session obtained.
- Do not claim that Windows persistence was actually written during this run; no protokol entry appeared in the Run key or service table before or after dynamic telemetry, and persistence is visible only in static code.
- Do not treat the 13 port-6881 addresses as HTTP C2; they are BitTorrent DHT bootstrap nodes operating over UDP.
:::

**Limitations and Pending Verification**

1. The dynamic phase captured only UDP 6881 bootstrap packets and DNS TXT queries; no C2 response was received, so the TXT protocol format, command set and second-stage payload address cannot be confirmed.
2. No Monero miner, downloader or proxy child process was observed being written to disk; the relevant capabilities come from the static string table and the decompiled control flow.
3. The dynamic run produced no Run key/service entry, possibly due to execution duration, privileges or sandbox network restrictions; this cannot be used to deny the persistence capability.
4. The string table uses a self-implemented ChaCha20 (32-byte key + 12-byte nonce) with the key hardcoded in .rdata; the family name 'protokol' comes from internal self-naming and public naming has not been confirmed by multiple sources.
5. Whether the 13 port-6881 nodes are long-term C2 infrastructure requires further external intelligence verification; currently they are only proven to be a built-in bootstrap list.
