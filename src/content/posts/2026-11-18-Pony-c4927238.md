## 行为分析

共 **10** 条行为，每条都挂了证据；其中 **7** 条静态可得、**3** 条经动态分析取得。

### 1. 回连五个投递门

`T1071.001` · 置信度 **高** · 动态

运行后按硬编码列表依次访问 5 个 HTTP 门，端口 80，请求为 POST %s HTTP/1.0，Host 为被入侵站点，UA 伪装成 Mozilla/4.0 (compatible; MSIE 5.0; Windows 98)。动态沙箱中进程 8108 对 www[.]komfort[.]n-co[.]ru、svcrystal[.]ru、www[.]karl-koller[.]at、fun-aktion[.]de 真实发出 POST，并以约 5 秒间隔重试。

> **证据**：0x403d14 push 0x414efe ("POST %s HTTP/1.0"); 动态日志 01:56:27 POST /rss/LijHgs3_3829008.php, Host: www[.]komfort[.]n-co[.]ru
> 
> **来源**：`ev-000014` · `ref:799db6d854` · `ref:9c198685fd`

### 2. 上传加密主机指纹

`T1041` · 置信度 **中** · 动态

每个门的 POST 体为 183 字节高熵二进制（Content-Length 185，Content-Type: application/octet-stream），多次请求内容完全相同，属于加密/编码后的机器与木马标识上报；未观察到明文字段。

> **证据**：动态流量：POST body 以 fd bf bc eb 73 ce c3 e9 开头，长度固定 185；四个门请求体一致
> 
> **来源**：`ref:799db6d854` · `ev-000014`

### 3. 窃取FTP客户端凭据

> **证据**：字符串 0x414xxx 起："Software\\Far\\Plugins\\FTP\\Hosts"、"\\sitemanager.xml"、"Software\\FlashFXP"、"Software\\SimonTatham\\PuTTY\\Sessions"
> 
> **来源**：`ev-000014`

### 4. 提取浏览器保存密码

> **证据**：字符串 "SELECT hostname, encryptedUsername, encryptedPassword FROM moz_logins"、"Login Data"、"password_value"、"PK11SDR_Decrypt"、"CryptUnprotectData"

> **来源**：`ev-000014`

> **证据**：字符串 "CredEnumerateA"、"PStoreCreateInstance"、"CryptAcquireCertificatePrivateKey"、"CryptUnprotectData"

## 分析方法与局限

| 项目 | 内容 |
|:--|:--|
| 分析方法 | 动态沙箱分析 + 静态反编译 |
| 脱壳 | 否 |

**局限与待验证**

1. 沙箱将外部流量重定向到假网，虽观测到样本真实发出 POST，但未获得门端响应，故 C2 条目按静态恢复记录并标记待动态复核。
2. POST 体为 183 字节高熵二进制，使用未知加密/编码，未能解出明文，无法确认上报字段（机器名、用户名、木马 ID 等）的具体结构。
3. 未观察到注册表 Run 键、服务或计划任务写入；不排除需要重启、特定权限或特定参数才触发的持久化。
4. 函数入口存在重叠指令/多态跳转，反编译输出多处不可达，函数级语义主要依据字符串常量、动态导入 API 与定点反汇编窗口。
5. 5 个门 URL 中 awardspace 一条格式错误，动态仅见失败的主机名解析，不能视为有效通信地址。
6. 凭据窃取能力由静态字符串与 API 组合证明；沙箱为干净环境，未实际生成可读取的受害者凭据文件，因此没有窃取成功的数据样本。
