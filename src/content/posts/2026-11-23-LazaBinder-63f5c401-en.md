> [!WARNING]
> **Verdict: malicious** · Family **LazaBinder** (doubtful) · Confidence **medium**
> 
> Aliases: TWINFORGE-PACK, Luxpert bundler
> 
> The outer layer is a LazaBinder packer/delivery tool written in Go: it carries a ZIP payload at the end of the file (starting at offset 0x50F600, trailer marker TWINFORGE-PACK1!), the manifest sets require_admin=true, and after execution it drops and simultaneously launches two programs under %LOCALAPPDATA%\LazaBinder\Runs\. A real detonation in the dynamic sandbox observed SinghHourly.exe extracting via IExpress into %TEMP%\IXP000.TMP, using the officially signed AutoIt3.exe to create Hampton.lnk and having explorer.exe launch the obfuscated AutoIt script Bond.au3; LuxpertDemo.exe is a PyInstaller/PySide6 demo of a Roblox script executor. The packer handles silent delivery and proxy execution, making it part of a malicious delivery chain; evidence for the behavior of the two payloads themselves rests on static modules and runtime process/memory data.

## Behavior Analysis

There are **8** behaviors in total, each with evidence attached; **4** are available statically and **4** were obtained through dynamic analysis.

### 1. Embedded ZIP payload

`T1027` · Confidence **high** · Static

The outer 53MB Go program carries a ZIP overlay at the end of the file (starting at 0x50F600) with trailer marker TWINFORGE-PACK1!, containing manifest.json plus programs/1.exe and programs/2.exe; the manifest declares title=Luxpert and require_admin=true.

> **Evidence**: the overlay @0x50F600 begins with PK\x03\x04; manifest.json: {"title":"Luxpert","require_admin":true}; entries programs/1.exe and programs/2.exe
> 
> **Source**: `ref:8a875d5d69` · `ref:15c992a832`

### 2. Drop and execute both payloads

`T1105` · Confidence **high** · Dynamic

At runtime it drops the two payloads to %LOCALAPPDATA%\LazaBinder\Runs\run-4037060001\program-1|program-2 and launches SinghHourly.exe and LuxpertDemo.exe as separate child processes.

> **Evidence**: process creation events: program-1\SinghHourly.exe (pid 6036, parent pid 4548) and program-2\LuxpertDemo.exe (pid 5492)
> 
> **Source**: `ref:9b9291f25a` · `ref:e7ba3141a5`

### 3. Create a shortcut, then launch

`T1204.002` · Confidence **high** · Dynamic

SinghHourly.exe (IExpress self-extractor) first extracts AutoIt3.exe and Bond.au3 to %TEMP%\IXP000.TMP, calls AutoIt3.exe /AutoIt3ExecuteLine to create Hampton.lnk pointing to Bond.au3, and then has explorer.exe start the shortcut to run the script.

> **Evidence**: RCDATA strings: "AutoIt3.exe" /AutoIt3ExecuteLine "FileCreateShortcut(@AutoItExe, 'Hampton.lnk', @WorkingDir, 'Bond.au3')"; "cmd /c explorer.exe Hampton.lnk & timeout /t 8 /nobreak"; process events IXP000.TMP\AutoIt3.exe (pid 4300 created the .lnk, pid 2612 was launched by explorer.exe to run Bond.au3)
> 
> **Source**: `ref:aa94f01d18` · `ref:9b9291f25a`

### 4. Abuse of a signed interpreter

`T1059.010` · Confidence **high** · Static

Uses the officially AutoIt-signed AutoIt3.exe (3.3.18[.]0, digital signature verification passed) as a trusted interpreter to execute scripts, forming LOLBin-style proxy execution.

> **Evidence**: AutoIt3.exe sha256=5d69a932a077fee044b193c28e84564143f5c7e51079ab48e88fef74ab0b77b7, signature status Valid; the command line in the PE resources is exactly AutoIt3.exe ... Bond.au3
> 
> **Source**: `ref:a490fd608d` · `ref:0b9992d808`

### 5. Script encryption and obfuscation

`T1027` · Confidence **high** · Static

Bond.au3 is actually a compressed/encrypted compiled AutoIt script: 1,083,715 bytes, entropy 7.999, no readable strings, with the AU3!EA06 marker appearing only at 0x1669 and at the end of the file; static analysis cannot recover the script logic.

> **Evidence**: Bond.au3 entropy=7.999; AU3!EA06 @0x1669 and @EOF-8; zlib/PE decompression attempts all failed
> 
> **Source**: `ref:2ff555898b` · `ref:389a14066e`

### 6. Dynamic execution at runtime

`T1059.010` · Confidence **medium** · Dynamic

AutoIt process memory shows obfuscated variable names and dynamic Execute('...') calls, plus runtime checks such as StringIsFloat/StringIsAlnum, indicating that the script interprets and executes encrypted logic at runtime.

> **Evidence**: memory forensics (AutoIt3.exe pid 2612) shows Execute('LQbqCam...'), Execute('jJgouoT...'), StringIsFloat('iOdxseWplcItCS'), StringIsAlnum('wDIKjah') and many random uppercase variable names
> 
> **Source**: `ref:a9f215ea5d` · `ref:bdde98da84`

### 7. Run a cheat frontend

`T1204.002` · Confidence **high** · Dynamic

LuxpertDemo.exe (PyInstaller/PySide6, Python 3.12) spawns a child of itself and starts a GUI; module names and copy show that it is a Roblox script executor (Inject, Luau editor, Script Hub, multi-instance, auto-inject), but run_demo describes itself as a recorded demo that does not actually inject.

> **Evidence**: CArchive contains run_demo, app, script_hub, script_catalog, script_samples, settings_page; run_demo docstring: "Nothing is injected, nothing is attached. It only plays the scene for the camera."; process event LuxpertDemo.exe child process pid 2148
> 
> **Source**: `ref:9b9291f25a` · `ref:bbf9e542df` · `ref:dde5c2bdfc`

### 8. Request administrator privileges

`T1548.002` · Confidence **medium** · Static

The manifest sets require_admin=true; the outer launcher implements an IsElevated check and shell32/ole32/advapi32 privilege-escalation logic, and runs the payloads in an administrator context.

> **Evidence**: manifest.json require_admin=true; Go symbols lazabinder/internal/launch.IsElevated, launch.Run, launch.Start; imports of kernel32/shell32/ole32/advapi32 calls
> 
> **Source**: `ref:8a875d5d69` · `ref:d79d63de51`

## Do Not Misjudge

:::important
The following conclusions are **easy to misjudge**; take care when citing this report.

- Do not claim that C2 or data exfiltration has been confirmed: network monitoring during the dynamic window recorded only system/Edge update traffic, no sample process initiated a DNS/HTTP session, and the C2 column is empty.
- Do not claim that the sample is an infostealer or ransomware: no credential reading, wallet/browser database access, or file encryption behavior was observed.
- Do not claim that LuxpertDemo.exe has real injection capability: its own copy explicitly states that it is a recorded demo which injects no process, and the bundle contains no native module for injection.
- Do not claim that persistence via registry Run/RunOnce, services, or scheduled tasks was established: this collection captured only process creation and memory dumps, with no registry/service telemetry to support it.
- Do not attribute Bond.au3 to a specific known family: the script is encrypted/obfuscated, memory shows only obfuscation markers and dynamic execution primitives, and no plaintext logic or C2 was recovered.
:::

## Analysis Method and Limitations

| Item | Content |
|:--|:--|
| Analysis method | dynamic sandbox analysis + static decompilation |
| Unpacking | Yes |

**Limitations and items pending verification**

1. Bond.au3 is an encrypted/obfuscated compiled AutoIt script, and its logic cannot be recovered statically; runtime memory forensics showed only obfuscation markers, dynamic Execute calls and decimal/hex-encoded strings, and no plaintext C2 or functionality could be decoded.
2. No network connection initiated by a sample process was observed during the dynamic window; network monitoring showed only Windows/Edge update traffic, so C2 and callback capability cannot be confirmed.
3. LuxpertDemo.exe is packaged with Python 3.12/PyInstaller, and no matching decompiler version is available locally; the behavior judgment is based on module names, embedded copy and runtime process events, and the bytecode was not recovered line by line.
4. This dynamic collection includes process creation events and process memory dumps, but not registry/service/certificate telemetry; persistence and privilege-escalation outcomes can only be inferred from the static manifest and launcher symbols.
5. The sandbox performed a single short observation; the AutoIt script showed no further file drops or external connections within the observation window, so delayed-trigger or environment-gated branches cannot be ruled out.
