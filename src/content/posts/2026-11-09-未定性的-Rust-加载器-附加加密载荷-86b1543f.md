> **判定：恶意** · 家族 **未定性的 Rust 加载器（附加加密载荷）**（存疑） · 置信度 **低**
> 
> 样本为 7.98 MB 的 64 位 Rust/PE 程序，静态导入表仅 ntdll!NtDelayExecution 一项，却在真实沙箱运行期动态加载了 wininet/winhttp/ws2_32/urlmon 以及 dpapi/mskeyprotect/rsaenh/ncrypt 等网络与密码组件，并向 443/80 发起无域名解析的 TCP 连接尝试；其 Authenticode 签名主体为 2011 年签发、2013 年即已过期的 Take-Two Interactive/Rockstar Games 代码签名证书，签名块之后附加了 4,456,448 字节、熵 7.99997 的未签名加密数据。静态自证与真实运行观测相互印证，无正常软件需要如此组合，判定为恶意加载器/植入体。

## 行为分析

共 **7** 条行为，每条都挂了证据；其中 **4** 条静态可得、**3** 条经动态分析取得。

### 1. 运行期动态加载网络库

`T1027` · 置信度 **高** · 动态

静态导入表只有 ntdll!NtDelayExecution 一项，但进程运行后内存模块表中出现 wininet.dll、winhttp.dll、ws2_32.dll、urlmon.dll、webio.dll、mswsock.dll 等网络组件，说明这些 API 由程序在运行期自行解析/加载，而非由 PE 导入表提供。

> **证据**：pe_imports 仅 ntdll!NtDelayExecution (IAT 0x140329E00)；内存模块表含 wininet/winhttp/ws2_32/urlmon/webio
> 
> **来源**：`ref:18e74332bf` · `ref:0d1e4d4acc`

### 2. 入口经IAT调用延时

`T1497.003` · 置信度 **高** · 静态

入口点 0x1400012E0 处的混淆跳板在 0x1400013A8 以 call qword ptr [rip+0x328c62]（即 [0x140329E00]）调用导入的 NtDelayExecution，具备睡眠/延时式反分析能力。

> **证据**：0x1400013A8 call qword ptr [0x140329E00] → IAT rva 0x329E00 = NtDelayExecution
> 
> **来源**：`ref:64dceb7fa7` · `ref:18e74332bf`

### 3. 附加加密载荷

`T1027.009` · 置信度 **高** · 静态

Authenticode 签名块结束于文件偏移 3,520,928，其后附加 4,456,448 字节（0x440000）数据，字节熵 7.99997，完全随机分布，且不在签名覆盖范围内；该区域高度疑似加密的第二阶段载荷或配置容器。

> **证据**：off 0x35BD60 起 4,456,448 字节，熵 7.99997；签名块长度 3,488
> 
> **来源**：`ref:8b13ad0334` · `ref:71b7436fde`

### 4. 滥用过期游戏厂商证书

`T1553.002` · 置信度 **高** · 静态

文件内嵌代码签名证书，主体为 Take-Two Interactive Software, Inc. / Rockstar Games（VeriSign Class 3 Code Signing 2010 CA），有效期 2011-09-21 至 2013-09-20。该证书早已过期多年，属在野长期被滥用的泄漏代码签名证书特征，用于降低安全产品与用户的戒心。

> **证据**：SECURITY 目录 rva 0x35AC00 长度 0xDA0；证书 Subject CN=Take-Two Interactive Software, Inc., OU=Rockstar Games；NotAfter=130920235959Z
> 
> **来源**：`ref:a44bdeaf5e` · `ref:b623e2d885`

### 5. 编码化数据与字符串

`T1027.013` · 置信度 **高** · 静态

.rdata 尾部与 .data 各自呈现受限符号表编码流（.data 仅 84 种取值、频次近似均匀，熵 5.605），可读 ASCII/UTF-16 业务字符串几乎不存在；配合仅 1 项导入，符合运行时解密字符串与配置、规避静态字符串检索的做法。

> **证据**：.data off 0x342A80 起 92,672 字节仅 84 种字节取值；.rdata 尾部同样为非常规编码流
> 
> **来源**：`ref:0cb9a5f5cf` · `ref:5e0bd8a58a`

### 6. 硬编码IP外联尝试

`T1095` · 置信度 **中** · 动态

进程运行期向远端 443 端口发起 TCP 连接尝试，随后又向 80 与 443 端口发起尝试；网络监控中该进程没有任何域名解析请求，提示目标为硬编码 IP。未捕获到完整的 HTTP 请求行、Host 头或响应，会话未建立。

> **证据**：网络监控：86b1543...exe (6816) requested TCP :443（01:31:02）、TCP :80 与 :443（01:31:08），全程无该进程的 DNS 请求
> 
> **来源**：`ref:75a20aa801` · `ref:3860ac66c9`

### 7. 加载DPAPI与CNG组件

`T1555` · 置信度 **中** · 动态

运行期内存模块表出现 dpapi.dll、mskeyprotect.dll、rsaenh.dll、bcrypt.dll、ncrypt.dll、crypt32.dll、cryptnet.dll、wintrust.dll 等，表明程序具备调用系统数据保护（DPAPI）与 CNG/RSA 加解密接口的能力；本次未观测到对凭据库的实际读取。

> **证据**：模块表：dpapi.dll 0x7ffc85550000、mskeyprotect.dll 0x7ffc64dd0000、rsaenh.dll 0x7ffc84830000、ncrypt.dll 0x7ffc85210000
> 
> **来源**：`ref:0d1e4d4acc` · `ref:305d1e1409`

5. 纯 CPU 仿真未产生任何 API 调用记录，说明该载荷依赖真实系统组件，仿真结果不具结论性。
