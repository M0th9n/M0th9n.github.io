The behavior chain is complete and internally consistent, hence malicious.

## Behavior analysis

**11** behaviors in total, each with evidence attached, all of them statically obtainable.

### 1. Connects to C2 and registers

`T1095` · confidence **high** · static

main.main reads host 23.247.168[.]32 and port 1337 from the .data global string header, resolves them through the built-in public DNS list, and calls net.Dial("tcp", host:port) to establish a long-lived connection; after connecting it collects CPU core count, memory, disk, and other information for registration (string REGISTER linux ppc64).

> **Evidence**: main.main RVA 0x2462e0; .data VA 0x59c1d0->"23.247.168[.]32", 0x59c1e0->"1337"; resolveDomain RVA 0x245d80; net.Dial @0x157fa0; "REGISTER linux ppc64" @0x33ec26
> 
> **Source**: `ev-000022` · `ev-000008` · `ev-000007`

### 2. Parses and dispatches commands

`T1059` · confidence **high** · static

After connecting it uses bufio.Scanner to read C2 text commands line by line, strings.Fields to tokenize, methodAllowed to validate the method name, and strconv.Atoi to parse numeric values such as port/duration, then startAttack dispatches to the corresponding attack function via map+goroutine; unknown methods are rejected.

> **Evidence**: main.main RVA 0x2462e0 calls bufio.NewScanner@0xa1850, strings.Fields@0x9ce70, methodAllowed@0x24a990, strconv.Atoi@0xc7c20, startAttack@0x24c6c0; method-name table VA 0x3b3118
> 
> **Source**: `ev-000007` · `ev-000016` · `ev-000009` · `ev-000022`

### 3. Launches multi-vector DDoS

`T1498.001` · confidence **high** · static

It contains at least a dozen L4/L7 attack methods (ack/syn/udp/tcp/pps/dns/ssh/tcp-bypass/udp-bypass/tcp-stomp/http/http-bypass/fortnite/minecraft/discord, etc.); startAttack starts concurrent goroutines to launch volumetric denial-of-service against the target port/duration specified by the command.

> **Evidence**: l4.Ackflood@0x23a1c0, Synflood@0x23d240, Udpflood@0x23f360, Dnsflood@0x23b110, Sshflood@0x23cdb0, Tcpbypassflood@0x23da80, Udpbypassflood@0x23f770, Tcpstompflood@0x23f030; l7.Httpflood@0x23faf0, Httpbypassflood@0x240790; startAttack RVA 0x24c6c0

## Do not misjudge

:::important
The conclusions below are **easily misjudged**; take care when citing this report.

- Do not judge it as ransomware: the AES/SHA-256 constants come from the Go standard library's TLS/HTTP implementation, and no file encryption or ransomware behavior was found.
- Do not claim that this analysis actually contacted the C2: the sample is a PPC64 big-endian program that the current execution environment cannot run, cross-architecture emulation failed at runtime initialization, and the C2/port were recovered only from static configuration.
- Do not classify it as a Mirai-style Telnet/SSH worm: no Telnet/SSH brute-force or scanning propagation code was found, and the SSH flood is only one DDoS method.
- Do not treat the miner as its only function: DDoS and persistence are the main body, and mining is an added capability.
:::

## Analysis method and limitations

| Item | Value |
|:--|:--|

**Limitations and pending verification**

1. The sample is a PPC64 big-endian ELF while the current hardened Linux execution environment is x86_64 and cannot load it directly; cross-architecture user-mode emulation exited during Go runtime initialization (exit 2) because it could not retain page-table summary memory, and no real network connections, file writes, or process behavior were obtained.
2. The C2 23[.]247[.]168[.]32:1337 and configuration come from static parsing of the .data string header, and no actual session was observed; pending_dynamic_verify=true.
3. The miner's pool, wallet, and other runtime parameters are delivered by C2 commands at runtime and cannot be determined statically.
4. The method-name table is stored with an 8-byte endian-swapped constant; the readable method family has been recovered, but the complete command syntax and field order still need dynamic verification.
5. Stage-2 payloads such as xmrig-ppc64 were not recovered, so their hashes and secondary behavior are unknown.
