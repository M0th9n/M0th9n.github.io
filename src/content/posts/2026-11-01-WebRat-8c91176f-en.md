> The sample is a 32-bit Windows RAT/stealer written in Go 1.24. Its code covers remote shell, screen/camera/microphone streaming, keylogging, SOCKS5 tunneling, LSASS/DPAPI credential theft, and browser/wallet data theft. When actually executed in the dynamic sandbox it continuously resolved TON DNS C2 domains and connected to sa1atik[.]cn; in memory, PowerShell scripts were recovered that add Defender exclusions, disable system restore, and download 7z/FFmpeg/RDP components.

## Behavior analysis

**11** behaviors in total, each backed by evidence: **6** are obtainable statically and **5** were obtained through dynamic analysis.

### 1. C2 resolution via TON domains

`T1102` · Confidence **High** · Dynamic

Resolves the TON DNS records of remoteadministratortool.ton and webratxaye1.ton through tonapi[.]io and the toncenter API, using on-chain records as a C2 endpoint discovery channel that evades traditional domain blocking.

> **Evidence**: main.tryTonResolve @0x8dfb60 / main.tonResolve @0x8dfd70; at runtime GET /v2/dns/remoteadministratortool.ton/resolve and POST runGetMethod(dnsresolve, webratxaye1.ton)
> 
> **Source**: `ev-000036` · `call_bc9853f763a94d7494aea76b`

### 2. Beacons to the C2 domain sa1atik

`T1071.001` · Confidence **High** · Dynamic

At runtime it repeatedly issues HTTP GET /sa1at/ to sa1atik[.]cn:443 (about once every 15 seconds, 12 times in total) with an 88-byte request body, consistent with an online/heartbeat protocol.

> **Evidence**: network monitoring recorded: PID 3260 TCP 443 -> sa1atik[.]cn, GET /sa1at/, Content-Type: application/octet-stream
> 
> **Source**: `ev-000036`

### 3. Run key autostart

`T1547.001` · Confidence **Medium** · Dynamic

Writes a startup entry under SOFTWARE\Microsoft\Windows\CurrentVersion\Run to launch itself at logon.

> **Evidence**: memory strings SOFTWARE\Microsoft\Windows\CurrentVersion\Run; main.staticinstall/newTask installation logic
> 
> **Source**: `ev-000036` · `call_bc9853f763a94d7494aea76b`

### 4. Adds Defender exclusions

`T1562.001` · Confidence **High** · Dynamic

Runs PowerShell to call Add-MpPreference -ExclusionPath, adding Program Files, AppData, and LocalAppData to the Defender exclusion list.

> **Evidence**: PowerShell script in memory: Add-MpPreference -ExclusionPath $ProgramFiles/$AppData/$LocalAppData
> 
> **Source**: `ev-000036`

### 5. Disables system recovery

## Do not misjudge

:::important
The following conclusions are **easy to misjudge**; keep this in mind when citing this report.

- Do not report it as ransomware/a wiper: the sample has no file-encryption or ransom-note logic; reagentc /disable is defense evasion that reduces recoverability, not data destruction.
- Do not report it as a pure dropper/loader: the program itself is a full RAT plus stealer; the downloaded components only support auxiliary functions (packing, RDP, audio/video).
- Do not claim credentials/browser data were successfully exfiltrated: within the dynamic window only C2 resolution and connection attempts were observed, with no completed upload or returned data content.
- Do not provide a real C2 IP or port resolved from the TON DNS records: the sandbox has no internet access, so no resolution response was obtained.
- Do not use Trojan/Generic as the family name: the sample carries the WEBR mutex and webrat1 infrastructure identifiers.
:::

## Analysis method and limitations

| Item | Content |
|:--|:--|

**Limitations and open questions**

1. The sandbox has no real internet access, so the content of the TON DNS records and the resolved real C2 endpoints were not obtained; only resolution requests were seen for remoteadministratortool.ton / webratxaye1.ton.
2. For sa1atik[.]cn only the GET /sa1at/ request was observed; no response body was obtained, so whether it is the primary C2 or a backup/telemetry endpoint cannot be confirmed.
3. No actual data exfiltration, keystroke content, or screenshot files were observed; the related capabilities come from code paths and embedded strings.
4. The install path %ProgramFiles%\bibawinv.exe, the Run key value name, and persistence details other than the mutex are inferred from runtime strings and were not confirmed item by item in the registry.
5. The family name WebRat is based on self-identification (WEBR, webrat1, webratxaye1.ton) and lacks vendor/YARA cross-validation.
6. The Go binary is large and its strings are highly aggregated; some configuration strings are not visible in the static file and require runtime memory forensics.
