> **判定：恶意** · 家族 **未定名的多阶段 .NET RAT 加载器**（存疑） · 置信度 **低**
> 
> 外层文件是带脚本注释的 WinRAR 自解压包：配置 Silent=1、Overwrite=1、Path="C:/Windows/system32/"、Setup=<随机名>.vbe，内嵌批处理与一个 1.4MB 的 .NET 程序。解码后的 VBE 会休眠 4 秒后在隐藏窗口启动批处理，批处理再执行 system32 下的 comproviderReview.exe。该 .NET 程序类型名与方法名全部随机化，引用 CodeDom 动态编译、AES 解密两个内嵌资源并在内存中加载代码，同时具备截屏、键鼠操作与主机信息枚举相关 API。投放链与载荷结构均指向可执行任意后续载荷的 RAT/加载器，且刻意隐藏执行、写入系统目录，恶意意图明确。沙箱中实际运行到 .NET 载荷进程，但未观察到外联会话，故 C2 未能取证。

## 行为分析

共 **9** 条行为，每条都挂了证据；其中 **8** 条静态可得、**1** 条经动态分析取得。

### 1. 静默解压释放三文件

`T1204.002` · 置信度 **高** · 静态

SFX 注释配置为 Silent=1、Overwrite=1、Path="C:/Windows/system32/"，Setup 指向随机名 .vbe；包内依次存放 oU2JQ0XXU1.bat（43 字节）、comproviderReview.exe（1433600 字节）与 k8Z40kEU49sFweC4Y70Rd9DDUG0.vbe（203 字节）。

> **证据**：RAR5 CMT 起始 off=0x4d431；文件头分别在 0x4d492 / 0x4d4ec / 0x1ab528
> 
> **来源**：`ref:1081b84a1b` · `ref:8267ab5005`

### 2. 解码 VBE 后隐藏启动

`T1059.005` · 置信度 **高** · 静态

VBE 解码后为 178 字符脚本：创建 WScript[.]Shell、Sleep(4000)，再以窗口模式 0 执行 C:/Windows/system32/oU2JQ0XXU1.bat。

> **证据**：k8Z40kEU49sFweC4Y70Rd9DDUG0.vbe off=0x1ab568，解码结果见证据
> 
> **来源**：`ref:79159c2dd6`

### 3. 批处理拉起主载荷

`T1059.003` · 置信度 **高** · 静态

BAT 内容仅一行："C:\Windows\system32\comproviderReview.exe"，负责启动 .NET 主程序。

> **证据**：oU2JQ0XXU1.bat off=0x4d4c1，43 字节
> 
> **来源**：`ref:688bd1d784`

### 4. AES 解密内嵌资源

`T1140` · 置信度 **高** · 静态

.NET 方法 pHLvs1RJSZ 用硬编码 32 字节 Key 与 16 字节 IV 设置 SymmetricAlgorithm，再以 CryptoStream 解密传入字节流；程序引用 GetManifestResourceStream 读取两个内嵌资源。

> **证据**：MethodDef#4556 (rva 0x7f964) 调用 set_Key/set_IV/CreateDecryptor；字段数据 off=0x160f3d / 0x160f5d
> 
> **来源**：`ref:c1bc85a697` · `ref:6456d47ecb`

### 5. CodeDom 动态编译代码

`T1620` · 置信度 **中** · 静态

程序引用 System.CodeDom.Compiler.CodeDomProvider.CompileAssemblyFromSource 与 CompilerParameters，可在运行时编译程序集并加载，属于反射式代码加载路径。

> **证据**：MemberRef#271 CompileAssemblyFromSource；MethodDef#3064 rva 0x52028

> **来源**：`ref:e66d4ff1b1` · `ref:8eca54777a`
