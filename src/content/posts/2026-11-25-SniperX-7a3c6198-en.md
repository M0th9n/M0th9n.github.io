> The sample ran for real in an isolated dynamic sandbox: after startup it first resolves the C2 domain serversniperxx[.]duckdns[.]org, then periodically sends a check-in packet starting with 0xADDE over TCP/4577, containing the computer name, user name, Windows version, architecture, antivirus name and current process path; the domain and the mutex name SniperX_4577 appear together in process memory. Static and memory evidence further shows full remote-control capability including an HVNC hidden desktop, browser credential/cookie/history theft, keyboard and clipboard logging, screen/microphone capture, remote shell, process injection and startup persistence; it is judged a malicious RAT/stealer with high confidence.

## Behavior Analysis

There are **10** behaviors in total, each backed by evidence; **8** are statically available and **2** were obtained through dynamic analysis.

### 1. Check in to C2 and send host fingerprint

`T1071.001` · Confidence **high** · Dynamic

After running, it resolves serversniperxx[.]duckdns[.]org and connects to TCP/4577, sending a check-in packet starting with 0xADDE; the packet consists of fixed-length fields containing, in order, the computer name, user name, Windows version and architecture, antivirus name and current process path, and it then reconnects repeatedly at 8–40 second intervals.

> **Evidence**: dynamic network log: DNS request for serversniperxx[.]duckdns[.]org followed by a connection to 4577/TCP; check-in packet at 0x000 is AD DE 02 00 10 02 00 00, 0x08 is DESKTOP-7QK4M2P-6431AF93, 0x88 is analyst, 0xC8 is Windows 10 Pro (64-bit, Build 19045), 0x120 is Windows Defender, and from 0x150 is CP1251 text "installed: C:\Windows\System32\WindowsPowerShell\v1.0\powershell.EXE".
> 
> **Source**: `ref:7a7a8c0364` · `ref:042a92ff7a` · `ref:b3fcd0f101`

### 2. Collect hardware and system information

`T1082` · Confidence **high** · Static

Through the registry, GetSystemInfo/GetAdaptersInfo and WMI queries it collects fingerprints such as CPU, GPU, memory, MAC, disk serial number, font count, screen resolution/color depth, time zone, language and installed antivirus, and generates an hwid for check-in.

> **Evidence**: strings off 0x14A3B8–0x14A7E0: os_name/cpu_name/cpu_id/gpu_name/ram_gb/mac_address/disk_serial/hwid/screen_width/screen_height/timezone/fonts; WMI queries ROOT\SecurityCenter2 + SELECT displayName FROM AntiVirusProduct (UTF-16 off 0x1491D0/0x149200), ROOT\CIMV2 + SELECT * FROM %s.
> 
> **Source**: `ref:b216c963c8` · `ref:e7d1fbf6bb`

### 3. Steal browser credentials and cookies

`T1555.003` · Confidence **high** · Static

It enumerates the user data directories of Chromium-based browsers such as Chrome, Edge, Brave, Opera/Opera GX, Vivaldi and Yandex, as well as Firefox, and copies databases such as Login Data, Cookies, History and Web Data; it uses SQL to read logins/cookies/history and calls CryptUnprotectData, NCryptDecrypt and decryption logic for Chrome app_bound_encrypted_key/Google Chromekey1 to recover plaintext.

> **Evidence**: strings off 0x149DB8 "SELECT origin_url, username_value, password_value FROM logins"; off 0x149E10 cookies query; off 0x149B10/0x149B60/0x149BB0 are the Chromium app-bound key and Chrome key service; off 0x149A90 "Microsoft Software Key Storage Provider", 0x149A20 ChainingModeGCM; imports CryptUnprotectData, NCryptOpenKey/NCryptDecrypt, BCryptDecrypt.
> 
> **Source**: `ref:b216c963c8` · `ref:93697f78dc`

### 4. Log keystrokes and clipboard

`T1056.001` · Confidence **high** · Static

It installs keyboard-monitoring logic, translating keys with GetAsyncKeyState/GetKeyState, ToUnicodeEx and keyboard layouts, captures window titles and clipboard content, and writes per-session keylog_YYYYMMDD_HHMMSS.txt logs under C:\ProgramData\SniperLogs.

> **Evidence**: strings off 0x1497B8 "\SniperLogs", 0x1497C8 "C:\ProgramData\SniperLogs", 0x1497E8 keylog_%04d%02d%02d_%02d%02d%02d.txt, 0x149818 SESSION START, 0x149872 ">>> CLIPBOARD:", 0x14968C–0x1497A8 key-name table; imports GetAsyncKeyState/ToUnicodeEx/GetClipboardData/OpenClipboard.
> 
> **Source**: `ref:b216c963c8` · `ref:93697f78dc`

### 5. HVNC hidden-desktop remote control

`T1055` · Confidence **high** · Static

It creates and switches to a hidden desktop via CreateDesktopW/OpenInputDesktop/SetThreadDesktop, captures the screen with PrintWindow, BitBlt, D3D11 and GDI+ and replays mouse and keyboard; it loads modules\hvnc_injection.dll (reading from an embedded PE resource when the file is missing), locates ReflectiveLoader and reflectively injects into a browser or host process, clones the browser profile and starts it with --no-sandbox --user-data-dir, achieving seamless remote browsing.

> **Evidence**: strings off 0x14AB98 hvnc_debug.log, 0x14ABE8 modules\hvnc_injection.dll, 0x14AC88 ReflectiveLoader, 0x14AD38/0x14ADA0 VirtualAllocEx/CreateRemoteThread, 0x14AE76 Local\hvnc_rdi_, 0x14B788 injected launch; embedded RCDATA resource (off 0x1C7718, 156160 bytes) contains ReflectiveLoader and HVNCInjection.x64.dll markers; imports CreateDesktopW/PrintWindow/D3D11CreateDevice/Gdip*.
> 
> **Source**: `ref:93f2083157` · `ref:b216c963c8` · `ref:93697f78dc`

### 6. Create a mutex to prevent duplicate runs

> **Evidence**: process memory dump at offset 0xE820 contains "SniperX_4577"; the static format string SniperX_%d is at file offset 0x14C1D8; imports CreateMutexW/CreateMutexA.

> **Evidence**: strings off 0x14A1F0/0x14A240 two powershell -WindowStyle Hidden -Command "Add-MpPreference -ExclusionPath/ExclusionProcess '"; off 0x14C140 Internet Settings, 0x14C180 ProxyEnable, 0x14C190 127.0.0[.]1:1, 0x14C1A0 ProxyServer; imports RegSetValueExA, SetTcpEntry, GetExtendedTcpTable.

### 9. Execute remote commands and control processes

`T1059.003` · Confidence **high** · Static

It executes commands sent by the server via cmd.exe /Q with anonymous pipes and collects their output, and also supports enumerating/terminating processes, suspending and resuming processes, locking the workstation, swapping mouse buttons, replacing the system cursor and changing display settings, forming a complete remote-control surface.

> **Evidence**: strings off 0x14A1B8 "cmd.exe /Q", 0x14BFD0 port-status JSON, 0x14C040 process-termination prompt; imports CreateProcessW/CreatePipe/PeekNamedPipe, TerminateProcess/OpenProcess, NtSuspendProcess/NtResumeProcess, LockWorkStation/BlockInput/SetSystemCursor/SwapMouseButton.

`T1055.012` · Confidence **high** · Static

## Do Not Misjudge

:::important
The following conclusions are **easy to misjudge**; please note them when citing this report.

- Do not judge it as ransomware or an encryptor merely from cryptographic APIs such as BCrypt AES-GCM/CryptUnprotectData; these calls are used to decrypt browser keys/configuration.
- Do not assert that this run exfiltrated browser credentials or keylogs: only the check-in packet was observed, and no file upload or credential data packet was seen.
- Do not assert that Defender protection was successfully disabled merely from the Add-MpPreference strings: the Defender exclusion list was still empty in system telemetry.
- Do not treat 192[.]0[.]2[.]123 in the dynamic sandbox as a real C2 IP: that address is the isolated-network redirection address, and the real IP was not obtained.
- Do not claim that this run completed startup-entry dropping or HVNC/injection: no Startup file was observed, and memory scanning found no suspicious injected module in the sample process.
:::

**Limitations and pending verification**

1. The simulated server in the isolated network only recorded the check-in packet sent by the sample and returned no response, so the server session, command set and follow-on payload cannot be verified; the C2 is therefore treated as not fully verified (static + pending_dynamic_verify).
2. No startup-entry file, Defender exclusion, HVNC injection or browser data theft was observed on disk; these capabilities are proven by strings, the import table and in-memory modules/configuration, which counts as static evidence.
3. The real C2 IP is masked by the isolated-network redirection and was not obtained; the domain serversniperxx[.]duckdns[.]org is confirmed by both runtime memory and DNS records, as plaintext decrypted at runtime.
4. System telemetry covers only services, certificates, Defender configuration and Run keys, not a full file/registry diff, so the proxy-setting and startup-entry writes were not dynamically confirmed.
5. "Evolution RAT/Overlord-Server" comes from the PDB path of the embedded HVNC module and may be upstream component reuse; the main program's family name rests mainly on SniperX evidence, and external intelligence review is still recommended.
