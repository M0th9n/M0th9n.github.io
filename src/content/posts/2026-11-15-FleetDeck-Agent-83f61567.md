## 行为分析

共 **8** 条行为，每条都挂了证据；其中 **3** 条静态可得、**5** 条经动态分析取得。

### 1. 安装内嵌 MSI

`T1218.007` · 置信度 **高** · 动态

安装器释放内嵌 MSI 并调用 msiexec 安装，msiexec 创建 C:\Program Files (x86)\FleetDeck Agent\fleetdeck_agent_svc.exe 并写入卸载项注册表。

> **证据**：动态：msiexec.exe 进程创建 + File created: C:\Program Files (x86)\FleetDeck Agent\fleetdeck_agent_svc.exe；静态：0x1b9460 处内嵌 MSI、0x1be460 处 #agent_svc.cab
> 
> **来源**：`ev-000034` · `ev-000030` · `ref:7834e20d29`

### 2. 注册自启服务

`T1543.003` · 置信度 **高** · 动态

MSI 创建服务 FleetDeck Agent Service，ImagePath 指向落地 agent，Start=2 自动启动，账户 LocalSystem（系统权限常驻）。

> **证据**：系统遥测 Event 7045 / 服务表：FleetDeck Agent Service, LocalSystem, Start=2；注册表 HKLM\System\CurrentControlSet\Services\FleetDeck Agent Service\ImagePath 与 Start 写入
> 
> **来源**：`ev-000030` · `ev-000034` · `ref:7834e20d29`

### 3. 启动并回连更新端

`T1071.001` · 置信度 **高** · 动态

服务以 -deploymentID b66c6e71-8ec2-49d4-915e-a8c910128585 -askForName=0 启动，持续解析 agentupdate[.]fleetdeck[.]io 并向 443/TCP 发起连接；未捕获完整 HTTP/TLS 请求响应。

> **证据**：动态：fleetdeck_agent_svc.exe pid 7824 多次 DNS 查询 agentupdate[.]fleetdeck[.]io，TCP 192.0.2[.]123:443 连接；命令行含 deploymentID
> 
> **来源**：`ev-000030` · `ev-000033` · `ref:7834e20d29`

### 4. 使用 DNS-over-TLS

`T1071.004` · 置信度 **高** · 动态

agent 内置 robustdns/miekg-dns，启动后向 1.1.1[.]1、8.8.8[.]8、9.9.9[.]9 的 853/TCP 发起 DNS-over-TLS 连接，绕过本地明文 DNS 观测。

> **证据**：动态：TCP 1.1.1[.]1:853、8.8.8[.]8:853、9.9.9[.]9:853 多次连接；静态：fleetdeck[.]io/prototype3/go-libs/robustdns、github[.]com/miekg/dns
> 
> **来源**：`ev-000030` · `ev-000033` · `ref:7834e20d29`

### 5. 生成防火墙放行规则

`T1562.004` · 置信度 **高** · 动态

安装/服务启动阶段以 PowerShell 执行 New-NetFirewallRule；agent 内实现 AddFirewallRule/UpdateFirewallRule/Remove-NetFirewallRule，用于放行/隐藏管理通道。

> **证据**：动态：C:\Windows\Sysnative\WindowsPowerShell\v1.0\powershell.exe -Command "New-NetFirewallRule…"（2 次）；静态：agent 0x36ef01 "Remove-NetFirewallRule -Name '%s'" 及 svcutil.AddFirewallRule
> 
> **来源**：`ev-000030` · `ev-000033` · `ref:7834e20d29`

### 6. 保留安全模式例外

`T1562.009` · 置信度 **中** · 静态

agent 含将自身加入安全模式启动例外的逻辑（Added safe boot exception），使服务在安全模式下仍可启动；本次未观察到该写入实际执行。

> **证据**：静态：agent 文件偏移 0x36ee1a 字符串 "Added safe boot exception for: %v"
> 
> **来源**：`ev-000033`

### 7. 内嵌远程会话控制

`T1134` · 置信度 **中** · 静态

agent 含 WTS 会话枚举、令牌复制/设置（nativeWTSEnumerateSessions、nativeDuplicateTokenEx、nativeSetTokenInformation、sendSAS）、PowerShell 调用与强杀进程逻辑，可进入交互桌面执行远程操作；本次未观察到远程指令下发。

> **证据**：静态：agent 符号 svcutil.nativeWTSEnumerateSessions/nativeDuplicateTokenEx/nativeSetTokenInformation，字符串 0x372ce2 "Forcibly terminating process with PID: %v"；动态仅有服务自身运行
> 
> **来源**：`ev-000033`

### 8. 自更新替换服务

`T1105` · 置信度 **中** · 静态

updater 从 agentupdate[.]fleetdeck[.]io 获取版本信息与更新包，解压后通过 ReplaceSvcExe/RestartSvc 替换自身并重启；含可执行文件完整性校验。

> **证据**：静态：模块 fleetdeck[.]io/prototype3/go-libs/updater（request/loadLatestVersion/unzip/Update/AsyncUpdate）、svcutil.ReplaceSvcExe/RestartSvc、0x374370 "Could not validate agent executable integrity"

> **来源**：`ev-000033` · `ev-000030`
