> [!WARNING]
> **Verdict: Malicious** · Family **Unidentified Rust loader (with appended encrypted payload)** (uncertain) · Confidence **low**
> 
> The sample is a 7.98 MB 64-bit Rust/PE program whose static import table contains only ntdll!NtDelayExecution, yet during a real sandbox run it dynamically loaded wininet/winhttp/ws2_32/urlmon along with network and cryptographic components such as dpapi/mskeyprotect/rsaenh/ncrypt, and initiated TCP connection attempts to ports 443/80 without any domain resolution; its Authenticode signer is a Take-Two Interactive/Rockstar Games code-signing certificate issued in 2011 and expired since 2013, and after the signature block 4,456,448 bytes of unsigned encrypted data with entropy 7.99997 are appended. Static self-evidence and real-run observations corroborate each other, no legitimate software requires such a combination, and it is judged to be a malicious loader/implant.

## Behavior analysis

**7** behaviors in total, each backed by evidence; **4** are statically available and **3** were obtained through dynamic analysis.

### 1. Dynamically loads network libraries at runtime

`T1027` · Confidence **high** · dynamic

The static import table contains only ntdll!NtDelayExecution, but after the process runs the in-memory module list contains network components such as wininet.dll, winhttp.dll, ws2_32.dll, urlmon.dll, webio.dll and mswsock.dll, indicating that these APIs are resolved/loaded by the program itself at runtime rather than provided by the PE import table.

> **Evidence**: pe_imports contains only ntdll!NtDelayExecution (IAT 0x140329E00); the in-memory module list contains wininet/winhttp/ws2_32/urlmon/webio
> 
> **Source**: `ref:18e74332bf` · `ref:0d1e4d4acc`

### 2. Entry delays via IAT call

`T1497.003` · Confidence **high** · static

The obfuscated trampoline at entry point 0x1400012E0 calls the imported NtDelayExecution at 0x1400013A8 via call qword ptr [rip+0x328c62] (i.e. [0x140329E00]), providing sleep/delay-based anti-analysis capability.

> **Evidence**: 0x1400013A8 call qword ptr [0x140329E00] → IAT rva 0x329E00 = NtDelayExecution
> 
> **Source**: `ref:64dceb7fa7` · `ref:18e74332bf`

### 3. Appended encrypted payload

`T1027.009` · Confidence **high** · static

The Authenticode signature block ends at file offset 3,520,928, after which 4,456,448 bytes (0x440000) of data are appended with byte entropy 7.99997, a fully random distribution, and outside the signature's coverage; this region is highly likely an encrypted second-stage payload or configuration container.

> **Evidence**: from off 0x35BD60, 4,456,448 bytes, entropy 7.99997; signature block length 3,488
> 
> **Source**: `ref:8b13ad0334` · `ref:71b7436fde`

### 4. Abuses expired game-vendor certificate

`T1553.002` · Confidence **high** · static

The file embeds a code-signing certificate whose subject is Take-Two Interactive Software, Inc. / Rockstar Games (VeriSign Class 3 Code Signing 2010 CA), valid from 2011-09-21 to 2013-09-20. The certificate has been expired for many years and matches the profile of a leaked code-signing certificate long abused in the wild to lower the suspicion of security products and users.

> **Evidence**: SECURITY directory rva 0x35AC00 length 0xDA0; certificate Subject CN=Take-Two Interactive Software, Inc., OU=Rockstar Games; NotAfter=130920235959Z
> 
> **Source**: `ref:a44bdeaf5e` · `ref:b623e2d885`

### 5. Encoded data and strings

`T1027.013` · Confidence **high** · static

The tail of .rdata and .data each present a restricted-symbol-table encoding stream (.data has only 84 distinct values with near-uniform frequency, entropy 5.605), and readable ASCII/UTF-16 business strings are almost absent; combined with the single import, this matches the practice of decrypting strings and configuration at runtime to evade static string searches.

> **Evidence**: .data from off 0x342A80, 92,672 bytes with only 84 distinct byte values; the .rdata tail is likewise an unconventional encoding stream
> 
> **Source**: `ref:0cb9a5f5cf` · `ref:5e0bd8a58a`

### 6. Hard-coded IP outbound attempts

`T1095` · Confidence **medium** · dynamic

At runtime the process initiated TCP connection attempts to remote port 443, then to ports 80 and 443; network monitoring shows no domain-resolution requests for this process at all, suggesting the target is a hard-coded IP. No complete HTTP request line, Host header or response was captured, and no session was established.

> **Evidence**: network monitoring: 86b1543...exe (6816) requested TCP :443 (01:31:02), TCP :80 and :443 (01:31:08), with no DNS requests from this process throughout
> 
> **Source**: `ref:75a20aa801` · `ref:3860ac66c9`

### 7. Loads DPAPI and CNG components

`T1555` · Confidence **medium** · dynamic

At runtime the in-memory module list shows dpapi.dll, mskeyprotect.dll, rsaenh.dll, bcrypt.dll, ncrypt.dll, crypt32.dll, cryptnet.dll, wintrust.dll and others, indicating the program has the ability to call the system data protection (DPAPI) and CNG/RSA crypto interfaces; no actual reads of credential stores were observed in this run.

> **Evidence**: module list: dpapi.dll 0x7ffc85550000, mskeyprotect.dll 0x7ffc64dd0000, rsaenh.dll 0x7ffc84830000, ncrypt.dll 0x7ffc85210000
>

## Must not be misjudged

:::important
The following conclusions are **easy to misjudge**; keep them in mind when citing this report.

- Do not assert that the sample belongs to Winnti/APT41 or any named family: the certificate is a leaked certificate expired since 2013, which only proves the signing material was abused and cannot be used as attribution evidence.
- Do not assert that the sample is officially related to Take-Two/Rockstar or that the signature is still valid: the appended data lies after the signature block and is not protected by the signature, and the certificate expired many years before the sample was compiled.
- Do not assert that outbound communication, downloading or credential theft was completed: dynamically only TCP connection attempts were seen, with no complete session, no child processes, no dropped files and no plaintext configuration.
- Do not assert persistence capability: no registry autostart, service or scheduled-task writes were observed.
- Do not assert that it is an information stealer merely because it loads DPAPI/CNG components: no actual access to browser databases, wallets or credential files was observed in this run.
:::

**Limitations and pending verification**

1. The 4,456,448 bytes appended after the signature block have entropy 7.99997 and were not decrypted in this analysis, so the C2 address, port, protocol and configuration keys were not recovered; c2/config/host_iocs are left empty rather than guessed.
2. Network monitoring recorded only TCP connection attempts (443/80), no complete request/response was captured, and the network layer rewrote the target address, so the original destination IP could not be determined.
3. The dynamic run was short and the sample may not have entered its core logic due to delays/environment checks; no file writes, registry modifications or child-process creation were observed, which cannot be used to deny those capabilities.
4. Host-side raw packet captures and complete file-system/registry diffs were not obtained, so persistence and dropped-file behavior cannot be confirmed.
5. Pure CPU emulation produced no API-call records, showing that the payload depends on real system components and that the emulation results are inconclusive.
6. No usable family configuration or code-reuse traits were obtained; the family attribution is a low-confidence candidate rather than a conclusion.
