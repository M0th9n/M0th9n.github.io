> [!WARNING]
> **Verdict: Malicious** · Family **Opus** (uncertain) · Confidence **Medium**
> 
> Aliases: Salat, Salatik
> 
> The sample is a UPX-packed 64-bit Rust program. Static analysis confirms a full remote-control capability set: browser credential/session-token theft, cryptocurrency wallet collection, screen/camera/microphone capture, keylogging, WTS session-token hijacking and an RDP client, plus an embedded PowerShell script that disables Defender exclusions/UAC and system recovery. After real detonation in an isolated Windows dynamic environment, the program resolved morkovka[.]cn and sa1atik[.]cn via DoH and continuously sent RSA+AES hybrid-encrypted JSON heartbeats to hxxps://<host>/qqkb/, while querying many Ethereum/Polygon/Base/TON RPC nodes. Static capabilities and dynamic callbacks corroborate each other, so it is judged a malicious RAT/stealer.

## Behavior Analysis

**10** behaviors in total, each backed by evidence; **8** are statically available and **2** were obtained through dynamic analysis.

### 1. UPX packing and anti-debugging

`T1027.002` · Confidence **High** · Static

The outer layer is a UPX packer (UPX0/UPX1/UPX2, UPX1 entropy 8.0), with the entry point self-decrypting in a writable/executable section; the packer also contains rdtsc timing-delta, int 2Dh and cpuid anti-debug/VM-detection code.

> **Evidence**: UPX! magic @0x1FD; entry 0x63D6A0 self-decrypting stub; anti-debug rva 4146939 / 4168757 / 4177364
> 
> **Source**: `ref:81c16bf2fa` · `ref:1ddefe4e34` · `ref:0d3cb3e3a3` · `ref:be086b1139`

### 2. DoH resolution of C2 domains

`T1071.004` · Confidence **High** · Dynamic

Instead of calling system DNS directly, it sends /dns-query and /resolve queries to the DoH endpoints of 1.1.1[.]1/8.8.8[.]8 and dns[.]google to resolve morkovka[.]cn and sa1atik[.]cn, evading DNS log monitoring.

> **Evidence**: Dynamic logs: GET /dns-query?name=morkovka[.]cn&type=A and /resolve?name=sa1atik[.]cn to 1.1.1[.]1:443 / 8.8.8[.]8:443
> 
> **Source**: `ev-000023` · `ref:b4edc1689e`

### 3. HTTPS heartbeat callback to C2

`T1071.001` · Confidence **High** · Dynamic

After successful resolution it sends HTTPS POST /qqkb/ to port 443 of both C2s with Content-Type: application/json; the first packet is 473 bytes and heartbeats are 453 bytes, resent roughly every 6–18 seconds; the body uses a hybrid structure of base64(RSA block)+'.'+base64(AES ciphertext).

> **Evidence**: Dynamic logs: POST /qqkb/ Host: morkovka[.]cn/sa1atik[.]cn Content-Length 473/453; the request body begins with 344 characters of base64
> 
> **Source**: `ev-000023` · `ref:571f695c61`

### 4. Steal browser credentials

`T1555.003` · Confidence **High** · Static

Enumerates Chrome/Edge/Yandex/Gecko user directories, copies locked Cookies/Login Data databases and reads Local State and key4.db master keys, decrypting cookies, saved account passwords, autofill and login tokens, with results written to Browsers/ and Clients/ text files.

> **Evidence**: Strings src/makelog/invdump/chrome.rs, scr/subprocess.rs, get_chromium_master_keys, decrypt_chrome cookie host=; imports CryptUnprotectData, CredReadW, sqlite
> 
> **Source**: `ev-000022` · `ref:571f695c61`

### 5. Harvest wallets and IM sessions

`T1539` · Confidence **High** · Static

Contains a large list of wallet extension IDs (MetaMask/Phantom/Keplr and others) and wallet directories, packaging wallet files; also collects Discord/Steam/Roblox tokens, Telegram tdata sessions and the MAX credential vault (CredEnumerateW/CredReadW), and queries wallet balances via public-chain RPC.

> **Evidence**: Strings [discord]/[steam]/[roblox]/[max]/[crypto] zipping wallets, Clients/*.txt, TelegramDesktop tdata; dynamically seen tonapi[.]io, toncenter[.]com and dozens of Ethereum/Polygon/Base RPC queries
> 
> **Source**: `ev-000022` · `ev-000023`

### 6. Screen/audio capture and keylogging

`T1113` · Confidence **High** · Static

Captures multi-monitor frames via DXGI/desktop duplication and GDI BitBlt and encodes them as JPEG, enumerates and captures cameras with nokhwa, records the microphone with cpal/WASAPI, and sets up keylogging (including foreground window titles) with SetWindowsHookExW + GetAsyncKeyState.

> **Evidence**: Imports D3D11CreateDevice/CreateDXGIFactory1/BitBlt/GetDIBits; strings src/screen.rs, src/camera.rs, src/sound.rs, src/keytest.rs, Monitor *.jpg
> 
> **Source**: `ev-000022` · `ref:571f695c61`

### 7. Hijack sessions and steal tokens

`T1134.001` · Confidence **High** · Static

Uses WTSEnumerateSessionsExW/WTSQueryUserToken to obtain interactive session tokens; after SeTcbPrivilege/SeDebugPrivilege elevation it calls DuplicateTokenEx + SetTokenInformation to rewrite the session ID, then uses CreateProcessAsUserW/ImpersonateLoggedOnUser to launch a copy of itself in the target session, and includes an RDP client (credssp/sspi) for remote desktop takeover.

> **Evidence**: Strings sessions::launch_via_token, about_to_createprocessasuserw, rewired SYSTEM token into session, rdp_child/src/credssp/handshake.rs; imports WTSQueryUserToken/CreateProcessAsUserW/SetThreadToken
> 
> **Source**: `ev-000022` · `ref:571f695c61`

### 8. Plant persistence and elevate

`T1547.001` · Confidence **Medium** · Static

Writes autostart through the HKCU Run key, registers and starts a Windows service (OpusSvc), creates a scheduled task (OpusUpdate) via TaskScheduler COM, and uses ShellExecuteW runas/service methods to relaunch itself elevated.

> **Evidence**: Strings SOFTWARE\Microsoft\Windows\CurrentVersion\Run, CreateServiceW/StartServiceW/RegisterTaskDefinition, OpusUpdate/OpusSvc, src/install.rs, src/elevate.rs
> 
> **Source**: `ev-000022` · `ref:571f695c61`

### 9. Disable protections and UAC

`T1562.001` · Confidence **High** · Static

An embedded PowerShell script calls Add-MpPreference to add Program Files, AppData, LocalAppData and the Windows directory to Defender exclusions; runs reagentc /disable to turn off system recovery; sets the HKLM policy EnableLUA to 0 to disable UAC; and enables WTS child sessions to facilitate session hijacking.

> **Evidence**: A 2498-byte base64 blob at file offset 0x4AE638 decodes to the script; it contains Add-MpPreference -ExclusionPath, reagentc /disable, Set-ItemProperty ... EnableLUA 0, WTSEnableChildSessions($true)
> 
> **Source**: `ev-000022`

### 10. Remote commands and file management

`T1059.001` · Confidence **High** · Static

Accepts remote instructions to execute cmd.exe/PowerShell scripts (opus-runscript/runscript), provides file upload/download, directory browsing, task manager, process and window enumeration, and includes SOCKS5/port forwarding and a p2p tunnel (p2_host|p2_port|key configuration) as an intranet proxy.

> **Evidence**: Strings opus-runscript, cmd.exe, UploadUrl payload (expected '<url>\n<dest>'), startPortForward, socks5 read timed out, src/tunnel.rs/src/proxy.rs/src/filemanager.rs
> 
> **Source**: `ev-000022` · `ref:571f695c61`

## What Not to Misjudge

:::important
The following conclusions are **easy to misjudge**; keep them in mind when citing this report.

- Do not classify it as ransomware/wiper: no user-file encryption, mass deletion or ransom note was found; the only destructive actions are disabling system recovery (reagentc /disable), UAC and Defender exclusions.
- Do not claim a service, scheduled task or Run key was successfully written: these are inferred only from strings and API imports, and no registry/service/scheduled-task telemetry was obtained in this dynamic run.
- Do not treat tonapi[.]io, toncenter[.]com or the Ethereum/Polygon/Base RPC domains as C2: they are public blockchain nodes used for wallet balance/asset queries; the actual callback endpoints are morkovka[.]cn and sa1atik[.]cn.
- Do not classify it as a stealer only: besides credential theft it has remote-control, RDP takeover, keyboard/mouse/camera/microphone control and intranet-proxy capabilities.
- Do not claim administrator/SYSTEM privileges or completed elevation: the dynamic run was only as a normal user, and no elevation chain or child process was observed.
:::

## Analysis Method and Limitations

| Item | Content |
|:--|:--|
| Analysis method | Dynamic sandbox analysis + static decompilation |
| Unpacking | Yes (stage2 `730f4ae80cf7b0ce69d50decbf835a54771881c75f4427f275ce6d580b43c6a9`) |

**Limitations and pending verification**

1. Dynamically only a single sample process was observed; no child processes, service/scheduled-task creation or elevation behavior was captured. Those entries are static inferences from strings and imported APIs, so their confidence was lowered.
2. Callback responses were returned by the isolated environment's network emulation component; no real panel-issued commands were obtained, so the full command set and second-stage payload cannot be confirmed.
3. The transmit key and HWID/machine-fingerprint reporting fields in the configuration were not decrypted from the encrypted messages; the encryption algorithm is inferred from dependency libraries and message structure.
4. The UPX static unpacked image and the process memory dump differ in hash (runtime self-check/relocation), and the plaintext configuration was not recovered from the memory image.
5. Registry/service/certificate/AMSI telemetry for this run was not read, so "UAC/Defender disabled" is confirmed only as embedded in the script, not as actually executed successfully.
6. The C2 domains were observed only through DoH and a spoofed HTTPS endpoint inside the isolated fake network; no real external network access was performed.
