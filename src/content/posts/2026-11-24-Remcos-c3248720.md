## 行为分析

共 **11** 条行为，每条都挂了证据，且全部静态可得。

### 1. 释放并启动PS脚本

`T1059.005` · 置信度 **高** · 静态

VBScript 以 Scripting.FileSystemObject 在 C:\Temp\ 下创建随机名 .ps1，写入 Base64 载荷后再用 WScript.Shell.Run 执行 'powershell.exe -nop -ep bypass -file <脚本>'，隐藏窗口同步等待。

> **证据**：vbe 文件偏移 0x9e 起 'Const TEMP_DIR = "C:\Temp\"'、0xe0 起 'PS_LAUNCH_CMD = "powershell.exe -nop -ep bypass -file """'；Main 内 pipeline=PrepareDirectory/DecodeAndWrite/Invoke/RemoveArtifacts
> 
> **来源**：`ref:d11b726046` · `ev-000012`

### 2. 分层解密释放载荷

`T1140` · 置信度 **高** · 静态

首个 PowerShell 脚本内置 Base64 的 GZip 容器与 32 字节 AES 密钥/16 字节 IV，先以 SHA-256 校验完整性，再 GZip 解压、AES-256-CBC/PKCS7 解密为第二段脚本，并以 [ScriptBlock]::Create + '&' 在内存中执行。

> **证据**：payload.ps1 头部注释 'Base64 -> GZip -> AES-CBC/PKCS7 -> ScriptBlock'；$B64_Key=9a1ce8ab...、$B64_IV=5d046180...；函数 Test-HashMatches/Expand-GZipBytes/Invoke-AesDecrypt
> 
> **来源**：`ev-000012` · `ref:d11b726046`

### 3. XOR还原内层程序集

`T1027` · 置信度 **高** · 静态

第二段脚本对内置的 $encodedFragment 先 Base64 解码，再用 13 字节密钥 'WWaDazKR6@@^^' 做重复密钥 XOR，结果再次 Base64 解码得到 .NET 程序集并以反射方式加载。

> **证据**：stage2.ps1 内 ConvertFrom-MaskedBlob 的循环 $plainBytes[$pos] = $rawBytes[$pos] -bxor $keyStream[$pos % $keyLen]；$xorKey = "WWaDazKR6@@^^"
> 
> **来源**：`ev-000012`

### 4. 反射加载.NET载荷

`T1620` · 置信度 **高** · 静态

第二段脚本调用 [Reflection.Assembly]::Load 加载解密出的 .NET 程序集，反射取类型 MACHINEE.WHORE 的静态方法 LAUNCHER，并以宿主路径与内嵌 PE 字节数组为参数 Invoke。

> **证据**：stage2.ps1 内 -TypeName 'MACHINEE.WHORE' -MethodName 'LAUNCHER'；程序集内可见 'MACHINEE.dll'、'LAUNCHER'、'targetPath'、'shellcode' 等元数据名
> 
> **来源**：`ev-000012` · `ref:6fbf0990be`

### 5. 注入aspnet_compiler进程

`T1055.012` · 置信度 **中** · 静态

LAUNCHER 以内嵌的合法 .NET 工具 C:\Windows\Microsoft.NET\Framework\v4.0.30319\aspnet_compiler.exe 为宿主，运行时通过 LoadLibraryA/GetProcAddress 解析 kernel32 注入相关 API，结合 CreateProcess(挂起)、VirtualAlloc、WriteProcessMemory、ReadProcessMemory、OpenProcess 与线程恢复完成远程进程注入，注入体为 537600 字节内嵌 PE。

> **证据**：stage2.ps1 内 $hostExe='C:\Windows\Microsoft.NET\Framework\v4.0.30319\aspnet_compiler.exe'；.NET 程序集字符串偏移 0xb2d8 LoadLibrary / 0xb2fa WriteProcessMemory / 0xb318 ReadProcessMemory / 0xb340 OpenProcess / 0xb0f0 VirtualAlloc / 0xb0be VirtualProtect，及 CreateProcess 参数名 applicationName/commandLine/startupInfo/processInformation
> 
> **来源**：`ev-000012` · `ev-000003` · `ref:e75011c19b`

### 6. 看守进程重启载荷

`T1057` · 置信度 **高** · 静态

Start-WatchLoop 每 5 秒检查名为 aspnet_compiler 的进程是否存在，缺席时重新执行注入并循环，形成对宿主进程的看守与自愈。

> **证据**：stage2.ps1 Start-WatchLoop：$Sentinel="aspnet_compiler"、$IntervalSeconds=5、Test-ProcessAbsent 后再次 Invoke-InMemoryAssembly
> 
> **来源**：`ev-000012`

### 7. 植入Remcos远控

`T1219` · 置信度 **高** · 静态

被注入的 537600 字节 PE 为 32 位 Delphi GUI 程序，字符串明确标识 Remcos v7.3.1 Pro (BreakingSecurity)，具备 GUI 消息循环、托盘与远程控制组件。

> **证据**：内嵌 PE 文件偏移 0x7583e 'Remcos v'、0x7584b ' BreakingSecurity.net'、0x75908 'Remcos'、0x7070c '7.3.1 Pro'；PE 结构 5 节、GUI 子系统、0 异常

> **来源**：`ev-000013` · `ref:7f131d8c35`

### 8. 窃取浏览器凭据

`T1555.003` · 置信度 **高** · 静态

> **证据**：内嵌 PE 文件偏移 0x6fcb4 '\Login Data'、0x6fce0 '\Network\Cookies'、0x6ffb0 '\logins.json'、0x6ffcc '\key3.db'、0x70024 '\cookies.sqlite'；0x6fda4/0x6fde0/0x6fe20/0x6fe78/0x6fec0/0x6ff54 各浏览器 User Data 路径
> 
> **来源**：`ev-000013` · `ref:87a320123d`

### 9. 键盘记录与剪贴板

`T1056.001` · 置信度 **中** · 静态

通过 SetWindowsHookExA/CallNextHookEx/GetKeyboardState/ToUnicodeEx/GetKeyboardLayout 构建全局键盘钩子，并用 OpenClipboard/GetClipboardData/SetClipboardData 读写剪贴板，同时用 GetForegroundWindow/GetWindowTextW 记录窗口标题。

> **证据**：导入表 USER32: SetWindowsHookExA、ToUnicodeEx、GetKeyboardState、GetClipboardData、GetWindowTextW
> 
> **来源**：`ref:87a320123d` · `ev-000013`

### 10. 截屏与音频采集

`T1113` · 置信度 **中** · 静态

使用 BitBlt/StretchBlt/CreateCompatibleBitmap 与 GDI+ 的 GdipSaveImageToStream 生成并编码屏幕截图(image/jpeg、image/png)，并通过 waveInOpen/waveInStart/waveInAddBuffer 采集麦克风音频、PlaySoundW 播放声音。

> **证据**：导入表 GDI32 BitBlt/StretchBlt/GetDIBits；gdiplus GdipSaveImageToStream；WINMM waveInOpen/waveInStart/waveInAddBuffer；字符串 0x75064 'image/jpeg'、0x7507c 'image/png'

> **来源**：`ref:87a320123d` · `ev-000013`

### 11. 注册表自启动驻留

`T1547.001` · 置信度 **中** · 静态

通过 RegCreateKeyExW/RegSetValueExW 在 Run、Policies\Explorer\Run 与 Uninstall 等键下写入自身信息，并可用 sc.exe/SetSvcStartup 调整服务启动项，配合拷贝到 svchost.exe/rmclient.exe 等伪装名与 VBS 自删除脚本收尾。

> **证据**：内嵌 PE 偏移 0x701f8/0x70258 Run 与 Policies\Explorer\Run、0x7516c 'SetSvcStartup'、0x74cec 'sc.exe'、0x74cb8 'svchost.exe'、0x74cd0 'rmclient.exe'、0x702ea 'h.vbs'、0x70488 '\update.vbs'；导入 ADVAPI32 RegCreateKeyExW/RegSetValueExW
