## 行为分析

共 **10** 条行为，每条都挂了证据；其中 **4** 条静态可得、**6** 条经动态分析取得。

### 1. 自解压落地载荷

`T1027.009` · 置信度 **高** · 静态

样本为 7-Zip 自解压包(有效 PE 仅 187904 字节, 其余为 SFX 配置与 7z 流), 按配置 InstallPath="%TEMP%" 释放 En_Bu.exe、krpt.dll、eventlib.map、proxy_server.pdb 及 VC 运行库, 并以 RunProgram 启动 %TEMP%\En_Bu.exe。

> **证据**：偏移 187907: ;!@Install@!UTF-8! InstallPath="%TEMP%" RunProgram="\"%%T\\En_Bu.exe\""; 偏移 188228 起为 7z 流; 释放文件经系统遥测确认
> 
> **来源**：`ev-000019` · `ref:1f16ffc385` · `ref:7973dcf12d`

### 2. 白加黑侧加载 krpt.dll

`T1574.002` · 置信度 **高** · 静态

En_Bu.exe 是具 Zhuhai Kingsoft 有效签名的 WPS PDF(wpspdf.exe, 12.9.0.21549) 白文件, 其导入表静态引用同目录 krpt.dll!?_force_link_krpt; 同目录 krpt.dll 无签名却导出同名 _krpt_* 函数, 加载即执行恶意逻辑。

> **证据**：En_Bu.exe 导入表 dll=krpt.dll, symbol=?_force_link_krpt@@YGXXZ; 签名主体 CN=Zhuhai Kingsoft Office Software Co., Ltd.; krpt.dll 导出 7 个 _krpt_* 函数且无安全目录
> 
> **来源**：`ref:b78768e0b4` · `ref:56a49a22d5` · `ref:c4fc6f8eb8` · `ref:8c7ff304fa`

### 3. 复制到 ProgramData 重启

`T1036.005` · 置信度 **高** · 动态

%TEMP% 下的 En_Bu.exe 将自身与 krpt.dll、msvcp140.dll、ucrtbase.dll、vcruntime140.dll 复制到 C:\ProgramData\logadapter\, 随后以该目录副本重新启动进程, 形成稳定落点。

> **证据**：系统遥测: Image=C:\Users\analyst\AppData\Local\Temp\En_Bu.exe (pid 800) 创建 C:\ProgramData\logadapter\En_Bu.exe / krpt.dll / msvcp140.dll / ucrtbase.dll / vcruntime140.dll; 随后 pid 2480 Image=C:\ProgramData\logadapter\En_Bu.exe
> 
> **来源**：`ref:7973dcf12d` · `ref:31c6887c0a`

### 4. 创建计划任务驻留

`T1053.005` · 置信度 **高** · 动态

ProgramData 副本(pid 2480)写入 C:\Windows\Tasks\sys_webhook_net20_rc.job, 任务计划服务随即生成 C:\Windows\System32\Tasks\sys_webhook_net20_rc, 以计划任务实现开机驻留。

> **证据**：系统遥测 T1053: pid 2480 创建 C:\Windows\Tasks\sys_webhook_net20_rc.job; svchost.exe(1260) 创建 C:\Windows\System32\Tasks\sys_webhook_net20_rc
> 
> **来源**：`ref:7973dcf12d`

### 5. 投放 EZ-Play 二级宿主

`T1036.005` · 置信度 **高** · 动态

ProgramData 副本释放 C:\Users\<user>\AppData\Local\PicoInterf.exe(厂商签名白文件, 描述 EZ-Play maintenance tool, 8.0.1[.]2) 并立即启动, 作为下一阶段恶意代码的宿主进程。

> **证据**：系统遥测 Process Create pid 8044 Image=C:\Users\analyst\AppData\Local\PicoInterf.exe, Company=VSO Software SARL, Description=EZ-Play maintenance tool, FileVersion 8.0.1[.]2; 父进程为 C:\ProgramData\logadapter\En_Bu.exe
> 
> **来源**：`ref:31c6887c0a` · `ref:7973dcf12d`

### 6. 替换进程内 PE 模块

`T1055.012` · 置信度 **高** · 动态

PicoInterf.exe 进程内 0xd00000 处存在 0xF0000 大小的 PE 模块, 其 DOS/NT 头、节表与入口点均被改写(is_pe_replaced=1), 与原文件不一致; 同时 ntdll 检出 3 处代码补丁、主模块检出 1346 处补丁, 属进程内模块替换/注入。

> **证据**：内存扫描: module=0xd00000 size=f0000 is_pe_replaced=1 dos_hdr_modified=1 nt_hdr_modified=1 ep_modified=1 sec_hdr_modified=1; ntdll patches=3; 400000 patches=1346
> 
> **来源**：`ref:3e668c9581` · `ref:5b310e40dc` · `ref:f11d321c52`

### 7. 回传主机侦察信标

`T1082` · 置信度 **高** · 动态

进程内存中出现明文 JSON 信标, 采集计算机名、用户名、Windows 版本、内存、CPU 核数、UAC 状态、杀软状态(Windows Defender(OFF))、显示器分辨率与刷新率, 并附带版本 0.1.32、buildId main、sid VUSURWIV、连接端口 cp=3333/dp=3334。

> **证据**：内存明文: {"computer":"DESKTOP-7QK4M2P","user":"analyst","av":"Windows Defender(OFF)","ver":"0.1.32","cp":3333,"dp":3334,"sid":"VUSURWIV","monitors":[{"name":"\\.\DISPLAY1","width":1371,"height":853,"rate":64}]}
> 
> **来源**：`ref:960a514dea` · `ref:d2ecc1659d`

### 8. 周期性加密回连 C2

`T1573.001` · 置信度 **高** · 动态

PicoInterf.exe 解析 new-label[.]club 后周期性连接 3333/TCP 并发送加密二进制数据(约 30-45 秒一次, 观测到 4 次), 未见服务端响应。

> **证据**：网络监控: Dns query new-label[.]club (pid 8044) → 192.0.2[.]123; TCP 3333 at 04:25:56 / 04:26:39 / 04:26:44 / 04:27:24, 原始 TCP 十六进制载荷已记录
> 
> **来源**：`ref:7d133558de` · `ref:7973dcf12d` · `ref:cdb2eb0aef`

### 9. 内置备用 C2 域名表

`T1008` · 置信度 **中** · 静态

进程内存中存在 4 个备用域名 ew-label[.]club、ew-zone[.]club、ew-craft[.]ink、ew-works[.]cc, 与主域名同端口使用, 构成备用通道。

> **证据**：内存 0x40d33c 起连续字符串: ew-label[.]club / ew-zone[.]club / ew-craft[.]ink / ew-works[.]cc
> 
> **来源**：`ref:741ecae710` · `ref:d2ecc1659d`

### 10. 加密容器伪装调试文件

`T1027.013` · 置信度 **中** · 静态

包内 eventlib.map(6570502 字节, 熵 7.94) 与 proxy_server.pdb(121905 字节, 熵 6.63) 均为高熵加密/压缩容器, 文件名伪装成链接器 map 与调试符号文件; krpt.dll 的 .data 段内嵌这两个文件名。

> **证据**：eventlib.map 熵 7.941、proxy_server.pdb 熵 6.628; krpt.dll 文件偏移 61679 (rva 0x112EF) 'eventlib.map'、偏移 60930 (rva 0x11002) UTF-16 'proxy_server.pdb'

> **来源**：`ev-000019` · `ref:adf64dd640` · `ref:0b2e3aa362`

## 不应误判

:::important
以下结论**容易被误判**，引用本报告时请注意。

- 不要把 En_Bu.exe / PicoInterf.exe 当成恶意自研程序: 前者是具 Kingsoft 有效签名的 WPS PDF 白文件, 后者是具 VSO Software 签名的 EZ-Play 维护工具, 二者只是被滥用为加载宿主。
- 不要称其为勒索软件或挖矿程序: 沙箱内未见文件加密、勒索提示(计数为 0), 也未见矿池/挖矿组件。
- 不要声称已窃取浏览器凭据或键盘记录: 内存信标仅体现主机信息采集, 未见浏览器数据库、键盘钩子或凭据转储证据。
- 不要把 C2 写成已建立完整控制通道: 仅观测到 DNS 解析与 TCP 外联/上行数据, 未捕获服务端响应或完整请求-响应会话。
:::
