## 行为分析

共 **10** 条行为，每条都挂了证据；其中 **8** 条静态可得、**2** 条经动态分析取得。

### 1. 回连C2发送主机指纹

`T1071.001` · 置信度 **高** · 动态

运行后解析 serversniperxx[.]duckdns[.]org 并连接 TCP/4577，发送以 0xADDE 开头的签到包；包内为固定长度字段，依次包含计算机名、用户名、Windows 版本与架构、杀软名称以及当前进程路径，随后按 8–40 秒间隔重复重连。

> **证据**：动态网络日志：DNS 请求 serversniperxx[.]duckdns[.]org 后连接 4577/TCP；签到包 0x000 起为 AD DE 02 00 10 02 00 00，0x08 为 DESKTOP-7QK4M2P-6431AF93，0x88 为 analyst，0xC8 为 Windows 10 Pro (64-bit, Build 19045)，0x120 为 Windows Defender，0x150 起为 CP1251 文本“已安装: C:\Windows\System32\WindowsPowerShell\v1.0\powershell.EXE”。
> 
> **来源**：`ref:7a7a8c0364` · `ref:042a92ff7a` · `ref:b3fcd0f101`

### 2. 收集硬件与系统信息

`T1082` · 置信度 **高** · 静态

通过注册表、GetSystemInfo/GetAdaptersInfo 与 WMI 查询收集 CPU、GPU、内存、MAC、磁盘序列号、字体数量、屏幕分辨率/色深、时区、语言、已安装杀软等指纹，并生成 hwid 供上线使用。

> **证据**：字符串 off 0x14A3B8–0x14A7E0：os_name/cpu_name/cpu_id/gpu_name/ram_gb/mac_address/disk_serial/hwid/screen_width/screen_height/timezone/fonts；WMI 查询 ROOT\SecurityCenter2 + SELECT displayName FROM AntiVirusProduct（UTF-16 off 0x1491D0/0x149200）、ROOT\CIMV2 + SELECT * FROM %s。
> 
> **来源**：`ref:b216c963c8` · `ref:e7d1fbf6bb`

### 3. 窃取浏览器凭据与Cookie

`T1555.003` · 置信度 **高** · 静态

枚举 Chrome、Edge、Brave、Opera/Opera GX、Vivaldi、Yandex 等 Chromium 系浏览器及 Firefox 的用户数据目录，复制 Login Data、Cookies、History、Web Data 等数据库；使用 SQL 读取 logins/cookies/history，并调用 CryptUnprotectData、NCryptDecrypt 以及针对 Chrome app_bound_encrypted_key/Google Chromekey1 的解密逻辑还原明文。

> **证据**：字符串 off 0x149DB8“SELECT origin_url, username_value, password_value FROM logins”；off 0x149E10 cookies 查询；off 0x149B10/0x149B60/0x149BB0 为 Chromium app-bound 密钥与 Chrome 密钥服务；off 0x149A90“Microsoft Software Key Storage Provider”、0x149A20 ChainingModeGCM；导入 CryptUnprotectData、NCryptOpenKey/NCryptDecrypt、BCryptDecrypt。
> 
> **来源**：`ref:b216c963c8` · `ref:93697f78dc`

### 4. 记录键盘与剪贴板

`T1056.001` · 置信度 **高** · 静态

安装键盘监控逻辑，结合 GetAsyncKeyState/GetKeyState、ToUnicodeEx 与键盘布局转换按键，捕获窗口标题与剪贴板内容，按会话写入 C:\ProgramData\SniperLogs 下的 keylog_YYYYMMDD_HHMMSS.txt 日志。

> **证据**：字符串 off 0x1497B8“\SniperLogs”、0x1497C8“C:\ProgramData\SniperLogs”、0x1497E8 keylog_%04d%02d%02d_%02d%02d%02d.txt、0x149818 SESSION START、0x149872“>>> CLIPBOARD:”、0x14968C–0x1497A8 按键名表；导入 GetAsyncKeyState/ToUnicodeEx/GetClipboardData/OpenClipboard。
> 
> **来源**：`ref:b216c963c8` · `ref:93697f78dc`

### 5. 隐蔽桌面远控HVNC

`T1055` · 置信度 **高** · 静态

通过 CreateDesktopW/OpenInputDesktop/SetThreadDesktop 建立并切换到隐藏桌面，使用 PrintWindow、BitBlt、D3D11 与 GDI+ 采集画面并回放鼠标键盘；加载 modules\hvnc_injection.dll（文件缺失时从内嵌 PE 资源读取），定位 ReflectiveLoader 后反射注入浏览器或宿主进程，克隆浏览器配置并以 --no-sandbox --user-data-dir 启动，实现无感远程浏览。

> **证据**：字符串 off 0x14AB98 hvnc_debug.log、0x14ABE8 modules\hvnc_injection.dll、0x14AC88 ReflectiveLoader、0x14AD38/0x14ADA0 VirtualAllocEx/CreateRemoteThread、0x14AE76 Local\hvnc_rdi_、0x14B788 injected launch；内嵌 RCDATA 资源（off 0x1C7718，156160 字节）含 ReflectiveLoader 与 HVNCInjection.x64.dll 标识；导入 CreateDesktopW/PrintWindow/D3D11CreateDevice/Gdip*。
> 
> **来源**：`ref:93f2083157` · `ref:b216c963c8` · `ref:93697f78dc`

### 6. 创建互斥体防重复运行

`T1480` · 置信度 **中** · 动态

使用 SniperX_%d 格式（%d 为 C2 端口）创建命名互斥体；本次运行中进程内存出现 SniperX_4577，说明样本在多实例场景下以该名称做单实例/运行状态标记。

> **证据**：进程内存转储偏移 0xE820 处为“SniperX_4577”；静态格式串 SniperX_%d 位于文件偏移 0x14C1D8；导入 CreateMutexW/CreateMutexA。
> 
> **来源**：`ref:b089976019` · `ref:042a92ff7a` · `ref:b216c963c8`

### 7. 投放启动项持久化

`T1547.001` · 置信度 **中** · 静态

将自身或释放体复制到当前用户启动目录，文件名为 WindowsDefender.exe，路径模板拼接 %s\Microsoft\Windows\Start Menu\Programs\Startup，实现用户登录自启动。

> **证据**：字符串 off 0x14C1E8“%s\Microsoft\Windows\Start Menu\Programs\Startup”、0x14C220“%s\WindowsDefender.exe”；导入 CopyFileA/GetEnvironmentVariableA/SHGetFolderPathA。
> 
> **来源**：`ref:b216c963c8` · `ref:93697f78dc`

### 8. 关闭杀软防护与网络

`T1562.001` · 置信度 **中** · 静态

构造 PowerShell 命令调用 Add-MpPreference 为指定路径/进程添加 Defender 排除项；修改当前用户 Internet Settings 的 ProxyEnable/ProxyServer 为 127.0.0[.]1:1，阻断浏览器联网更新；并通过 GetExtendedTcpTable/SetTcpEntry 枚举并切断指定 TCP 连接。

> **证据**：字符串 off 0x14A1F0/0x14A240 两条 powershell -WindowStyle Hidden -Command "Add-MpPreference -ExclusionPath/ExclusionProcess '"；off 0x14C140 Internet Settings、0x14C180 ProxyEnable、0x14C190 127.0.0[.]1:1、0x14C1A0 ProxyServer；导入 RegSetValueExA、SetTcpEntry、GetExtendedTcpTable。
> 
> **来源**：`ref:b216c963c8` · `ref:93697f78dc`

### 9. 执行远程命令与进程控制

`T1059.003` · 置信度 **高** · 静态

通过 cmd.exe /Q 与匿名管道执行服务端下发的命令并回收输出，同时支持枚举/终止进程、挂起与恢复进程、锁定工作站、交换鼠标按键、替换系统光标及修改显示设置，构成完整远控面。

> **证据**：字符串 off 0x14A1B8“cmd.exe /Q”、0x14BFD0 端口状态 JSON、0x14C040 进程终止提示；导入 CreateProcessW/CreatePipe/PeekNamedPipe、TerminateProcess/OpenProcess、NtSuspendProcess/NtResumeProcess、LockWorkStation/BlockInput/SetSystemCursor/SwapMouseButton。
> 
> **来源**：`ref:b216c963c8` · `ref:93697f78dc`

### 10. 向宿主进程注入代码

`T1055.012` · 置信度 **高** · 静态

具备多种注入路径：VirtualAllocEx + WriteProcessMemory + CreateRemoteThread 的直接注入；CreateProcess 挂起后 NtUnmapViewOfSection + SetThreadContext + ResumeThread 的进程镂空；以及为 HVNC 模块准备的 RDI 反射加载（替换宿主节区并注入 DLL）。尝试启用 SeDebugPrivilege 以获得跨进程权限。

> **证据**：字符串 off 0x14BC28 FAIL|CreateProcess、0x14BCA0 NtUnmapViewOfSection、0x14BD28 OK|PE64 injected PID=、0x14BE18 OK|PE32 injected、0x14AD38 ReflectiveInject: VirtualAllocEx/WriteProcessMemory/CreateRemoteThread、0x14AE08 SeDebugPrivilege；导入 VirtualAllocEx/WriteProcessMemory/CreateRemoteThread/SetThreadContext/NtUnmapViewOfSection/RtlVirtualUnwind。

## 不应误判

:::important
以下结论**容易被误判**，引用本报告时请注意。

- 不要仅凭 BCrypt AES-GCM/CryptUnprotectData 等密码学 API 判定为勒索软件或加密器；这些调用用于浏览器密钥/配置解密。
- 不要断言本次运行已把浏览器凭据或键盘日志外传：仅观测到上线签到包，未观测到文件回传或凭据数据包。
- 不要仅凭 Add-MpPreference 字符串断言 Defender 防护已被成功关闭：系统遥测中 Defender 排除列表仍为空。
- 不要将动态沙箱中的 192[.]0[.]2[.]123 当作真实 C2 IP：该地址为隔离网络重定向地址，真实 IP 未取得。
- 不要声称本次运行已完成启动项落地或 HVNC/注入：未观测到 Startup 文件，内存扫描也未在样本进程发现可疑注入模块。
:::

**局限与待验证**

1. 隔离网络中的模拟服务端只记录到样本发出的签到包，未返回任何响应，无法验证服务端会话、指令集与后续载荷；因此 C2 按未完成验证处理（static + pending_dynamic_verify）。
2. 未观测到启动项文件、Defender 排除项、HVNC 注入或浏览器数据窃取落地；这些能力均由字符串、导入表与内存中的模块/配置证明，属于静态证据。
3. 真实 C2 IP 被隔离网络重定向掩盖，未取得；域名 serversniperxx[.]duckdns[.]org 由运行期内存与 DNS 记录共同确认，属于运行期解密的明文。
4. 系统遥测仅覆盖服务、证书、Defender 配置与 Run 键，不含文件/注册表全量差分，因此代理设置与启动项的写入未获动态确认。
5. “Evolution RAT/Overlord-Server”来自内嵌 HVNC 模块的 PDB 路径，可能为上游组件复用；主程序家族名以 SniperX 证据为主，仍建议结合外部情报复核。
