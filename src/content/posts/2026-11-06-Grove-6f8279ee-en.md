> [!WARNING]
> **Verdict: Malicious** · Family **Grove** (uncertain) · Confidence **medium**
> 
> Aliases: GroveLoader, Grove Loader, EtherHiding loader
> 
> After real detonation inside the isolated Windows dynamic sandbox, the original process drops and launches a hidden copy at %LOCALAPPDATA%\Windows\Config\700E238B\NetHost1dcc90.exe; that copy resolves its configuration through the api[.]telegra[.]ph dead drop and Polygon/Ethereum smart-contract eth_call, and establishes a WebSocket callback to queue[.]grovewest89[.]club:443. On the static side it is high-entropy packed with only 5 imports, its entry lies in a high-entropy section, and it contains rdtsc / int 2Dh / cpuid anti-debugging; the pure emulation environment triggers 'Initialization error 3' and ExitProcess(0xdeadc0de), while the real sandbox continues execution. Taken together it is judged a malicious loader/downloader.

## Behavior analysis

**10** behaviors in total, each backed by evidence; **2** are statically recoverable and **8** were obtained through dynamic analysis.

### 1. High-entropy packed code hiding

`T1027.002` · Confidence **high** · static

In the original PE the SizeOfRawData of .text/.rdata/.data is 0, and the real content is concentrated in the .lD; section with entropy 7.953; the entry RVA 0x1CD3D2 lies in that section (section base RVA 0x1CA000), and the import table retains only 5 APIs, a typical high-entropy packing/payload-hiding pattern.

> **Evidence**: static PE parsing: .lD; entropy 7.953, entry 0x1CD3D2, import directory RVA 0x434118, only 5 imports; unpack.detect rules packed=true, signals=[executable section .lD;, high entropy 7.95, very few imports 5]
> 
> **Source**: `ref:b9baf94332` · `ref:b0be608a89` · `ref:908a504ff0` · `ref:c6bd86eac0`

### 2. Anti-debug and virtual-machine checks

`T1497.001, T1622` · Confidence **high** · static

The code contains rdtsc timing-difference measurement, int 2Dh and cpuid probing to identify debuggers/virtualized environments; in the pure emulation environment it pops 'Initialization error 3' and calls ExitProcess(0xdeadc0de), while in the real sandbox it keeps executing, indicating an environment-dependent branch.

> **Evidence**: unpack.antidebug hits rdtsc @RVA 0x1CD49B, int 2Dh @RVA 0x1E7032, cpuid @RVA 0x1D89A6; emulation observed MessageBoxW('Initialization error 3') and ExitProcess(0xdeadc0de)
> 
> **Source**: `ref:8eec1b238a` · `ref:ad57a29f0f` · `ref:008dd30fd0`

### 3. Drop hidden copy

`T1036` · Confidence **high** · dynamic

In the real sandbox, after the original process exits, a copy located in a hidden directory appears in the process table, C:\Users\analyst\AppData\Local\Windows\Config\700E238B\NetHost1dcc90.exe (PID 7880), and that copy takes over the subsequent network behavior; the reconstructed payload also stores the same UTF-16 path and NetHost filename.

> **Evidence**: dynamic timeline: PID 8056 original sample 'process gone before dump'; memory scan main_image_path=C:\Users\analyst\AppData\Local\Windows\Config\700E238B\NetHost1dcc90.exe; reconstructed image offset 0x4BA00 contains the same UTF-16 path
> 
> **Source**: `ref:d76cdbe5be` · `ref:795e869419` · `ref:488e29b086`

> **Evidence**: network monitoring: NetHost1dcc90.exe (7880) requests Host: api[.]telegra[.]ph, GET /getPage/Grove-record-index-09-21?return_content=false; reconstructed image offsets 0xF998/0xF9B8/0xF9E8 contain the same string and the '"description":"' parsing marker

## What not to claim

:::important
The following conclusions are **easy to misjudge**; keep them in mind when citing this report.

- Do not assert it is ransomware/wiper: no file encryption, bulk rewriting or destructive behavior was observed, and there is no ransom note.
- Do not assert it is an infostealer: no browser credential databases, wallets, keylogging, screenshots or data exfiltration were observed; the current evidence is mainly host-information collection and a C2 channel.
- Do not assert persistence exists: the import surface only has registry-read APIs, and no Run key, service or scheduled-task writes were observed; the hidden-directory copy alone does not constitute autostart.
- Do not assert process injection occurred: memory scanning found no implanted module, and the import surface shows no actual CreateRemoteThread/WriteProcessMemory call chain.
- Do not assert remote command execution or second-stage payload dropping was observed: the C2 channel was established, but no task delivery, download or execution result was seen within the observation window.
- Do not treat 'Grove' as a vendor/YARA-confirmed family name: it is a candidate named after the sample's own infrastructure, family.uncertain=true.
:::

**Limitations and pending verification**

1. Network monitoring used a fake network/redirection, so Telegraph and the blockchain RPCs returned no real content; follow-on tasks, second-stage payloads and their decryption results were not obtained, and the C2 command layer was not observed.
2. The on-disk NetHost1dcc90.exe was not retrieved; recovered.unpacked_sha256 and the stage2 hash come from the memory-reconstructed image and may differ byte-wise from the on-disk file.
3. The family name 'Grove' comes only from self-naming in the sample's own infrastructure (Telegraph page and C2 subdomain), without vendor/YARA/multi-engine confirmation, uncertain=true.
4. No persistence writes such as Run keys, services or scheduled tasks were observed; it cannot be ruled out that later C2 commands establish persistence.
5. The high-entropy section remains high-entropy in the memory image, and the exact protection/virtualization/encryption algorithm was not fully recovered; some behaviors are supported only by the import surface, strings or external network observation.
6. The reconstructed image contains 96/64-character hex strings (da87239f…, 4040862b…) and a 56-character base64 string (WcjQeoGS…) whose purpose is unconfirmed; they are not used as conclusions.
7. The pure emulation environment triggered 'Initialization error 3' and ExitProcess(0xdeadc0de), unlike the real sandbox; the environment-dependent branch was not fully analyzed.
