> [!CAUTION]
> **Verdict: Gray/PUA** · Family **PDFMaestro** · Confidence **high**
> 
> Aliases: PDF Maestro, Secure PC Software PDF Maestro, browserSDKWrapper offerware
> 
> This MSI installs a fully usable PDF tool, PDF Maestro 1.1.6, but the installer hides/neutralizes the Cancel button, creates a startup shortcut immediately on installation, and at runtime modifies Chrome's default search engine through browserSDKWrapper while reporting browser and host information back to configuration/telemetry endpoints and billing per offer display. No credential theft, file encryption, backdoor or interactive remote-control capability was found, so it is judged a potentially unwanted application (PUA/offerware) rather than traditional malware.

## Behavior analysis

**10** behaviors in total, each backed by evidence, and all are statically available.

### 1. Hide installer Cancel button

`T1204.002` · Confidence **high** · static

The MSI's JScript custom actions HideMsiCancel/ApplyMsiCancel and TelemetrySender's MSI dialog automation hide or disable msiexec's Cancel button during installation, restoring it only when a marker file exists.

> **Evidence**: MSI CustomAction table HideMsiCancel/ApplyMsiCancel/DisableCancelButton (Type 4197/194); TelemetrySender IL strings HideAndNeutralizeControl, MsiDialogCloseClass, '&Cancel'; mutex Local\PDFMaestro_MsiCancelWatcher
> 
> **Source**: `ref:f243f45b71` · `ref:7d1fe19135`

### 2. Write startup shortcut

`T1547.001` · Confidence **high** · static

The installer creates a shortcut to PDFMaestro.exe in the Startup folder with the arguments /quiet /startupshortcut; the application also recreates the missing startup shortcut when it runs.

> **Evidence**: MSI Shortcut table StartupShortcut -> StartupFolder, [#AppExe] /quiet /startupshortcut; StartupShortcutHelper.InstallStartupShortcut calls WScript.Shell to create the .lnk; app string 'Recreated missing startup shortcut'
> 
> **Source**: `ref:f243f45b71` · `ref:a78b1f2c40`

### 3. Register daily scheduled tasks

`T1053.005` · Confidence **high** · static

It creates the scheduled task PDFMaestroUpdater to run PDFMaestro.exe /checkupdate daily (schtasks /create /xml) and maintains the PDFMaestroLauncher autostart task.

> **Evidence**: CfuScheduledTaskHelper.EnsureUpdaterTaskRegistered -> schtasks.exe /create /tn PDFMaestroUpdater; TaskSchedulerHelperForAutoLaunch.SetAutoLaunch -> PDFMaestroLauncher; task XML Author=Secure PC
> 
> **Source**: `ref:a78b1f2c40` · `ref:7d1fe19135`

### 4. Hijack Chrome search engine

`T1185` · Confidence **high** · static

ChromeSearchService.SetSearchEngine calls browserSDKWrapper.set(...), writing the search URL delivered by configuration into Chrome's configuration; the same SDK also provides revertSearch and profile-level search/homepage/newtab reads.

> **Evidence**: PDFMaestro.Core.ChromeSearchService.SetSearchEngine IL calls browserSDKWrapper.Instance.set; the SDK exposes set/get/revertSearch; ChromeHelper reads default_search_provider_data and short_name from Local State/Preferences/Secure Preferences
> 
> **Source**: `ref:7d1fe19135` · `ref:50a867cc5f`

### 5. Collect browser and host information

`T1082` · Confidence **high** · static

Daily-activity telemetry collects whether Chrome is installed/default/running, the current search engine and profile count, along with .NET/OS/CPU/virtual-machine identifiers, and uploads them together with InstanceId/MacId/geo.

> **Evidence**: EventDataCollector.BuildDailyActivityEvent IL calls IsChromeInstalled/IsDefaultBrowser/IsChromeOpened/IsAnyChromeProfileUsingOurSearchEngine; browserSDKWrapper.sysInfoEventModel(OS/CPU/.NET/isVM) and coreDataEventModel(macId/instanceId/geo); TelemetryService.PostRequestAsync
> 
> **Source**: `ref:7d1fe19135` · `ref:0e0bab40ae`

### 6. Send telemetry and fetch control config

`T1071.001` · Confidence **high** · static

It sends install/update/daily-activity/offer-display-and-response events to dev-events.pdfmaestro.ai over HTTPS POST, and fetches CFF/CFC/CFU configuration and update information from api[.]configtower[.]com.

> **Evidence**: strings hxxps://api[.]configtower[.]com/api/cff, /api/cfc, /api/cfu, hxxps://dev-events.pdfmaestro.ai/api/dev/v1/events; ConfigTowerHelper.SendCFFRequest/SendCFCRequestAsync; TelemetryService.SendTelemetryEventAsync
> 
> **Source**: `ref:6b190447ec` · `ref:7d1fe19135`

### 7. Decrypt bundled install configuration

`T1140` · Confidence **high** · static

It uses the hard-coded AES-192-CBC key 'mugGam-byrqu2-syrjim-001' and IV '1234567890123456' to decrypt Base64 configuration in install-info.txt, installConfig.txt, tParams.txt, metadata.txt and similar files.

> **Evidence**: AESHelper.Decrypt IL: Aes.Create + UTF8.GetBytes(key/iv) + CreateDecryptor + FromBase64String; hard-coded key/IV in .cctor; GetInstallInfo/InstallConfigHelper/TParamsHelper all call Decrypt
> 
> **Source**: `ref:67b19d50a1` · `ref:a78b1f2c40`

### 8. Silently download and install updates

`T1218.007` · Confidence **high** · static

It obtains an MSI URL from configtower's CFU response, downloads it to %TEMP%\PDFMaestroUpdate, invokes msiexec with /qn /norestart PM_UPDATER=1 for a silent install, and restarts the application after updating.

> **Evidence**: MsiUpdateApplyHelper.ToInstallerMsiDownloadUrl/GetTempMsiPath; UpdateService.CheckForUpdatesAsync POST hxxps://api[.]configtower[.]com/api/cfu; strings '" /qn /norestart PM_UPDATER=1' and 'msiexec'
> 
> **Source**: `ref:a78b1f2c40` · `ref:7d1fe19135`

### 9. Write install identity markers

`T1112` · Confidence **high** · static

At install start it writes InstanceId, MacId, FirstLaunchDate and CampaignGeo under HKCU\Software\SB\PM for subsequent telemetry and offer attribution.

> **Evidence**: TelemetrySender IL: EnsureIdentityAtInstallStart/LogExistingIdentity read InstanceId/MacId from SOFTWARE\SB\PM; GetInstallInfo.GetCountryCodeFallback reads CampaignGeo
> 
> **Source**: `ref:7d1fe19135` · `ref:a78b1f2c40`

### 10. Show search offer windows

`T1204.002` · Confidence **medium** · static

It pulls rollout templates from CFC/CFF and shows search or static offer windows according to the display counts and intervals recorded in its database, logging Offer_Shown/Offer_Response and counting display days per offer type.

> **Evidence**: App.DynamicWindow AcceptButton_Click -> 'Processing offer type for search SDK'; RolloutService.RolloutLogs (OfferType/Action/Timestamp); OfferMetricsHelper.GetNoOfSearchOfferShown/GetDaysSinceLastSearchOfferShown; EventDataCollector.BuildOfferShownEvent
> 
> **Source**: `ref:7d1fe19135` · `ref:a78b1f2c40`

## Must not be misjudged

:::important
The following conclusions are **easy to misjudge**; keep them in mind when citing this report.

- Do not call it ransomware or a credential-stealing trojan: no file encryption, credential-database/browser-password/cookie theft or keylogging logic was found; reading Chrome configuration is only used to check/modify the default search engine.
- Do not call it a dropper: the MSI delivers the advertised PDF Maestro application itself and its dependencies, not a second-stage malicious payload unrelated to the product.
- Do not claim that a live C2 session or successful outbound communication was observed: all endpoints come from static strings and decompilation, the sample was not executed, and the C2/config entries are static with pending_dynamic_verify=true.
- Do not claim the digital signature is invalid: the MSI, PDFMaestro.exe and browserSDKWrapper.dll all carry valid Authenticode signatures from Secure PC Software LLC; only the TelemetrySender component is not separately signed.
:::

## Analysis method and limitations

| Item | Content |
|:--|:--|
| Analysis method | Pure static analysis |
| Unpacking | No |

**Limitations and pending verification**

1. The sample was not executed: there was no dynamic-sandbox/network-monitoring session, and the network and registry drop behaviors in c2, host_iocs and config are statically inferred, with pending_dynamic_verify=true.
2. browserSDKWrapper.dll uses obfuscated .NET type/method names and embeds encrypted resources (browserSDKCore etc.); its set/revertSearch concrete registry/Preferences write paths are inferred from the caller ChromeSearchService and model names, not byte-for-byte recovered.
3. Actual CFF/CFC/CFU responses were not captured, so the actual delivered search URL, offer templates, campaigns and update MSI URL are unknown.
4. The MSI was not installed on an isolated machine; the Startup shortcut, scheduled tasks and HKCU\Software\SB\PM identity writes are MSI table and IL string evidence.
5. The cloud conversion service api[.]cloudconvert[.]com is a third-party PDF conversion API that only processes files the user explicitly selects and should not be confused with a C2.
