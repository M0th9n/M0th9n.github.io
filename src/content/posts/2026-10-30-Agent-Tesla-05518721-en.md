>

> 
> In the isolated Windows sandbox the sample ran as a managed .NET process (CLR loaded, 49 modules), opened a TCP connection to the hardcoded 188.137.243[.]190:443 about 31 seconds after launch, and then self-exited. Its process memory holds the same host/port together with a campaign id, key material and a large set of decrypted browser, messenger, wallet and keylogger strings. Static metadata and decrypted strings confirm credential/cookie theft, keylogging and screen capture.

## Behaviour analysis

**11** behaviours in total, each tied to evidence; **9** are statically recoverable and **2** were obtained dynamically.

### 1. Decrypt embedded config

`T1140` · Confidence **high** · dynamic

After launch it decrypts the host, port, campaign id and several key sets from an encrypted managed resource; these values then persist as plaintext strings on the managed heap.

> **Evidence**: memory dump offsets 5172796/5173020/5173220 contain 188.137.243[.]190 / 443 / WEZAK888 and 5 key sets; the managed resource in the PE is 67,552 bytes with entropy 7.93
> 
> **Source**: `ref:6f2f6f7fda` · `ref:3e6bf3d5ce`

### 2. Contact hard-coded C2

`T1071` · Confidence **high** · dynamic

The process opens a TCP connection to port 443 on the hard-coded IP 188.137.243[.]190, matching the host and port in the memory config.

> **Evidence**: network monitoring: pid 7604 requests TCP 188.137.243[.]190:443 about 31 seconds after launch; the same IP/port sits at memory offset 5172796
> 
> **Source**: `ref:3466f9d459` · `ref:6f2f6f7fda`

### 3. Steal browser credentials

`T1555.003` · Confidence **high** · static

Enumerates Chromium/Gecko profile directories, reads Login Data and Cookies, and decrypts stored passwords and cookies with os_crypt/encrypted_key from Local State.

> **Evidence**: plaintext from memory offset 389796 includes Login Data, Cookies, Local State, os_crypt, encrypted_key, encrypted_value, is_secure; metadata includes Account-type URL/Username/Password properties
> 
> **Source**: `ref:3e6bf3d5ce` · `ref:15562bd4fb`

### 4. Harvest forms and cards

`T1555.003` · Confidence **high** · static

Reads autofill records and encrypted card number, expiry and cardholder fields from the browser Web Data store.

> **Evidence**: memory plaintext includes Web Data, autofill, name_on_card, card_number_encrypted, expiration_month, holder name; metadata includes Autofill and credit-card object properties
> 
> **Source**: `ref:3e6bf3d5ce` · `ref:15562bd4fb`

## Do not misjudge

:::important
The following conclusions are **easy to misjudge**; keep them in mind when citing this report.

- It should not be classified as ransomware or a wiper: no file encryption, bulk deletion, shadow-copy deletion or ransom note was found; the code and memory evidence all point to information theft.
- Do not claim the sample writes persistence: no Run key, service or scheduled-task creation was observed; the \Run strings in memory are Explorer MRU data, not sample configuration.
- Do not treat WEZAK888 directly as a mutex name: it sits in the config block and looks more like a campaign/build identifier; no evidence links it to mutex creation parameters.
:::

**Limitations and pending verification**

1. Only the TCP connection to 188.137.243[.]190:443 and a reverse DNS lookup were observed; no TLS plaintext, HTTP path or returned content was captured, so the C2 protocol details remain unconfirmed.
2. Family attribution is a candidate judgement based on code structure and functionality, lacking engine/YARA or multi-engine corroboration; derived versions such as OriginLogger are equally possible.
3. The purpose of each Base64/hex key in the config was not verified individually (it may be used for exfiltration encryption, resource decryption or identification); they are only classified by their position in the config block.
4. The embedded high-entropy managed resource was not decrypted offline; the full string table was only partly recovered from memory and may miss modules that never triggered.
5. The sample self-exits after running; no persistence, downloader behaviour or secondary payload was observed, so long-term residency cannot be assessed.
