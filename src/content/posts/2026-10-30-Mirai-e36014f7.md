## 行为分析

共 **12** 条行为，每条都挂了证据，且全部静态可得。

### 1. 建立C2长连接

`T1095` · 置信度 **高** · 静态

机器人主循环从 argv 覆盖 C2 地址，随后反复 socket(AF_INET,SOCK_STREAM)->connect，用 select/recv 读取 2 字节命令，并通过 send 发送 2 字节心跳。

> **证据**：FUN_000364d0 @0x364d0: 0x26b24 call connect, 0x26a34 call send, socket/select/recv loop
> 
> **来源**：`ref:d0868ddb3b` · `ref:6d54c4b7f8` · `ref:1bfc312c8b`

### 2. 解析CNC指令表

`T1071` · 置信度 **高** · 静态

二进制内嵌命令字符串表，映射 PING、PONG、REPORT %s:%s:%s、HTTPFLOOD、SCANNER ON/OFF、BOTKILLER、GETLOCALIP 等机器人命令，标识为 MIRAI-CNC/1.0。

> **证据**：string table at file offset 0x5c280-0x5c2b0 (VA 0x5e280): 'MIRAI-CNC/1.0', 'HTTPFLOOD', 'SCANNER ON', 'BOTKILLER'
> 
> **来源**：`ref:134f619d21` · `ref:008b80701c`

### 3. 发起HTTP洪泛攻击

`T1498.001` · 置信度 **高** · 静态

实现 HTTP 洪泛原语，使用原始 HTTP/1.1 与 HTTP/2 preface 字符串、代理认证头以及 IRC 风格的 'PRIVMSG #%s :HTTPFLOOD ready' 状态消息。

> **证据**：strings 'HTTPFLOOD', 'PRIVMSG #%s :HTTPFLOOD ready', 'PRI * HTTP/2.0', 'Proxy-Authorization: Basic ' at file offsets 0x5d60/0x7430 region
> 
> **来源**：`ref:a25b2e216d` · `ref:008b80701c`

### 4. SSH口令爆破横扫

`T1110.001` · 置信度 **高** · 静态

内置 19 个用户名与 18 个常见口令，以及一组伪造的 SSH 客户端 banner（OpenSSH/libssh/Dropbear/PuTTY/JSCH），用于凭据爆破与 SSH 横向移动。

> **证据**：credential table at file offset 0x5c2e8-0x5c414 (SSH-2.0 banners, root/admin/ubuntu..., P@ssw0rd/Winter2024!/Debian11)

> **来源**：`ref:134f619d21` · `ref:a25b2e216d`

### 5. 利用内核漏洞提权

`T1068` · 置信度 **高** · 静态

包含 rxrpc/rxkad 本地提权模块，带 AF_ALG pcbc(fcrypt)/NETLINK_XFRM 字节翻转逻辑、unshare(NEWUSER|NEWNET) 与 splice/vmsplice/mmap 原语；模块在 fork 子进程中启动并检查状态。

> **证据**：FUN_0005e5a0 @0x5e5a0 fork/waitpid + pread; strings '=== rxrpc/rxkad LPE EXPLOIT (uid=1000 ...', 'DIRTYFRAG_CORRUPT_ONLY', 'AF_ALG pcbc(fcrypt)'; call sites 0x4e718 unshare, 0x4eebc splice, 0x4e828 vmsplice
> 
> **来源**：`ref:0b275cbba2` · `ref:6d54c4b7f8` · `ref:a25b2e216d`

### 6. 篡改passwd植入root

## 分析方法与局限

| 项目 | 内容 |
|:--|:--|
| 分析方法 | 动态沙箱分析（Linux 样本）+ 静态反编译 |
| 脱壳 | 否 |

**局限与待验证**

1. 该样本是 32 位 ARM Android ELF，无法在加固的 x86 Linux 引爆实例中直接执行；真机运行与 qemu-user 仿真均在启动阶段失败，因此未观察到运行时网络、文件或 API 事件。
2. 所有 C2 主机、备用 IP、端口与凭据均从内嵌表静态恢复，并标记为待动态验证；真实 C2 端点与端口在运行时选择，未被观测。
3. 二进制中的若干 IP 是公共/CDN 或 TEST-NET 诱饵，未执行或缺乏外部报告时无法缩小真实 C2 集合。
4. AES/SHA-256/TEA 常量的确切用途（协议加密还是漏洞辅助）未能在静态分析中确定。
5. 提权模块在特定内核上的成功率未验证；其存在与控制流已确立，但利用结果未经证实。
