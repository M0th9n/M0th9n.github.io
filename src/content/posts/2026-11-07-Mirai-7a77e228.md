## 行为分析

共 **12** 条行为，每条都挂了证据，且全部静态可得。

### 1. UPX外壳自解压

`T1027.002` · 置信度 **高** · 静态

样本是 UPX 5.21 加壳的 32 位 x86 ELF，文件偏移 0x93 有 'UPX!' 标记，尾部为 UPX 解压 stub；解包后 6,490,348 字节，整体熵 7.905。

> **证据**：off 0x93 ';UPX!'；off 0x2a00de '$Info: This file is packed with the UPX executable packer'；scan_entropy=7.905
> 
> **来源**：`ref:e6b6c839ea` · `ref:7258b05b67` · `ref:27f28273aa`

### 2. 内嵌Go植入体

`T1027.009` · 置信度 **高** · 静态

解包文件 .rodata（off 0x140, size 0x615ecc）内、偏移 0x10b0 处嵌入一个完整 Go ELF（Go 1.26/386，模块 example[.]com/read-remote-text，含 dnsshm/textcrypto/updater 包）；外层 C 载体入口位于 0x628f70。

> **证据**：off 0x10b0 第二个 ELF 头（entry 0x080DB680）；Go buildinfo 'go1.26.1'；模块路径 example[.]com/read-remote-text；节表 .rodata off 0x140 size 0x615ecc、.text off 0x617f70
> 
> **来源**：`ref:55a310b18d` · `ref:479aa8d1da` · `ref:9fea826195` · `ref:55eeb0f738`

### 3. 四源拉取加密配置

`T1071.001` · 置信度 **高** · 静态

从内置 4096 字节 'c' 区读取 4 个逗号分隔 URL 依次拉取配置文本，全部失败才终止；URL 列表由 RTSRC02_BEGIN___ / RTSRC02_END_____ 包裹。

> **证据**：off 0x5d9160 'RTSRC02_BEGIN___https://twilight-mountain-dacb.goto2022.workers.dev/,...'；sourceconfig.URLs @0x8297db0 → sourceconfig.Read @0x8297ef0；错误串 'All configuration sources failed: %w'
> 
> **来源**：`ref:c24f6cd76a` · `ref:82246c7cf4` · `ref:4497bac7fd` · `ref:eff5ada39a`

### 4. AES-GCM解密配置

`T1140` · 置信度 **高** · 静态

配置文本以 'textenc:v1:' 前缀 + Base64 承载；PBKDF2(600000 次, 32 字节) 派生密钥后 AES-GCM 解密，失败返回 'incorrect key or corrupted ciphertext'；明文必须是 JSON 对象。

> **证据**：textcrypto.Decrypt @0x82a5310；newAEAD @0x82ad870 调 pbkdf2(...,600000,0x20)；串 'textenc:v1:'、'Invalid ciphertext format: expected textenc:v1:'、'Decryption failed: incorrect key or corrupted ciphertext'
> 
> **来源**：`ref:4de6d54678` · `ref:b87a794cd6` · `ref:3db5bbd40b`

### 5. 自更新覆盖可执行文件

`T1105` · 置信度 **高** · 静态

解析配置中的 version/downloads，比较版本后下载新 ELF，校验 ELF class/machine 与下载哈希，替换 /proc/self/exe 并自动重启；失败时提示手动运行。

> **证据**：updater.Install @0x82a5d50；updater.validateELF @0x82a4f70；runApplication 串 'New version available: %s -> %s; downloading'、'Updated to %s; restarting automatically'、'The executable was replaced, but restart failed; run %s manually: %w'
> 
> **来源**：`ref:51c879634d` · `ref:50778313ad` · `ref:3db5bbd40b`

### 6. 执行第三方程序

`T1059.004` · 置信度 **高** · 静态
