## 行为分析

共 **11** 条行为，每条都挂了证据；其中 **10** 条静态可得、**1** 条经动态分析取得。

### 1. 解密浏览器密钥库

`T1555.003` · 置信度 **高** · 静态

读取 Chromium Local State 的 os_crypt.encrypted_key / app_bound_encrypted_key，经 DPAPI 解包后用 BCrypt 的 AES-GCM 或 ChaCha20-Poly1305 解密 Login Data/Web Data 中保存的口令与 Cookie。

> **证据**：函数 0x5dc0；0x5f4f lea rdx, os_crypt；字符串 encrypted_key/app_bound_encrypted_key/DPAPI/ChainingModeGCM/CHACHA20_POLY1305；导入 CryptUnprotectData、BCryptDecrypt
> 
> **来源**：`ev-000014` · `ev-000005`

### 2. 窃取浏览器凭据

`T1555.003, T1539` · 置信度 **高** · 静态

枚举 Chrome/Edge/Brave/Opera/Opera GX/Vivaldi/Yandex 的用户数据目录，读取 Login Data、Login Data For Account、Web Data、Preferences/Secure Preferences、Local Extension Settings 与 IndexedDB，收集 Cookie、口令和表单数据。

> **证据**：字符串 Login Data、Web Data、Local Extension Settings、IndexedDB\chrome-extension_；端点 /api/v1/ext/passwords、/api/v1/ext/tokens；内存含 ...Edge\User Data\Default
> 
> **来源**：`ev-000014` · `dyn-log-43340d`

### 3. 收割钱包与TG数据

`T1555` · 置信度 **高** · 静态

定位 MetaMask/Trust/OKX/SafePal 扩展存储，以及 Exodus/Atomic/Electrum/Bitcoin/Litecoin 钱包文件和 Telegram Desktop tdata，打包成 wallet.zip/tdata.zip 后上传。

> **证据**：字符串 metamask/trust/okx/safepal、Exodus\exodus.wallet、Electrum\wallets、Telegram Desktop\tdata、tdata.zip、/api/v1/ext/wallets、/api/v1/ext/telegram
> 
> **来源**：`ev-000014`

### 4. 投放恶意浏览器扩展

`T1176` · 置信度 **高** · 静态

从 .embed 段内嵌 ZIP 释放名为 Google Translate v1.2.1 的 MV3 扩展，写入 %LOCALAPPDATA%\Packages\Extensions\<HWID>\e<index>，并可对指定浏览器执行安装、固定和启用操作。

> **证据**：0x36a00 起 PK ZIP，manifest name=Google Translate/version 1.2.1；运行时内存路径 ...\Packages\Extensions\<HWID>\e0 与 Temp\extE899.tmp.zip
> 
> **来源**：`ev-000006` · `ev-000014` · `dyn-log-43340d`

### 5. 注册原生消息宿主

`T1559, T1176` · 置信度 **高** · 静态

在运行时目录写入 host.ps1、host.bat 与 com.lunex.explorer.json，并向 HKCU 的 Chrome/Edge NativeMessagingHosts 注册 com.lunex.explorer，使扩展获得本机文件读取、写入和执行通道。

> **证据**：FUN_0x19f40 写 host.ps1/host.bat/com.lunex.explorer.json；0x1a35f/0x1a36e lea rcx 注册表路径；RegCreateKeyExW/RegSetValueExW
> 
> **来源**：`ev-000015` · `ev-000014`

### 6. 创建登录自启任务

`T1053.005` · 置信度 **高** · 静态

通过 Task Scheduler COM 注册名为 installerUtils 的任务，登录时触发并执行当前样本路径，描述为 Starts installerUtils at user logon。

> **证据**：FUN_0x1a480 调用 ITaskService/RegisterTaskDefinition；0x1a7e1 lea r9, 'Starts %s at user logon'；运行时内存含 installerUtils
> 
> **来源**：`ev-000016` · `dyn-log-43340d`

### 7. 回传主机指纹

`T1082, T1518.001` · 置信度 **高** · 动态

采集 HWID、计算机名/用户名、OS 版本与补丁、CPU/RAM/GPU/磁盘/屏幕、时区/语言、MAC、管理员标志、杀软产品与已安装浏览器，POST 到 /api/v1/checkin。

> **证据**：真实动态：GET hxxp://37[.]187[.]140[.]177:8080/api/v1/agent/config（X-API-Key），两次 POST /api/v1/checkin，正文含 hwid/computer_name/username/os_build/cpu/mac_address/is_admin/antivirus/browsers
> 
> **来源**：`dyn-log-43340d` · `ev-000014`

### 8. 查询杀软与系统信息

`T1518.001, T1082` · 置信度 **高** · 静态

通过 WMI ROOT\SecurityCenter2 的 AntiVirusProduct 表枚举杀软 displayName，并读取 CurrentVersion、CPU、显卡、时区、Locale 等注册表键。

> **证据**：0x11163 lea rdx, ROOT\SecurityCenter2；字符串 SELECT displayName FROM AntiVirusProduct；0x10a26 CurrentVersion
> 
> **来源**：`ev-000014` · `ev-000005`

### 9. 下发并执行远程任务

`T1105, T1059.001, T1059.003` · 置信度 **高** · 静态

轮询 /api/v1/agent/tasks?hwid= 并对任务 ack，下载文件后用 cmd.exe /C、PowerShell -File 或 msiexec 执行，也可 taskkill 结束指定浏览器进程。

> **证据**：0xed40；0xf27d cmd.exe /C "%s"；0xf2dc powershell ... -File "%s"；字符串 imsiexec.exe /i、taskkill /F /IM "%s" /T、/api/v1/agent/tasks
> 
> **来源**：`ev-000014`

### 10. 远程操控浏览器

`T1185, T1056.001, T1113` · 置信度 **高** · 静态

扩展连接受控 WebSocket/HTTP 通道，执行注入覆盖层、模拟鼠标键盘、截取标签页画面、读取 Cookie/历史/书签、设置代理和关闭/重载标签页等指令。

> **证据**：background.js 混淆还原：/api/v1/ext/remote?api_key=、__bp_spoof_frame__ 全屏 iframe（camera/microphone/geolocation/payment/clipboard-write）、captureVisibleTab、mouse_move/key_down、set_proxy、bp_sent_cookies
> 
> **来源**：`ev-000006` · `dyn-log-43340d`

### 11. 剥离CSP注入页面

`T1176, T1185` · 置信度 **高** · 静态

扩展在 <all_urls> 的 document_start/all_frames 注入 content script，并用 declarativeNetRequest 规则删除所有响应的 CSP 头，为脚本注入和全屏伪造页面清除障碍。

> **证据**：manifest content_scripts matches <all_urls> run_at document_start all_frames；rules/strip_csp.json 删除 content-security-policy 等 4 个头
> 
> **来源**：`ev-000006` · `ev-000014`

## 不应误判

:::important
以下结论**容易被误判**，引用本报告时请注意。

- 不要将其归类为勒索软件或擦除器：未发现文件加密、勒索信或破坏性写入行为。
- 不要把扩展自称的 Google Translate 当作良性证据：其 manifest 申请 cookies、proxy、nativeMessaging、<all_urls> 等权限并主动剥离 CSP。
- 不要声称已确认扩展在浏览器中成功加载或 C2 已下发配置：本次仅观测到 config/checkin 请求，扩展投放与任务下发未完整闭环。
:::
