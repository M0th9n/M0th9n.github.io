> [!WARNING]
> **判定：恶意** · 家族 **Ransom.Win32.Blocker**（存疑） · 置信度 **低**
> 
> 别名：Winlock、Crypto-File Blocker、Ransom.Blocker
> 
> 样本在动态沙箱中启动为单个 64 位 GUI 进程并常驻；其进程内存转储显示运行时解密出一组勒索提示文本（“This is a VIRUS!!!! Do you want to run the file?” / “To remove the window, you must CRYPT FILE!” / “Warning”）、一个活动标识串“--k1176k”、128 字节疑似密钥材料，以及一张 ntdll 原生 API 名称表（NtCreateFile / NtReadFile / NtWriteFile / NtQueryDirectoryFile / NtCreateThreadEx / NtWriteVirtualMemory / NtCreateMutant …）。可执行文件本身没有任何导入表，仅在 .rdata 内含 LoadLibraryA / GetProcAddress / Heap* 等 8 个 API 名字符串与 41 KB 高熵加密块，入口处使用 PEB 访问、rdtsc 计时差、int 2Dh 与 cpuid 做反分析，并大量使用不透明谓词与垃圾算术。文件内不存在的勒索文案在运行期出现在内存中，属于直接观测到的解混淆行为；据此判定为勒索类恶意软件。

## 行为分析

共 **8** 条行为，每条都挂了证据；其中 **3** 条静态可得、**5** 条经动态分析取得。

### 1. 运行期解密内置配置

`T1140` · 置信度 **高** · 动态

运行后把 .data 中的 41 KB 高熵（7.9）加密块解出为明文配置：勒索窗口文案、标识串“--k1176k”、128 字节随机材料与原生 API 名表，写入 .data 的 BSS 区（运行时 .data+0x47F30 起可见 ASCII 明文，而文件中该内容不存在，文件内 .data 起始处仍为密文）。

> **证据**：内存转储 t0：.data+0x47F30 “This is a VIRUS!!!!…CRYPT FILE!”、.data+0x46240 “--k1176k”、.data+0x44A10 128B 随机块；文件内 .data 0x8E800 起为熵 7.91 的密文
> 
> **来源**：`ref:564a3a1bea` · `ref:5f10e1ea3a` · `ref:8dc5e03186`

### 2. 按名解析原生 API

`T1106` · 置信度 **高** · 动态

运行期在 .data 构造 “kernel32.dll / ntdll.dll / user32.dll” 名表并据此加载模块、解析约 45 个 Nt* 原生函数，全部导入走 LoadLibraryA/GetProcAddress 的动态路径而非 PE 导入表。

> **证据**：内存 .data+0x450B0 “kernel32.dll/ntdll.dll/user32.dll”，.data+0x480A8 起连续 Nt* 名称表；进程模块表含 user32.dll、advapi32.dll、ws2_32.dll、bcryptPrimitives.dll
> 
> **来源**：`ref:5f10e1ea3a` · `ref:e6ae295e39`

### 3. 弹出勒索阻断提示

`T1486` · 置信度 **高** · 动态

以 “Warning” 为标题、正文 “This is a VIRUS!!!! Do you want to run the file? / To remove the window, you must CRYPT FILE!” 构造阻断式提示，把“移除窗口”与“加密文件”绑定，属勒索胁迫话术。

> **证据**：内存 .data+0x47F30 文案与 .data+0x47F90 “Warning”；user32.dll 运行期被加载
> 
> **来源**：`ref:5f10e1ea3a`

### 4. 具备遍历加密文件能力

`T1486` · 置信度 **中** · 动态

解析到的原生 API 覆盖目录枚举（NtQueryDirectoryFile）、文件打开/读写/属性修改（NtCreateFile、NtReadFile、NtWriteFile、NtSetInformationFile），并在解密配置中携带 128 字节随机密钥材料，构成“枚举—加密—改写文件”的完整实现要素（代码路径未在观测窗口内执行）。

> **证据**：内存 .data+0x480A8 名表含 NtQueryDirectoryFile/NtCreateFile/NtReadFile/NtWriteFile/NtSetInformationFile；.data+0x44A10 128B 随机材料
> 
> **来源**：`ref:5f10e1ea3a`

### 5. 反调试与反分析检测

`T1622` · 置信度 **高** · 静态

入口与多个函数使用 gs:[0x60] 读取 PEB、rdtsc 前后差值、int 2Dh 与 cpuid 组合做调试器/虚拟化探测，并对结果做异或/移位垃圾运算以掩盖判定。

> **证据**：entry 0x5FDB4：mov rax, qword ptr gs:[0x60] @0x5FDE8；rdtsc @0x5FDF0；int 2Dh @0x1328；cpuid @0x2124
> 
> **来源**：`ref:511b804e68` · `ref:fceeed7335`

### 6. 剥离导入表动态取 API

`T1027` · 置信度 **高** · 静态

PE 导入目录与 IAT 全为 0、无资源与 Rich 头，仅在 .rdata 保留 LoadLibraryA/GetProcAddress/GetModuleHandleA/ExitProcess/GetProcessHeap/HeapAlloc/HeapReAlloc/HeapFree 八个名字，并在 .text 内出现 CRC32(0xEDB88320) 与 FNV-1a(0x1000193) 常量，指向按名/按哈希的手工导入解析。

> **证据**：IMPORT rva=0 size=0、IAT rva=0；.rdata 0x8D9A7 起 8 个 API 名（被 0x7CC54 等函数 lea 引用）；0xEDB88320 @off 0x659D6；0x1000193 @off 0x5038E
> 
> **来源**：`ref:8dc5e03186` · `ref:91b9dd8d45`

### 7. 混淆代码并注入诱饵串

`T1027` · 置信度 **高** · 静态

1694 个 .pdata 函数普遍填充垃圾算术、不透明谓词与 nop，常量被拆成多次移位/异或；.rdata 混入大量随机双词标识符（如 “kenelXoutbound”、“mutex32srter”）、拉丁伪文段落与约 40 个随机 GUID，用于稀释相似度与特征提取。

> **证据**：.pdata 0xDC000 共 1694 项；.text 0x1000 起函数内含 rdtsc/异或链；.rdata 0x7F010 “modue_stage”、0x850xx 段 GUID 列表
> 
> **来源**：`ref:e6ae295e39` · `ref:d12250a6d6`

### 8. 常驻运行未建子进程

`T1497` · 置信度 **高** · 动态

进程自启动至观测结束（约 2.5 分钟）保持存活，未创建任何子进程、未写入自启动项/服务、未产生网络连接，属单体本地执行形态而非下载器。

> **证据**：watch 时间线 pid 4748 全程存活；监控组件 进程事件无父进程为 4748 的子进程；网络监控 日志无该 pid 的 DNS/TCP 记录
> 
> **来源**：`ref:564a3a1bea`

## 不应误判

:::important
以下结论**容易被误判**，引用本报告时请注意。

- 不要声称已观测到实际文件加密：观测窗口内没有文件加密事件，也没有勒索信文件落地，勒索提示仅存在于解密后的配置数据中，且会话未继续到加密阶段。
- 不要声称存在 C2 或外联能力：进程全程无 DNS/TCP 记录，配置中也没有主机、端口或 URI，属单机勒索形态。
- 不要把它归为下载器/投放器：无子进程、无落地文件、无临时目录写行为，虽有 ws2_32.dll 被加载但未见套接字通信。
:::

**局限与待验证**

1. 未观测到实际文件加密、勒索信落地或赎金指示；提示窗口为交互式对话框，沙箱内无人工点击，程序可能在此等待。
2. 加密算法未确证：静态与运行时均未命中 AES/RSA 轮常量或 S 盒，仅发现 128 字节随机材料，无法确认具体算法与密钥派生方式。
3. 家族归属为候选：缺少厂商命名、YARA 或公开沙箱报告佐证，仅依据 “CRYPT FILE” 阻断式话术与原生 API 能力集推断为 blocker/winlock 型勒索程序。

5. 沙箱客体对 Wi-Fi/显卡等服务有基线噪声，网络日志已按进程归属过滤；本样本相关记录为空。
