> 该 MSI 是同源 RDP Wrapper Library 1.6.2 安装包。反编译确认 RDPWInst 会替换 TermService 的 ServiceDll、重启服务，并由 rdpwrap.dll 挂钩/补丁 termsrv.dll 的许可与会话策略，放行多用户 RDP。该行为绕过 Windows 终端服务授权限制，属于 HackTool/PUA；未发现窃密、C2 或第三方载荷，因此不判 malicious。

## 行为分析

共 **9** 条行为，每条都挂了证据，且全部静态可得。

### 1. 解包 MSI 并释放组件

`T1027.009` · 置信度 **高** · 静态

MSI 的 CustomAction 表以 type 18 调用 RDPWInst.exe，安装命令为 -i -o；RDPWInst 再从 RT_RCDATA 资源释放 RDPW32/RDPW64（rdpwrap.dll）、RDPCLIP 各版本、RFXVMT 和 CONFIG（rdpwrap.ini）到目标目录。

> **证据**：MSI CustomAction=InstallAction/RDPWInst -i -o；FUN_0043d0f8 @ 0x43d0f8 调用 0x43cc44 释放 RDPW32/RDPW64/RDPCLIP/RFXVMT/CONFIG；RT_RCDATA 资源表见 0x3ca6c-0x3cc60。
> 
> **来源**：`ev-000044` · `ev-000036` · `ev-000045`

### 2. 写入终端服务 DLL

`T1543.003` · 置信度 **高** · 静态

RDPWInst 打开 HKLM\SYSTEM\CurrentControlSet\Services\TermService\Parameters，写入 ServiceDll 指向 rdpwrap.dll；在 64 位环境下还准备了通过 reg.exe add 写入 REG_EXPAND_SZ 的命令。

> **证据**：FUN_0043c598 @ 0x43c598 调用 SetValue(\"ServiceDll\")，键为 \\SYSTEM\\CurrentControlSet\\Services\\TermService\\Parameters；0x43c860 处拼接 reg.exe add 命令。
> 
> **来源**：`ev-000035` · `ev-000038`

### 3. 重启终端服务加载 DLL

`T1569.002` · 置信度 **高** · 静态

安装/更新路径会启用 SeDebugPrivilege，终止 TermService 相关进程后重新启动 TermService，使 svchost 加载被替换的 ServiceDll。

> **证据**：FUN_0043f7a4 @ 0x43f7a4：SeDebugPrivilege -> TerminateProcess -> 重启 TermService；FUN_0043a7bc @ 0x43a7bc 读取 TermService ImagePath。
> 
> **来源**：`ev-000037` · `ev-000038`

### 4. 挂钩许可策略查询

`T1562.001` · 置信度 **高** · 静态

rdpwrap.dll 挂钩 SLGetWindowsInformationDWORD 与 CSLQuery::Initialize，使终端服务在查询许可/策略时得到伪造结果，从而绕过单会话与许可限制。

> **证据**：RDPW64 字符串 \"Hook SLGetWindowsInformationDWORD\"、\"Hook SLGetWindowsInformationDWORDWrapper\"、\"Hook CSLQuery::Initialize\"；配置键 SLPolicyHookNT60/SLPolicyHookNT61。
> 
> **来源**：`ev-000045`

### 5. 内存补丁绕过会话限制

`T1562.001` · 置信度 **高** · 静态

按 rdpwrap.ini 中与 termsrv.dll 版本对应的偏移，对 CEnforcementCore::GetInstanceOfTSLicense、CSessionArbitrationHelper::IsSingleSessionPerUserEnabled、CDefPolicy::Query 等函数打内存补丁。

> **证据**：RDPW64 字符串 \"Patch CEnforcementCore::GetInstanceOfTSLicense\"、\"Patch CSessionArbitrationHelper::IsSingleSessionPerUserEnabled\"、\"Patch CDefPolicy::Query\"；导入 WriteProcessMemory/ReadProcessMemory/SuspendThread/ResumeThread。
> 
> **来源**：`ev-000045` · `ev-000016`

### 6. 放行多用户远程桌面

`T1133` · 置信度 **高** · 静态

内置 rdpwrap.ini 的 [SLPolicy] 将 AllowRemoteConnections、AllowMultipleSessions、AllowAppServerMode 等设为 1，并将 MaxUserSessions 等限制设为 0/1000，放行并发 RDP 会话。

> **证据**：CONFIG 资源 [SLPolicy]：TerminalServices-RemoteConnectionManager-AllowMultipleSessions=1、MaxUserSessions=0、8dc86f1d-9969-4379-91c1-06fe1dc60575-MaxSessions=1000。
> 
> **来源**：`ev-000045`

### 7. 下载最新 INI 配置

`T1105` · 置信度 **高** · 静态

使用 WinINet 从 stascorp/rdpwrap 的 GitHub raw 地址下载 rdpwrap.ini；-i -o（MSI 默认安装参数）会走在线安装模式，失败时回退到内置 CONFIG。

> **证据**：FUN_0043cf60 @ 0x43cf60：InternetOpenW -> InternetOpenUrlW -> InternetReadFile；URL 位于 0x3c460：hxxps://raw[.]githubusercontent[.]com/stascorp/rdpwrap/master/res/rdpwrap.ini；FUN_0043f7a4 下载失败时打印 GitHub 错误。
> 
> **来源**：`ev-000039` · `ev-000037` · `ev-000036`

### 8. 替换 RDP 剪贴板组件

`T1554` · 置信度 **高** · 静态

当 %SystemRoot%\System32\rdpclip.exe 或 rfxvmt.dll 不存在时，释放内嵌的对应架构/版本副本，以配合被挂钩的终端服务。

> **证据**：FUN_0043d0f8 @ 0x43d0f8：根据架构/版本选择 rdpclip6032/6064/6132/6164 或 rfxvmt32/64，并写入 %SystemRoot%\System32\rdpclip.exe、rfxvmt.dll。
> 
> **来源**：`ev-000036` · `ev-000045`

### 9. 探测终端服务配置

`T1012` · 置信度 **高** · 静态

安装前读取 TermService 的 ImagePath 和 Parameters\ServiceDll，仅接受 svchost.exe 宿主与 termsrv.dll/rdpwrap.dll，遇到第三方 TermService 库或自定义宿主则中止。

> **证据**：FUN_0043a7bc @ 0x43a7bc：读取 \\SYSTEM\\CurrentControlSet\\Services\\TermService 的 ImagePath 与 Parameters 的 ServiceDll，匹配 svchost.exe、termsrv.dll、rdpwrap.dll。
> 
> **来源**：`ev-000038`

## 不应误判

:::important
以下结论**容易被误判**，引用本报告时请注意。

- 不要将其判定为窃密木马或 RAT：未发现凭证/浏览器数据收集、键盘记录或命令控制回传。
- 不要将其判定为通用 dropper：MSI 仅安装同源 RDP Wrapper 组件，内嵌 CAB 只有 RDPWInst，未释放第三方恶意载荷。
- 不要声称已观察到 C2 或真实网络会话：唯一外部地址是官方 INI 更新源，且本次为纯静态分析，未执行样本。
- 不要声称它创建了新的后门账号或修改了账户口令：代码聚焦 Terminal Services 服务与许可策略，不涉及账户管理。
- 不要因为存在服务/注册表写入就判 ransomware/wiper：没有加密、删除或破坏用户数据的行为。
:::
