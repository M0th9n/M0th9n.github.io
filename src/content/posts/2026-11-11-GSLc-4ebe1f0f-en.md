> **Verdict: malicious** · family **GSLc** (uncertain) · confidence **medium**
> 
> Aliases: SmallSpy, WindowsDriverUpdate Telegram RAT, drivers RAT
> 
> The sample is a Telegram RAT written in .NET: it embeds a Base64-encoded bot token and chat_id, pulls commands via getUpdates, and provides a full feature set including keylogging, browser/Discord/Telegram/Steam/Wi-Fi credential theft, command execution, UAC bypass, logon persistence, screen and webcam capture, and self-destruction. Code-level static evidence and a real sandbox detonation both confirm it is an unauthorized remote-control program; in the dynamic phase the sample exited abnormally after startup and no actual outbound connection was observed, so C2 liveness rests on static evidence.

## Behavior analysis

**12** behaviors in total, each backed by evidence, and all are statically obtainable.

### 1. Decode the bot token

`T1027` · confidence **high** · static

On startup it uses Convert.FromBase64String and UTF8.GetString to decode the embedded Telegram bot token and chat_id, which are then used to build the remote-control session.

> **Evidence**: RVA 0x2048 get_BOT_TOKEN, 0x205e get_CHAT_ID; IL calls Convert::FromBase64String → Encoding::get_UTF8/GetString; api[.]telegram[.]org and config strings are visible in the memory dump
> 
> **Source**: `ref:e55e944b6d` · `ref:7c20c3b93b` · `ref:c0b127f8d3`

### 2. Poll Telegram for commands

`T1071.001` · confidence **high** · static

Polls api[.]telegram[.]org/bot<token>/getUpdates over HTTPS, parses update_id/message/text, and dispatches remote-control commands by instruction.

> **Evidence**: BotListener d__67; strings '/getUpdates?offset=', '&timeout=30', 'update_id', 'message', 'text'
> 
> **Source**: `ref:b0df0f0fcd` · `ref:43833b2876`

### 3. Write an HKCU Run entry

`T1547.001` · confidence **high** · static

Writes the current executable path to HKCU\Software\Microsoft\Windows\CurrentVersion\Run\WindowsDriverUpdate, achieving autostart at user logon.

> **Evidence**: RVA 0x2938 AddPersistence: Registry::CurrentUser → OpenSubKey("SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\Run", true) → SetValue("WindowsDriverUpdate", Application::ExecutablePath)
> 
> **Source**: `ref:e55e944b6d` · `ref:7693f0e731`

### 4. Register a logon scheduled task

`T1053.005` · confidence **high** · static

Calls schtasks to create a logon-triggered scheduled task named WindowsDriverUpdate with a 0001:00 delay, as a second persistence path.

> **Evidence**: RVA 0x2938 Process::Start at the end of AddPersistence; string schtasks /create /tn "WindowsDriverUpdate" /tr ... /sc onlogon /delay 0001:00 /f
> 
> **Source**: `ref:e55e944b6d` · `ref:43833b2876`

### 5. Log keystrokes

`T1056.001` · confidence **high** · static

Installs a WH_KEYBOARD_LL global low-level keyboard hook, translates keystrokes into a text buffer, and sends them back via /keylog or SendKeyLog.

> **Evidence**: RVA 0x3b28 KeyloggerWorker; SetWindowsHookEx / WH_KEYBOARD_LL / LowLevelKeyboardProc / WM_KEYDOWN / SendKeyLog
> 
> **Source**: `ref:b0df0f0fcd` · `ref:f91af1d11b` · `ref:43833b2876`

### 6. Steal browser credentials

`T1555.003` · confidence **high** · static

Enumerates Login Data and Cookies for Chrome/Edge/Opera/Brave/Vivaldi, reads os_crypt.encrypted_key from Local State, decrypts it via DPAPI, and extracts sites, usernames, passwords and cookies.

> **Evidence**: RVA 0x36d0 BrowserStealer; strings 'Login Data', 'SELECT origin_url, username_value, password_value FROM logins', 'os_crypt', 'encrypted_key', 'System.Security.Cryptography.ProtectedData'
> 
> **Source**: `ref:b0df0f0fcd` · `ref:f91af1d11b` · `ref:43833b2876`

### 7. Collect chat and gaming credentials

`T1555` · confidence **high** · static

Extracts tokens from Discord Local Storage (regex match), packages the Telegram tdata session directory, and reads Steam loginusers.vdf accounts plus cleartext Wi-Fi passwords via netsh wlan.

> **Evidence**: DiscordTokens 0x35e0, TelegramSteal 0x3a30, SteamAccounts 0x346c, WifiPasswords 0x2f4c; strings 'dQw4w9WgXcQ:', 'tdata', 'loginusers.vdf', 'wlan show profile name="' ... ' key=clear'

## What not to misjudge

:::important
The following conclusions are **easy to misjudge**; keep them in mind when citing this report.

- Do not conclude ransomware because the sample contains EncryptFiles/DecryptFiles and the XOR string: this is a directory XOR manually triggered by the operator via /encrypt, and no automatic encryption, ransom prompt or ransom note was observed.
- Do not treat the Telegram API as a confirmed active C2 session: only the token/chat_id were decoded from the static configuration here, the sample exited abnormally after startup in the sandbox, and network monitoring recorded no api[.]telegram[.]org request or response.
- Do not claim the sample actually wrote a registry Run entry or scheduled task: the code paths exist, but dynamic telemetry recorded no successful write by the sample to the Run key, SOFTWARE\drivers or schtasks.
- Do not treat the multi-engine generic MSIL/GSLc naming as a precise family verdict; the family attribution is only medium confidence.
:::

**Limitations and pending verification**

1. The sample exited abnormally about 5 seconds after startup in the sandbox (unhandled .NET exception, possibly related to VM detection or missing dependencies), so no Telegram communication, persistence or credential theft was observed; the C2 and configuration were extracted statically and need dynamic re-verification.
2. No api[.]telegram[.]org request appears in the network monitoring logs, so it cannot be confirmed that the bot token/chat_id are still valid in the current environment.
3. Family naming relies on multi-engine labels (GSLc/SmallSpy) and lacks cross-validation from vendor-private reports or YARA rules; the attribution is medium confidence and flagged as uncertain.
4. No decrypted browser database, Discord token or Telegram tdata sample was obtained; the credential-theft path is code-level evidence.
5. The UAC bypass and elevation chain were confirmed only at the code level, and their success rate was not verified in a real interactive environment.
