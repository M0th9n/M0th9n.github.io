## 行为分析

共 **12** 条行为，每条都挂了证据；其中 **9** 条静态可得、**3** 条经动态分析取得。

### 1. 解密内置配置

`T1140` · 置信度 **高** · 静态

读取 .stgcfg（魔数 CGTS，长度 0x9b0）并通过混淆控制流调用 BCrypt AES 解密运行期配置，失败时回退默认值。

> **证据**：0x140006ab0 校验 CGTS 后跳转；0x140006c06 载入宽字符 AES 并调用运行时解析的 BCrypt API；.stgcfg 熵 7.108；字符串 CONFIG: decrypted
> 
> **来源**：`ev-000005` · `ev-000023` · `ref:ebdcc14764` · `ev-000047`

### 2. 反虚拟机探测

`T1497.001` · 置信度 **高** · 静态

通过 CPUID hypervisor 位、CPUID 厂商串（vmware/vbox/kvm/xen）、SMBIOS RSMB 扫描、注册表键、进程名与时间/分辨率/最近文件数判断是否处于虚拟机或沙箱。

> **证据**：FUN_140003d40（CPUID/时间）、FUN_140004400（CPUID/注册表/进程/SMBIOS）、FUN_140003f30（进程数/Recent/屏幕）；字符串 vmtoolsd/VBoxService/qemu-ga/xenservice
> 
> **来源**：`ev-000034` · `ev-000035` · `ev-000036` · `ev-000046`

### 3. 屏蔽独联体语言

`T1614.001` · 置信度 **高** · 静态

读取系统/用户 UI 语言标识并与一组独联体语言 ID 比较，命中时记录 CIS: blocked 并退出，用于规避特定地区。

> **证据**：FUN_140004f40 使用 GetSystemDefaultUILanguage/GetUserDefaultUILanguage 并匹配位掩码 0x6c0400c8601；字符串 CIS: blocked / CIS: passed
> 
> **来源**：`ev-000031` · `ev-000015` · `ev-000046`

### 4. 建立单实例互斥体

> **证据**：FUN_1400053c0 调用 CreateMutex 并格式化 Global 互斥体名；主流程检查返回值后退出；字符串 MUTEX: ok / MUTEX: already running
