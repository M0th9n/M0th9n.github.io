## 行为分析

共 **11** 条行为，每条都挂了证据；其中 **6** 条静态可得、**5** 条经动态分析取得。

### 1. 经TON域名解析C2

`T1102` · 置信度 **高** · 动态

通过 tonapi[.]io 与 toncenter API 解析 remoteadministratortool.ton、webratxaye1.ton 的 TON DNS 记录，把链上记录作为 C2 端点发现通道，规避传统域名封禁。

> **证据**：main.tryTonResolve @0x8dfb60 / main.tonResolve @0x8dfd70；运行期 GET /v2/dns/remoteadministratortool.ton/resolve 与 POST runGetMethod(dnsresolve, webratxaye1.ton)
> 
> **来源**：`ev-000036` · `call_bc9853f763a94d7494aea76b`

### 2. 回连C2域名sa1atik

`T1071.001` · 置信度 **高** · 动态

运行期向 sa1atik[.]cn:443 反复发起 HTTP GET /sa1at/（约每 15 秒一次，共 12 次），请求体 88 字节，符合上线/心跳协议。

> **证据**：网络监控记录：PID 3260 TCP 443 -> sa1atik[.]cn，GET /sa1at/，Content-Type: application/octet-stream
> 
> **来源**：`ev-000036`

### 3. 写入Run键自启动

`T1547.001` · 置信度 **中** · 动态

向 SOFTWARE\Microsoft\Windows\CurrentVersion\Run 写入启动项，实现登录自启动。

> **证据**：内存字符串 SOFTWARE\Microsoft\Windows\CurrentVersion\Run；main.staticinstall/newTask 相关安装逻辑
> 
> **来源**：`ev-000036` · `call_bc9853f763a94d7494aea76b`

### 4. 加Defender排除项

`T1562.001` · 置信度 **高** · 动态

执行 PowerShell 调用 Add-MpPreference -ExclusionPath，把 Program Files、AppData、LocalAppData 加入 Defender 排除目录。

> **证据**：内存中的 PowerShell 脚本：Add-MpPreference -ExclusionPath $ProgramFiles/$AppData/$LocalAppData

## 不应误判

:::important
以下结论**容易被误判**，引用本报告时请注意。

- 不要报为 ransomware/wiper：样本没有文件加密或勒索信逻辑；reagentc /disable 是降低可恢复性的防御规避，不等于破坏数据。
- 不要报为纯 dropper/loader：程序自身即完整 RAT+窃密体，下载组件只是辅助功能（打包、RDP、音视频）。
- 不要声称已成功外传凭据/浏览器数据：动态窗口内只观测到 C2 解析与连接尝试，未见上传完成或数据回传内容。
- 不要给出 TON DNS 记录解析后的真实 C2 IP 或端口：沙箱无外网，解析响应未获得。
- 不要使用 Trojan/Generic 作为家族名：样本自带 WEBR 互斥体、webrat1 基础设施标识。
:::
