## Behavior analysis

**12** behaviors in total, each backed by evidence; **9** are obtainable statically and **3** were obtained through dynamic analysis.

### 1. Decrypt built-in configuration

`T1140` · Confidence **High** · Static

Reads .stgcfg (magic CGTS, length 0x9b0) and decrypts the runtime configuration with BCrypt AES through obfuscated control flow, falling back to defaults on failure.

> **Evidence**: 0x140006ab0 validates CGTS then jumps; 0x140006c06 loads the wide-character AES string and calls a runtime-resolved BCrypt API; .stgcfg entropy 7.108; string CONFIG: decrypted
> 
> **Source**: `ev-000005` · `ev-000023` · `ref:ebdcc14764` · `ev-000047`

### 2. Anti-VM probing

`T1497.001` · Confidence **High** · Static

Determines whether it is in a VM or sandbox via the CPUID hypervisor bit, CPUID vendor strings (vmware/vbox/kvm/xen), SMBIOS RSMB scanning, registry keys, process names, and time/resolution/recent-file counts.

> **Evidence**: FUN_140003d40 (CPUID/time), FUN_140004400 (CPUID/registry/process/SMBIOS), FUN_140003f30 (process count/Recent/screen); strings vmtoolsd/VBoxService/qemu-ga/xenservice
> 
> **Source**: `ev-000034` · `ev-000035` · `ev-000036` · `ev-000046`

### 3. Block CIS languages

`T1614.001` · Confidence **High** · Static

Reads the system/user UI language identifiers and compares them against a set of CIS language IDs; on a hit it logs CIS: blocked and exits, evading specific regions.

> **Evidence**: FUN_140004f40 uses GetSystemDefaultUILanguage/GetUserDefaultUILanguage and matches bitmask 0x6c0400c8601; strings CIS: blocked / CIS: passed
> 
> **Source**: `ev-000031` · `ev-000015` · `ev-000046`

### 4. Establish single-instance mutex

`T1480` · Confidence **High** · Static

Creates a mutex named Global plus 8 hex digits; if ERROR_ALREADY_EXISTS it logs MUTEX: already running and exits, preventing duplicate runs.

> **Evidence**: FUN_1400053c0 calls CreateMutex and formats the Global mutex name; the main flow checks the return value and exits; strings MUTEX: ok / MUTEX: already running
> 
> **Source**: `ev-000033` · `ev-000046`

### 5. Orchestrate 20 theft modules

`T1119` · Confidence **High** · Static

Iterates a 20-entry module table, creating threads to collect in parallel with 60/180-second timeouts, and exfiltrates the extracted results in chunks by index.

> **Evidence**: module table 0x140020660, 20×24 bytes; main flow CreateThread/WaitForSingleObject loop; string MODULES: all done
> 
> **Source**: `ev-000020` · `ev-000046` · `ref:9e8422b05a`

### 6. Steal browser credentials

`T1555.003` · Confidence **High** · Static

Locates Chrome/Edge/Brave/Opera/Yandex/Chromium/Firefox profile directories and reads Login Data, Web Data, History, Network\Cookies, and Local State, extracting passwords, credit cards, autofill, cookies, and Google tokens protected by DPAPI and app_bound_encrypted_key.

> **Evidence**: strings Login Data, Network\Cookies, Web Data, Local State, encrypted_key, app_bound_encrypted_key; output Browser/Passwords.txt, Browser/CreditCards.txt, Browser/Cookies/*
> 
> **Source**: `ev-000015` · `ev-000046`

### 7. Harvest wallets and sessions

`T1552.001` · Confidence **High** · Static

Copies desktop and browser-extension wallets (Exodus, Electrum, MetaMask, Phantom, TronLink, Coinbase, etc.) plus Discord/Telegram/Steam/Outlook/Thunderbird tokens, tdata, and configuration files.

> **Evidence**: strings Exodus\exodus.wallet, Electrum\wallets, wallet.dat, MetaMask, Messengers/Discord/Tokens.txt, Telegram Desktop\tdata, Games/Steam/Tokens.txt, Mails/Outlook/Profiles.txt

> **Evidence**: FUN_140018410 decrypts the strings AES, ChainingMode, ChainingModeGCM and calls BCryptGenerateSymmetricKey/BCryptEncrypt; FUN_140005ea0 derives the key with SHA256 and the label aokigahara; header X-KEX: x25519

> **Source**: `ev-000052` · `ev-000040` · `ev-000047` · `ev-000048`

## Do not misjudge

:::important
The following conclusions are **easy to misjudge**; keep this in mind when citing this report.

- It is not ransomware or a wiper: only data reading and exfiltration paths were found, with no file encryption, deletion, or destructive writes.
- It is not a downloader/dropper: no second-stage payload was observed being downloaded and executed from the C2; all 20 modules collect local data.
- No persistence was found: no service, scheduled-task, Run-key, or startup-folder writes were observed, so it should not be described as a resident backdoor.
- ip-api[.]com is a public IP geolocation service, not a C2, and should not be listed as malicious infrastructure.
- Polkadot{.js} (a wallet extension name) and x9dxdxe{199UUU} (an embedded obfuscated string) in the sample are not flags.
:::

| Item | Content |

**Limitations and open questions**

1. Dynamic observation captured only the sysinfo, screenshot, and filegraber chunks before receiving COMPLETE; the other modules produced no chunks in this run, affected by the sandbox user profile lacking browser/wallet data, so their capability is judged statically from the module table and target paths.
2. The sample contains complete anti-VM/sandbox detection, yet this dynamic run was not blocked; the checks are likely controlled by switches in the decrypted configuration, and their trigger conditions in other virtualized environments cannot be determined.
3. The built-in configuration is an AES-encrypted custom .stgcfg structure; algorithm details are inferred from BCrypt/AES calls and high-entropy data, while the host, build number, and token are directly confirmed by memory dumps.
4. No persistence or lateral movement was observed; subsequent capabilities enabled only after server-side instructions cannot be ruled out.
5. Analysis was completed in an isolated environment without executing the sample on the host; network IOCs are written de-weaponized.
