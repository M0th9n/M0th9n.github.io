## 行为分析

共 **12** 条行为，每条都挂了证据；其中 **10** 条静态可得、**2** 条经动态分析取得。

### 1. UPX 外壳自解压

`T1027.002` · 置信度 **高** · 动态

外层为 UPX（UPX0 熵 0、UPX1 熵 7.783），运行后把约 25MB 的 UPX0 段解压填充并跳入内层加载器；内存转储中该区已被写入。

> **证据**：内存转储 Minidump 内存范围 0x401000 长度 0x181c000 已填充；磁盘 UPX1 熵 7.783；入口 RVA 0x1C56150
> 
> **来源**：`ref:f386b0fd32` · `ref:0bb47ad3e4` · `ref:2450c7992f` · `ref:fe4daf07be`

### 2. 读取密钥解密载荷

`T1027` · 置信度 **高** · 静态

二次加载器打开 C:\Windows\mshlpda32.dll，并读取 C:\Windows\temp\setup_gitlog.txt 首字节，结合 CPUID 派生密钥流对 .text 做 XOR/add 解密；仿真观测到对应 CreateFileA/ReadFile 调用。

> **证据**：0x1C560B0 CreateFileA(C:\Windows\mshlpda32.dll) / 0x1C564BE CreateFileA(setup_gitlog.txt) + ReadFile 1 字节; CPUID 后循环写 0x401000 起字节; 内存 .text 与磁盘差异 10,650 字节
> 
> **来源**：`ref:d7c97717d4` · `ref:768d3bb1a8` · `ref:1c590e66e0`

### 3. 伪装微软服务宿主

`T1036.005` · 置信度 **高** · 静态

版本资源伪装为 sqhost.exe、Host Process for Windows Service、Microsoft Corporation、2.0.0[.]0，进程运行元数据同样显示该伪装信息。

> **证据**：VS_VERSION_INFO 字符串 sqhost.exe / Host Process for Windows Service / Microsoft Corporation；动态进程元数据 Product=sqhost.exe
> 
> **来源**：`ref:ece342d437` · `ref:2dbd472b0c`

### 4. 执行系统侦察命令

`T1082` · 置信度 **高** · 动态

派生 cmd.exe 执行 systeminfo 与 ping 8.8.8[.]8，并将输出重定向写入 C:\Windows\temp\setup_gitlog.txt，随后再派生 systeminfo.exe 完成主机信息采集。

> **证据**：动态进程创建事件：cmd.exe PID 4976，命令行 /c systeminfo>>C:\Windows\temp\setup_gitlog.txt&ping 8.8.8[.]8>>...；systeminfo.exe PID 6832
> 
> **来源**：`ref:25edfe24ec` · `ref:2dbd472b0c` · `ref:fe4daf07be`

### 5. 安装 UPlugPlay 服务

`T1543.003` · 置信度 **高** · 静态

通过 sc create/sc config 与 reg add 创建自启动服务 UPlugPlay，DisplayName 为 UPlug-and-Play Host，并把 ImagePath 指向投放文件，之后 sc start 启动。

> **证据**：字符串 0x4D594 '/C sc delete UPlugPlay&sc create UPlugPlay binPath= '；0x4D5D0 reg add HKLM\SYSTEM\CurrentControlSet\Services\UPlugPlay /v ImagePath；0x4D67C sc start UPlugPlay
> 
> **来源**：`ref:5f3d638aee` · `ref:772897c5f5`

### 6. 写入 Run 键自启动

`T1547.001` · 置信度 **高** · 静态

通过 reg add HKCU\Software\Microsoft\Windows\CurrentVersion\Run 写入自启动项，作为服务安装之外的用户态持久化。

> **证据**：字符串 0x4D710 '/C reg add HKCU\Software\Microsoft\Windows\CurrentVersion\Run /v ' 与 0x4D6E0 目标键名

> **来源**：`ref:5f3d638aee`

### 7. 放行防火墙规则

`T1562.004` · 置信度 **高** · 静态

### 9. 建立远程控制通道

### 11. 提权并调整访问令牌

**局限与待验证**

1. 动态窗口内仅观测到侦察子进程，未取得 200.111.174[.]22 的实际网络会话；C2 与 peer_chain 均为静态提取，recoverability=static 且 pending_dynamic_verify=true。

3. 未在动态沙箱中观察到 UPlugPlay 服务创建、Run 键写入或 mshlpda32.dll 投放；相应行为为静态代码/字符串能力判断，未升级为动态结论。
4. 家族命名基于 UPlugPlay、mshlpda32.dll、Dcomsvc/watchdog 等服务名与安装流程指纹，缺少解密配置或厂商命名交叉验证，故为 medium confidence 且 uncertain=true。
