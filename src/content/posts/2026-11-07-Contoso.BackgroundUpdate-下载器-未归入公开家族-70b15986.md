## 行为分析

共 **8** 条行为，每条都挂了证据；其中 **4** 条静态可得、**4** 条经动态分析取得。

### 1. 伪装系统更新组件

`T1036.005` · 置信度 **高** · 静态

资源中的 VERSIONINFO 与 manifest 伪装成 Canonical Ltd. 的 agent.exe / Configuration Tool 与 Contoso.BackgroundUpdate 后台更新服务，以降低用户与终端防护的怀疑。

> **证据**：资源 VERSIONINFO：CompanyName=Canonical Ltd.、InternalName=agent.exe；manifest assemblyIdentity=Contoso.BackgroundUpdate、description=Background Update Service
> 
> **来源**：`ref:213ceb6257` · `ref:c03f7e34d3`

### 2. XOR编码API名

`T1027` · 置信度 **高** · 静态

DLL 与 API 名称以单字节 XOR(0x4B) 编码存放（advapi32.dll、SystemFunction036、winhttp.dll、psapi.dll 等），运行时解码后经 LoadLibraryA/GetProcAddress 动态解析，规避导入表静态检测。

> **证据**：0x1a0ed 起 XOR 0x4B 字符串表（解码得 advapi32.dll/SystemFunction036/winhttp.dll/shell32.dll/psapi.dll）；LoadLibraryA/GetProcAddress 间接调用链
> 
> **来源**：`ref:ed3b4741f2` · `ref:d283e976d3`

### 3. 填充2MB诱饵数据

`T1027.001` · 置信度 **高** · 静态

PE 末尾追加 2155104 字节（约 2.1MB）重复可打印串（含循环的 Initializing runtime environment and loading required components 与固定 47 字节图案），人为放大文件体积，不参与执行。

> **证据**：文件偏移 542208..2697312 为重复图案填充；各 section 原始大小合计约 542KB，size_of_image 仅 569344
> 
> **来源**：`ref:213ceb6257` · `ref:235460ffd0` · `ref:c03f7e34d3`

### 4. 下载远程EXE载荷

`T1105` · 置信度 **高** · 动态

从硬编码 HTTPS 地址下载可执行载荷，落盘文件名为 payload.exe，位于当前用户的 %APPDATA% 目录。

> **证据**：内存字符串 hxxps://unostroagesdeel[.]cc/files/Btthhfx.exe；PE 内字符串 payload.exe / .exe / hxxps:// / APPDATA；0x140006d0d 调用 CreateFileA(GENERIC_WRITE,CREATE_ALWAYS)+WriteFile 写盘
> 
> **来源**：`ref:213ceb6257` · `ref:ea3aee02ce` · `ref:ed3b4741f2`

### 5. 落盘并命令行启动

`T1059.003` · 置信度 **高** · 静态

写盘完成后若文件为 .exe，则拼接 cmd.exe /c start "" "<路径>" 命令，以 CreateProcessA（CREATE_NO_WINDOW=0x08000000）隐藏窗口启动载荷。

> **证据**：0x140006d0d：0x14001b532 处 21 字节 cmd.exe /c start 前缀拼入路径后调用 CreateProcessA（dwCreationFlags=0x8000000）
> 
> **来源**：`ref:ea3aee02ce` · `ref:ed3b4741f2`

### 6. HTTPS回连C2

`T1071.001` · 置信度 **高** · 动态

运行后对 unostroagesdeel[.]cc 做 DNS 解析，并由样本进程自身向该主机 443 端口建立 TLS 连接（WinHTTP），用于获取载荷。

> **证据**：网络监控日志：04:20:30 记录 Received A request for domain 'unostroagesdeel[.]cc'，紧接着样本进程（PID 7428）请求 TCP 192.0.2[.]123:443；进程加载 winhttp.dll
> 
> **来源**：`ref:c426460242` · `ref:213ceb6257`

### 7. 查询Defender配置

`T1518.001` · 置信度 **中** · 动态

进程加载 WMI 组件（wbemprox/wbemcomn/wbemsvc/fastprox），内存中出现 root\Microsoft\Windows\Defender 与 MSFT_MpPreference，表明通过 WMI 读取 Microsoft Defender 偏好设置以探测防护状态。

> **证据**：内存转储字符串 root\Microsoft\Windows\Defender、MSFT_MpPreference；模块清单含 wbemprox.dll/wbemcomn.dll/wbemsvc.dll/fastprox.dll
> 
> **来源**：`ref:213ceb6257` · `ref:c426460242`

### 8. 枚举杀软与桌面进程

`T1057` · 置信度 **中** · 动态

内存中存在 explorer.exe 与 MsMpEng.exe（Microsoft Defender 主进程）字符串，配合 psapi 动态解析，用于进程枚举与安全软件识别。

> **证据**：内存转储字符串 explorer.exe、MsMpEng.exe；动态解析 psapi.dll
> 
> **来源**：`ref:213ceb6257` · `ref:ed3b4741f2`
