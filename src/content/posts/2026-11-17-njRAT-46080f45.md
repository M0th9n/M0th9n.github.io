> [!WARNING]
> **判定：恶意** · 家族 **njRAT**（存疑） · 置信度 **高**
> 
> 别名：Bladabindi、NJRat、Kognito recoder
> 
> 外层是 NSIS 自解压安装包，静态解包得到 4 个高度混淆的 JScript/VBS 脚本和 2 个 PE。脚本层解密后是 njRAT（Bladabindi）载荷，内置口令窃取、键盘记录、远程 shell、RDP/反向代理与 USB 传播；Torrent (1).exe 是带 PEB 遍历、ROR13 哈希、间接系统调用的 shellcode 加载器，并实现注册表、Active Setup、WMI 订阅、SYSTEM 计划任务等多路持久化。在隔离沙箱中真实引爆后，wscript.exe 向两个 njRAT C2 发送 POST /is-ready，Torrent (1).exe 外连 4784 端口并出现 Pulsar RAT 协议报文，恶意行为被直接观测。

## 行为分析

共 **12** 条行为，每条都挂了证据；其中 **9** 条静态可得、**3** 条经动态分析取得。

### 1. 自解包释放六文件

`T1027.009` · 置信度 **高** · 静态

样本是 NSIS 自解压安装包，运行后把 Torrent+ Installer.exe、Torrent (1).exe 以及 4 个伪装成种子文件的 JScript/VBS 脚本释放到临时目录再执行。

> **证据**：主样本 0x2A804 处 0xDEADBEEF + 'NullsoftInst' 头（文件偏移 174084），解包清单 6 个文件
> 
> **来源**：`ev-000009` · `ev-000034`

### 2. 解密内置 shellcode

`T1027` · 置信度 **高** · 静态

Torrent (1).exe 从 .rdata 取 0x1848cc 字节密文，对每个 32 位字先循环左移 13 位再异或 0xDEADBEEF，还原出后续执行的 shellcode。

> **证据**：FUN_140001870 @0x140001870（ROL13+ XOR 解码）与 FUN_1400033c0 @0x1400033c0（立即数 0xdeadbeef）
> 
> **来源**：`ev-000027` · `ev-000028`

### 3. PEB 遍历取系统调用

`T1106` · 置信度 **高** · 静态

加载器通过 PEB 遍历定位 ntdll/kernel32，用 ROR13 哈希解析导出函数，读取 NtAllocateVirtualMemory 等函数的 SSN 并搜索 syscall;ret gadget，改用间接系统调用规避用户态钩子。

> **证据**：0x1400033c0 中 PEB Walking / Export Table Walking / SSN / gadget 流程，字符串见 0x140005048 起
> 
> **来源**：`ev-000028`

### 4. 内存中执行 RAT

`T1620` · 置信度 **高** · 静态

解码后的 shellcode 先写入 RW 内存，经 NtProtectVirtualMemory 改为 RX，再由 NtCreateThreadEx 创建线程执行，全程不落盘（进程内自注入）。

> **证据**：0x1400033c0 步骤 [7][9][10]：VirtualAlloc(0x1848cc) → NtProtectVirtualMemory → NtCreateThreadEx
> 
> **来源**：`ev-000028`

### 5. 四路持久化自启

`T1547.001` · 置信度 **高** · 静态

加载器写入 HKCU Run\WindowsSecHealth、HKLM Active Setup 的 StubPath、创建 SYSTEM 权限登录计划任务 WindowsSecurityHealth，并将自身复制为 %STARTUP%\Windows\UpdateService.exe。

> **证据**：FUN_1400019a0 @0x1400019a0（Run 键）、FUN_140001ae0 @0x140001ae0（Active Setup）、FUN_140001950 @0x140001950（schtasks）、FUN_140001a40 @0x140001a40（启动目录）
> 
> **来源**：`ev-000032` · `ev-000033` · `ev-000038` · `ev-000030`

### 6. 植入 WMI 事件订阅

`T1546.003` · 置信度 **高** · 静态

通过隐藏 PowerShell 创建 __EventFilter（SysHealth）与 CommandLineEventConsumer（SysHealthC）并绑定，借每 60 秒的系统性能事件反复拉起自身。

> **证据**：FUN_140001ba0 @0x140001ba0，WinExec 传入 powershell.exe -WindowStyle Hidden ... root\subscription
> 
> **来源**：`ev-000031`

### 7. 脚本释放隐藏 .NET

`T1027.009` · 置信度 **中** · 静态

Torrent (1).js 将内嵌 base64 .NET 载荷写入 %TEMP%\<随机>.exe，设为隐藏+系统属性并以隐藏窗口启动，再复制到 %APPDATA%\<随机>_cache、写 Run 键与启动目录 lnk，同时把自身复制为 .js 注册 wscript 自启，5 秒后删除原文件。

> **证据**：解密后的脚本：ActiveXObject('ADODB.Stream') / SaveToFile / Attributes=6 / Run(...,0) / HKCU\...\Run\ / CreateShortcut
> 
> **来源**：`ev-000034`

### 8. njRAT 上线两个 C2

`T1071.001` · 置信度 **高** · 动态

两个解密后的 JScript 载荷经 wscript.exe 常驻，分别向 hxxp://netframework[.]dynamic-dns[.]net:8000 与 hxxp://redlan[.]linkpc[.]net:8000 发送 POST /is-ready 上线，并按服务端指令执行 shell、文件管理、下载执行、更新等。

> **证据**：沙箱网络监控：wscript.exe (pid 2924/5872) POST /is-ready，Host: netframework[.]dynamic-dns[.]net:8000 / redlan[.]linkpc[.]net:8000
> 
> **来源**：`ev-000034` · `ev-000036`

### 9. 窃取口令键盘记录

`T1056.001` · 置信度 **中** · 静态

njRAT 载荷内置 passgrabber 与 get-pass / get-pass-offline 指令，按需下载 wshsdk（内含 python.exe）抓取浏览器和系统凭据；另有 keyloggerstarter、reverseproxy、servicestarter、enumprocess、USB 传播等远程控制能力。

> **证据**：解密脚本函数 passgrabber / gsp / decode_pass / keyloggerstarter / reverseproxy / servicestarter / usbspreading
> 
> **来源**：`ev-000034`

### 10. Pulsar回连4784

`T1095` · 置信度 **高** · 动态

Torrent (1).exe 在内存中执行 shellcode 后解析 Netframework[.]strangled[.]net 并连接 TCP 4784，上线报文含明文 Pulsar.Common.Messages.Other.Secure 与 Envelope 标记；同时访问 ipwho.is、api[.]ipify[.]org 做地理位置探测。

> **证据**：沙箱网络监控：Torrent (1).exe (pid 1072/6740) → 192.0.2[.]123:4784，报文偏移 0x12 起 'Pulsar.Common.Messages.Other.Secure'
> 
> **来源**：`ev-000036`

### 11. 伪装商店安装器

`T1036.005` · 置信度 **中** · 动态

包内 Torrent+ Installer.exe 是 Microsoft Store Installer（22609.1501.4.0），被用作“安装 Torrent+ 应用”的诱饵；沙箱中它只访问微软商店域名，不携带 RAT 逻辑。

> **证据**：程序集 StoreInstaller / 属性 Microsoft Corporation 22609.1501.4.0；动态访问 storeedge[.]microsoft[.]com
> 
> **来源**：`ev-000021` · `ev-000035` · `ev-000036`

### 12. 内嵌未启用的木马

`T1027.009` · 置信度 **高** · 静态

Torrent (1).vbs 内嵌一个 QuasarRAT 系 .NET 客户端（程序集 Client 1.3.0[.]0，命名空间 xClient，含浏览器凭据恢复与鼠标键盘钩子），但整个 VBS 每行都被单引号注释，实际不会执行。

> **证据**：VBS 首行起每行以 ' 开头；自 base64 还原的 PE 元数据 Assembly=Client 1.3.0[.]0，xClient.Core.Recovery.Browsers / MouseKeyHook
> 
> **来源**：`ev-000034` · `ev-000035`

## 不应误判

:::important
以下结论**容易被误判**，引用本报告时请注意。

- 不要因为包含 Torrent+ Installer.exe 与商店安装逻辑就把整个样本定性为普通软件捆绑安装器（pua_bundler）；脚本层实际投递并运行了 RAT。
- 不要把 Torrent+ Installer.exe（Microsoft Store Installer）本身认定为恶意载荷，它是被复用的正规安装组件。
- 不要因为出现 base64/编码字符串就断言使用 AES 或勒索加密；本次未观测到文件加密、勒索说明或挖矿行为。
- 不要仅凭 C2 未收到服务端响应就否定投递链，沙箱中已实际观测到 njRAT 上线请求与 Pulsar 协议帧。
:::
