> [!WARNING]
> **判定：恶意** · 家族 **Yhwach**（存疑） · 置信度 **中**
> 
> 别名：Yhwach Loader、AutoIt/LuaJIT loader
> 
> 从 MSI 内嵌 cabinet 解出四个组件：AutoIt 可执行文件 Yhwach.exe、AutoIt 明文脚本 Yhwach.ini、被改名为 vcruntime140.dll 的 LuaJIT 2.0.4、以及 Lua 脚本 environment.ini。脚本以标准 base64 加固定三字节密钥 0x12/0x34/0x56 异或解出一个 479232 字节的 VB6 PE（funked.exe），随后通过 LuaJIT FFI 调用 CreateProcessW/NtUnmapViewOfSection/VirtualAllocEx/WriteProcessMemory/SetThreadContext 对 ping.exe、mshta.exe、rundll32.exe、csc.exe、RegAsm.exe、MSBuild.exe 之一做进程镂空注入。该 VB6 载荷具备浏览器登录与信用卡读取、FTP 与邮件客户端凭据收集、WMI 主机侦察、RunOnce 持久化，以及经 SMTP/Telegram 外传的能力。整条链无正常软件用途。

## 行为分析

共 **10** 条行为，每条都挂了证据，且全部静态可得。

### 1. 伪装系统服务安装包

`T1036.005` · 置信度 **高** · 静态

MSI 产品名设为 Windows System Service、厂商写 Microsoft Corporation、版本 3.18.0，使用 WiX Toolset 构建，但安装内容与 Windows 服务无关。

> **证据**：MSI 数据库 Property 表字符串 ProductName=Windows System Service / Manufacturer=Microsoft Corporation
> 
> **来源**：`ref:2bb9617baa` · `ref:9126bb234c`

### 2. 释放四件套并启动宿主

`T1105` · 置信度 **高** · 静态

安装包释放 Yhwach.exe、Yhwach.ini、vcruntime140.dll、environment.ini 四个文件，并通过自定义动作 RunAppFromTemp 以 "[INSTALLFOLDER]Yhwach.exe" "[#YhwachIni]" 立即启动。

> **证据**：MSI File 表（Yhwach.exe / Yhwach.ini / ovihklqt.dll|vcruntime140.dll / u1mwucek.ini|environment.ini）与 CustomAction 表 RunAppFromTemp
> 
> **来源**：`ref:9126bb234c` · `ref:2bb9617baa`

### 3. AutoIt 调 LuaJIT 执行脚本

`T1059.010` · 置信度 **高** · 静态

Yhwach.ini 用 DllOpen 打开同目录 vcruntime140.dll（实际是 LuaJIT 2.0.4），再经 DllCall 调用 luaL_newstate、luaL_openlibs、luaL_loadfile、lua_pcall 执行 environment.ini，脚本以 pcall(R) 自动运行。

> **证据**：Yhwach.ini 中 DllOpen(@ScriptDir & "\vcruntime140.dll") 与 luaL_loadfile(envirnment.ini)；vcruntime140.dll 内含 LuaJIT 2.0.4 / luaL_* 导出
> 
> **来源**：`ref:260e5b45be` · `ref:dd1a5a3b68`

### 4. 自解码内置载荷

`T1140` · 置信度 **高** · 静态

environment.ini 先做标准 base64 解码，再用固定循环密钥 {18,52,86} 逐字节异或，解出 479232 字节的 PE32（stage2），并校验非空后交给注入函数。

> **证据**：Lua 源码 local u={18,52,86} 与 local function H(N,y) ... U.bxor(N[y],H)；解出 MZ/PE32，SHA256=41def1bee0cdb7c97d39f74676914dc994e9b571d403334a991e67832e074f53
> 
> **来源**：`ref:3ee2b77f60` · `ref:22a1e54324`

### 5. 镂空注入系统进程

`T1055.012` · 置信度 **高** · 静态

以 CREATE_SUSPENDED 启动 ping.exe、mshta.exe、rundll32.exe、csc.exe、RegAsm.exe 或 MSBuild.exe 之一，调用 NtUnmapViewOfSection 卸载原映像，VirtualAllocEx 按原 ImageBase 分配，WriteProcessMemory 写头与节，改 PEB+8 的 ImageBaseAddress 并把线程 Eax 指向新入口后 ResumeThread。

> **证据**：environment.ini CreateProcessW(...,4,...)、NtUnmapViewOfSection、VirtualAllocEx、WriteProcessMemory、SetThreadContext、ResumeThread；目标路径 C:\Windows\SysWOW64\ping.exe 等六个
> 
> **来源**：`ref:22a1e54324` · `ref:c618c81c16` · `ref:c981e5b2b3`

### 6. 窃取浏览器账号与信用卡

`T1555.003` · 置信度 **高** · 静态

读取 Chromium 系（Chrome/Edge/Brave/Epic/Torch 等）与 Firefox 系配置目录，执行 SELECT origin_url, username_value, password_value FROM logins 及 credit_cards 查询，并用正则识别 Amex、BCGlobal、Carte Blanche 等卡号。

> **证据**：UTF-16 字符串 SELECT origin_url, username_value, password_value FROM logins；SELECT name_on_card, expiration_month, expiration_year, card_number_encrypted FROM credit_cards；^3[47][0-9]{13}$
> 
> **来源**：`ref:0966f117b6` · `ref:908244664e`

### 7. 收集 FTP 与邮件凭据

`T1552.001` · 置信度 **高** · 静态

从 FileZilla sitemanager/recentservers、CoreFTP、WinSCP、Foxmail 及 Windows Mail/Outlook 注册表配置中提取服务器、用户名与口令。

> **证据**：Application : FileZilla / CoreFTP / WinSCP 2、Foxmail.url.mailto 注册表路径、moz_logins 与 SMTP/POP3/IMAP 字段
> 
> **来源**：`ref:94088c21da` · `ref:0966f117b6`

### 8. SMTP 与 Telegram 外传

`T1048` · 置信度 **高** · 静态

硬编码 SMTP 主机 cphost17[.]qhoster[.]net 与账号 onwalogs@exzwzc[.]com、winnerman2026@exzwzc[.]com（口令 Qwerty!@#），用 CDO.Message 发送附件；同时拼接 hxxps://api[.]telegram[.]org/bot 与 /sendDocument?chat_id= 上传文件。

> **证据**：UTF-16 字符串 cphost17[.]qhoster[.]net / onwalogs@exzwzc[.]com / Qwerty!@# / hxxps://api[.]telegram[.]org/bot / /sendDocument?chat_id= / CDO.Message
> 
> **来源**：`ref:0966f117b6` · `ref:94088c21da`

### 9. RunOnce 持久化

`T1547.001` · 置信度 **高** · 静态

向 HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\RunOnce\ 写入以 *RD_ 为前缀的项，实现登录后自启动并配合 cmd 批处理自删。

> **证据**：UTF-16 字符串 HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\RunOnce\*RD_ 与 @TITLE Removing / @RD /S /Q
> 
> **来源**：`ref:0966f117b6`

### 10. 安装后自清理

`T1070.004` · 置信度 **高** · 静态

安装完成后由隐藏 PowerShell 延时 4 秒删除 environment.ini 与 vcruntime140.dll，再延时 6 秒执行 msiexec /x [ProductCode] /qn 静默卸载安装包。

> **证据**：CustomAction DeleteExtraFiles / SelfUninstall 的 PowerShell 命令行（Remove-Item -LiteralPath 与 Start-Process msiexec.exe）
> 
> **来源**：`ref:2bb9617baa` · `ref:9126bb234c`

## 不应误判

:::important
以下结论**容易被误判**，引用本报告时请注意。

- 不能仅凭 AES/BCryptOpenAlgorithmProvider 就判定为勒索软件；该 AES 只用于打包/加密外传数据。
- 不能在未实际运行的情况下声称已观测到 C2 会话或数据外传成功；本次为纯静态分析，SMTP/Telegram 仅来自硬编码字符串。
- 不能把 showip[.]net、mediacollege[.]com 当作 C2，它们只是公网 IP 查询服务。
- 不能声称 Telegram bot token 或 HTTP 网关已配置；样本中仅有 @StrBotToken、@GateUrl 占位符。
- 不能把 MSI 的 Microsoft Corporation / Windows System Service 元数据当作合法签名或可信来源。
:::
