## 行为分析

共 **12** 条行为，每条都挂了证据；其中 **9** 条静态可得、**3** 条经动态分析取得。

### 1. 内存加载内置DLL

`T1620` · 置信度 **高** · 动态

从 .rsrc 的 RCDATA 资源（数据 RVA 0x2E50D0，298,496 字节）取出内嵌 PE，其导出为 chrome_decrypt.dll!Bootstrap；加载器将其手工映射进自身进程，并用命名管道与 __DLL_PIPE_COMPLETION_SIGNAL__ 完成同步。动态内存中存在该 DLL 镜像，但动态加载的模块列表中没有对应模块。

> **证据**：RCDATA RVA 0x2E50D0 size 298496；字符串 'Could not find entry point in payload' @0x28AD20 与 '__DLL_PIPE_COMPLETION_SIGNAL__' @0x28AE60；内存 0x710510 处 chrome_decrypt.dll/Bootstrap
> 
> **来源**：`ev-000051` · `ev-000052` · `ev-000038`

### 2. 解密内置配置

`T1027` · 置信度 **高** · 动态

RT_MESSAGETABLE 资源（RVA 0x32DED0，22,806 字节）以 base64/逐字符混淆保存，运行时解出管道分隔配置，包含 C2 主机、端口、密钥、功能开关与伪装进程名。

> **证据**：资源 RVA 0x32DED0；内存明文 '31.77.232[.]57|6000|0|NONE|NONE|Mj6pdS9AJ5wAK0GxYBv|...|15TDHiOv|svchost.exe|FALSE'
> 
> **来源**：`ev-000051` · `ev-000052`

### 3. 回连C2接收指令

`T1095` · 置信度 **高** · 动态

样本启动约 40 秒后开始向 31.77.232[.]57:6000 反复建立 TCP 会话，5 分钟内约 50 次重连，会话载荷为高熵密文，符合自定义加密远控协议。

> **证据**：网络监控: pid 7052 -> TCP 31.77.232[.]57:6000 (02:57:06 起, 约50次)；RawTCP 抓取为随机密文
> 
> **来源**：`ev-000052` · `ev-000053` · `ref:35fa90e2fe`

### 4. 窃取浏览器凭据

`T1555.003` · 置信度 **高** · 静态

枚举 Chrome/Edge/Brave/Yandex/Opera/CocCoc/Avast 与 Firefox/Thunderbird 的 Login Data、Cookies、Local State、logins.json、key4.db，并通过 os_crypt/DPAPI（CryptUnprotectData）及 nss3.dll 解密，打包为 browser-data.zip。

> **证据**：文件偏移 0x274FA0 Chromium cookie 查询、0x279050 Firefox moz_cookies 查询、0x279F90 Login Data、0x279E80 Local State、0x2790C8 nss3.dll；导入 CryptUnprotectData @IAT 0x2530F8
> 
> **来源**：`ev-000056` · `ev-000022` · `ref:4eb306b755`

### 5. 打包Telegram会话

`T1528` · 置信度 **高** · 静态

定位 %LOCALAPPDATA%\Telegram Desktop\tdata 及 Program Files 安装目录，将 tdata 打包为 telegram.zip 回传；同时读取 Discord 的 Local State 与 Local Storage\leveldb，输出 DiscordTokens.txt。

> **证据**：字符串 0x273890 '\\Telegram Desktop\\tdata'、0x277020 'telegram.zip'、0x2786D8 '\\discord\\Local State'、0x2770D0 'DiscordTokens.txt'
> 
> **来源**：`ev-000056` · `ev-000022`

### 6. 枚举钱包扩展

`T1555` · 置信度 **高** · 静态

内置 40 余个浏览器钱包扩展 ID（MetaMask、Coinbase、Exodus、Jaxx 等）及 Local Extension Settings 路径，用于提取助记词、私钥与扩展数据。

> **证据**：扩展 ID 表 0x28C930-0x28E0D0；MetaMask @0x28C9C8；路径 '\\Local Extension Settings' @0x28DF68
> 
> **来源**：`ev-000056` · `ev-000022`

### 7. 隐藏桌面远程控制

`T1219` · 置信度 **高** · 静态

实现 HVNC 隐藏桌面（CreateDesktopW/SwitchDesktop/SetThreadDesktop）、文件管理器（列目录、上传/下载、删除、加解密）以及弹窗、提权、关机、卸载等远程指令。

> **证据**：字符串 HVNCSTART/HVNCINPUT/HVNC_Desktop_ @0x277128/0x27A830；FILEMANAGER*LIST*/DOWNLOAD/FILESAVED；CreateDesktopW/SwitchDesktop @IAT 0x2538F0/0x2538E8
> 
> **来源**：`ev-000055` · `ev-000022`

### 8. 远程执行PowerShell

`T1059.001` · 置信度 **高** · 静态

接收 POWERSHELLEXECUTE 指令后，以 powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -Command - 启动管道会话执行命令并回传输出。

> **证据**：字符串 0x277210 POWERSHELLSTART/0x2772D0 POWERSHELLEXECUTE；0x28B6B0 'powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -Command -'；CreateProcessW @IAT 0x253388
> 
> **来源**：`ev-000055` · `ev-000022`

### 9. 采集屏幕与音视频

`T1113, T1125, T1123` · 置信度 **高** · 静态

通过 BitBlt/GetDIBits/GDI+ 抓屏保存 screenshot.png；用 Media Foundation 枚举摄像头采集画面；用 waveIn 系列 API 录音保存 recording.wav。

> **证据**：字符串 SCREENSHOT @0x2776F0、screenshot.png @0x2770B0、WEBCAMERASTART @0x277128、recording.wav @0x277090；导入 MFEnumDeviceSources/waveInOpen/GdipSaveImageToStream
> 
> **来源**：`ev-000055` · `ref:4eb306b755`

### 10. 记录键盘输入

`T1056.001` · 置信度 **高** · 静态

使用 SetWindowsHookExW 与 GetKeyState/ToUnicodeEx 记录前台按键并写入 keylogs.txt，由 KEYLOGGERDATA 指令回传。

> **证据**：字符串 0x2770E8 keylogs.txt、0x2777F0 KEYLOGGERDATA；导入 SetWindowsHookExW/GetKeyState/ToUnicodeEx @IAT 0x253920/0x2539A8/0x253978

> **来源**：`ev-000055` · `ref:4eb306b755`

### 11. 写入Run键自启动

`T1547.001` · 置信度 **中** · 静态

通过 RegSetValueExW 向 HKCU\Software\Microsoft\Windows\CurrentVersion\Run 写入自启动项；本次动态运行未观察到该键被写入。

> **证据**：字符串 0x28BC20 'Software\\Microsoft\\Windows\\CurrentVersion\\Run'；导入 RegSetValueExW @IAT 0x253000

## 不应误判

:::important
以下结论**容易被误判**，引用本报告时请注意。

- 不能仅凭截图/摄像头/麦克风 API 就把它定性为普通远程控制工具：其核心动机是浏览器凭据、Cookie、Telegram/Discord 会话与钱包数据的窃取。

- 动态期间未观察到文件落地、Run 键写入或子进程，不能声称持久化已生效或存在已释放的二次载荷。
- 不应把 WLDAP32、PFXImportCertStore、证书链等导入单独当作攻击能力，这些来自静态链接的 libcurl/Windows 证书栈。
- 未观察到横向移动、漏洞利用或蠕虫式传播，不应标注为 worm/exploit。
:::
