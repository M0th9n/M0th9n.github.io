## 行为分析

共 **9** 条行为，每条都挂了证据，且全部静态可得。

### 1. 伪装 PDFgear 组件

`T1036.005, T1574.002` · 置信度 **高** · 静态

版本资源与程序集名冒充合法 PDFgear 公共库（CommonLib.dll / PDFgear Software / 2.1.18[.]0），内部却包含 BeCtrl 远程控制命名空间；宿主调用看似正常的 PDFgear 数据库初始化接口 SqliteUtils.InitializeDatabase 时，第一句即转入恶意引导 BeCtrlBootstrap.EnsureStarted。

> **证据**：版本资源 Comments="PDFgear Common Library"、InternalName="CommonLib.dll"；CommonLib.Config.SqliteUtils.InitializeDatabase 的 IL 首条指令为 call BeCtrlBootstrap.EnsureStarted（方法 RVA 0x5a53）；BeCtrlBootstrap.EnsureStarted RVA 0x20a0
> 
> **来源**：`ref:86879eaabd` · `ref:9606c725ef` · `ref:c2a43e98bb`

### 2. 写入 Run 键持久化

`T1547.001` · 置信度 **高** · 静态

通过注册表 HKCU\Software\Microsoft\Windows\CurrentVersion\Run 写入值 "PDFgear FileSync"，指向落地的 RegExt.exe，实现当前用户登录自启动。

> **证据**：.Persistence.TrySetRunKey（方法 RVA 0x2510）调用 Registry.CurrentUser.OpenSubKey("Software\\Microsoft\\Windows\\CurrentVersion\\Run") 并 SetValue("PDFgear FileSync", 带引号路径)
> 
> **来源**：`ref:c2a43e98bb`

### 3. 复制宿主与库文件

`T1574.002` · 置信度 **高** · 静态

把当前宿主进程的主模块复制为 %LOCALAPPDATA%\PDFgear\Services\RegExt.exe，并将同目录的 CommonLib.dll 一并复制到该目录，形成可被 Run 键拉起的合法外观程序加侧加载 DLL 组合；若当前已在目标目录则直接退出避免递归。

> **证据**：.Persistence.Install（方法 RVA 0x2398）：Environment.GetFolderPath(LocalApplicationData)+ "PDFgear\\Services"，File.Copy(Process.GetCurrentProcess.MainModule.FileName, ...\\RegExt.exe)，并复制 CommonLib.dll
> 
> **来源**：`ref:c2a43e98bb` · `ref:0126196c48`

### 4. 父进程伪装启动

`T1134.004` · 置信度 **高** · 静态

枚举 explorer.exe 的 PID，以 OpenProcess 取得句柄后通过 UpdateProcThreadAttribute 设置 PROC_THREAD_ATTRIBUTE_PARENT_PROCESS，再创建子进程，使 RegExt.exe 与远程命令进程在进程树上表现为 explorer.exe 的子进程，规避基于父进程的检测。

> **证据**：BeCtrl.Compat.ExplorerLauncher.Start（方法 RVA 0xafd4）：FindExplorerPid → OpenProcess(0x80) → InitializeProcThreadAttributeList → UpdateProcThreadAttribute(PROC_THREAD_ATTRIBUTE_PARENT_PROCESS, explorer handle) → CreateProcessW；Persistence.Install 与 CmdExecutor.RunJobAsync 均调用该函数
> 
> **来源**：`ref:c2a43e98bb`

### 5. UDP/53 与 WSS 双通道

`T1095, T1071.001, T1008` · 置信度 **高** · 静态

默认优先使用 UDP 通道且端口固定为 53（伪装 DNS 流量），失败后按 443、80、22、21、8080、1080 顺序尝试 WSS；连接失败按 1s/3s/5s/10s/30s 退避重连，并记住上次成功通道。会话心跳 8 秒一次，连续 8 次缺失判定掉线。

> **证据**：BeCtrl.Config.ClientDefaults 解码值：UDPPorts=[53]、WssPorts=[443,80,22,21,8080,1080]、ProtocolPriority="UDP"、ReconnectBackoffMs=[1000,3000,5000,10000,30000]；Protocol.ProtocolConst：Magic=0x50524F31、UDPMaxFrame=1400、WssMaxFrame=65535、HBIntervalMs=8000、HBMissThreshold=8；ChannelPicker.BuildCandidates 按 IP×端口生成候选
> 
> **来源**：`ref:c2a43e98bb`

### 6. RSA+AES 加密会话

`T1573.001, T1573.002` · 置信度 **高** · 静态

登录阶段用内置 RSA-2048 公钥以 OAEP 填充包装随机会话密钥，登录成功后改用 AES-256-GCM 加密全部帧；帧头含魔数 "PRO1"、版本、标志、负载长度、CRC32，GCM 使用 12 字节 nonce 与 16 字节认证标签，且默认跳过 TLS 证书校验。

> **证据**：ProtocolConst：Magic=0x50524F31、Version=1、HeaderSize=36、RsaKeyBits=2048、RsaCipherSize=256、AesKeySize=32、AesNonceSize=12、AesTagSize=16；Protocol.RsaOaepCodec/BcryptRsaOaep 与 Protocol.AesGcmCodec/BcryptAesGcm；ClientDefaults.SkipCertValidation=true；二进制内嵌 2048 位 RSA 公钥 PEM
> 
> **来源**：`ref:c2a43e98bb` · `ref:9606c725ef`

### 7. 远程执行 cmd 命令

`T1059.003` · 置信度 **高** · 静态

接收 C2 的 CmdRequest（命令路径、命令行、超时、工作目录、捕获模式），默认使用 C:\Windows\System32\cmd.exe 以 /c 方式执行，把 stdout/stderr 重定向到临时文件后分块回传，默认超时 30 秒，并用父进程伪装方式启动。

> **证据**：BeCtrl.Business.Cmd.CmdExecutor.BuildArgs（方法 RVA 0xfdb8）："/c " + cmdline + " > \"" + stdoutPath + "\" 2>&1"（另有独立 stderr 分支）；RunJobAsync 调用 ExplorerLauncher.Start 创建进程并按块发送 CmdResponse；ProtocolConst.CmdDefaultTimeoutMs=30000
> 
> **来源**：`ref:c2a43e98bb`

### 8. 下发文件到指定路径

`T1105` · 置信度 **高** · 静态

实现完整的服务端到受控端文件上传：接收文件名、大小、分块数、目标绝对路径、SHA-256 与覆盖策略，写入同目录 .part 临时文件，校验分块与整体 SHA-256 后落到目标路径；拒绝包含 ".." 的路径，单文件上限 10MB，覆盖策略支持报错/覆盖/自动改名。

> **证据**：BeCtrl.Business.Upload.FileReceiver.OnUploadStart/ResolveFinalPath（方法 RVA 0xed3c）/IsSafeAbsolutePath（RVA 0xede4）：IsPathRooted 校验、按反斜杠分割拒绝 ".."、FileMode 与 {0}.{1} 改名；ProtocolConst.MaxUploadFileSize=10485760；Protocol.UploadCodec 编解码 UploadStart/Data/End/Cancel/Error
> 
> **来源**：`ref:c2a43e98bb`

### 9. 采集主机指纹

`T1082, T1016` · 置信度 **高** · 静态

登录前拼接主机名、操作系统描述与设备指纹发送给 C2；指纹取自网卡 MAC 与注册表 HARDWARE\DEVICEMAP\Scsi 下的磁盘序列号，失败时使用回退值，用于识别与去重受控主机。

> **证据**：BeCtrl.Business.LoginClient.BuildClientInfoPlain：Encoding.UTF8.GetBytes(MachineName)、RuntimeInformation.OSDescription 与 FingerprintProvider.Get 拼接；FingerprintProvider.PickMac/PickDiskSerial 读取注册表路径 "HARDWARE\\DEVICEMAP\\Scsi\\Scsi Port 0\\Scsi Bus 0\\Target Id 0\\Logical Unit Id 0"
> 
> **来源**：`ref:c2a43e98bb`

## 不应误判

:::important
以下结论**容易被误判**，引用本报告时请注意。

- 不能判定为勒索软件：AES-256-GCM 仅用于 C2 会话加密，代码中没有用户文件遍历、加密或赎金说明。
- 不能判定为凭证/浏览器数据窃取器：未见浏览器数据库、钱包、凭据目录访问，回传内容限于命令输出与主机指纹。
- 内置 RSA 公钥不是勒索或文件加密密钥，而是登录阶段用于包装随机会话密钥。
- 不能仅凭文件上传能力就称其为通用 dropper：上传由 C2 指令驱动，目标路径与内容均来自服务端。
- 二进制中出现的类 flag 噪声串不是真实 flag，也不应作为 C2 凭据或配置使用。
:::
